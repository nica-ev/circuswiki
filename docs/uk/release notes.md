>[!info]
>Ці нотатки про випуск містять лише загальний огляд. Дрібні зміни (наприклад, окремі нові сторінки, зміни в наявному контенті) не перелічені всі. Однак їх можна детально відстежити в історії репозиторію.

>[!info]- **Версія:** v0.04 - **Дата випуску**: 9 червня 2026
>**Контент**
>- Значно розширено багатомовний контент: тепер контент розташований структуровано в `docs/<мова>`.
>- Додано нові та оновлені переклади для багатьох описів ігор та сторінок проєктів.
>- Імпортовано польські матеріали для воркшопів та інтегровано їх у багатомовну структуру контенту.
>- Подальша уніфікація структури контенту та метаданих для ігор.
>
>**Технічні аспекти**
>- Генератор вебсайту переведено з MkDocs/MkDocs Material на Zensical.
>- Впроваджено нову багатомовну структуру збірки та підготовки до випуску.
>- Німецька залишається мовою за замовчуванням без префікса мови; інші мови публікуються під кодами мов, наприклад, `/en/`, `/pl/`, `/es/`.
>- Впроваджено централізовану конфігурацію мов через `tools/config/languages.json`.
>- Оновлено розгортання GitHub Pages для нової структури Zensical.
>- Значно розширено локальні інструменти перекладу та консоль розробника: перевірки стану, пакетне планування, статус перекладу, графічні представлення, інструменти навігації, робочі процеси виправлення посилань та очищення.
>- Додано перемикач мов, індикатори статусу перекладу та резервні сторінки для відсутніх перекладів.
>- Покращено таблиці у фінальному виводі сайту: сортовані таблиці, краще відображення щільних таблиць та опціонально згортані секції сторінок.
>
>**Виправлено**
>- Внутрішні посилання та посилання Markdown на перекладених сторінках надійніше зберігаються та виправляються.
>- Стабілізовано багатомовну навігацію та структуру URL.
>- Покращено адаптивну поведінку навігації, особливо у поєднанні з мобільним меню-гамбургером Zensical.

>[!info]- **Версія:** v0.03 - **Дата випуску**: 11 березня 2025
>**Контент**
>- Додано відсутні описи ігор
>

>- Додано іконку сайту (Favicon) та логотип
>- Редизайн інтерфейсу користувача (UI)
>- Навігація першого рівня тепер знаходиться у заголовку сторінки, тоді як контекстно-залежна права панель навігації адаптується
>- Таблиці можна сортувати, натискаючи на заголовки
>
>**Виправлено**
>- Теги знову працюють
