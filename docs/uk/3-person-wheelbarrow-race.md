> [!info] Короткий опис
> Гонка для трьох осіб, де двоє носіїв керують "людським тачкою", одночасно підтримуючи спільний каскад із трьох м'ячів.

![wheelbarrow-juggling](../img/wheelbarrow-juggling.jpg){ width=300 }

**Розмір групи**: від 3 до 60 гравців  
**Складність**: середня  
**Матеріал**: Три м'ячі для жонглювання на команду, маркери дистанції  
**Тривалість**: приблизно 5-15 хвилин

## Опис гри

Команди складаються з трьох гравців. Один гравець виконує роль "людської тачки", спираючись на руки. Інші два гравці тримають по одній нозі гравця-тачки.

Під час руху до фінішної лінії, двоє гравців, що стоять, підтримують спільний каскад із трьох м'ячів між собою. Команда повинна рухатися як єдине ціле, не впускаючи м'ячі та не дозволяючи позиції "тачки" розвалитися. Перемагає найшвидша команда, яка пройшла дистанцію без помилок.

## Підготовка

- Позначте коротку пряму дистанцію зі стартовою та фінішною лініями.
- Сформуйте команди по три особи.
- Дозвольте кожній команді потренувати позицію "тачки" перед тим, як додавати жонглювання.
- Запускайте команди по черзі, в окремих доріжках або забігами, залежно від наявного простору.

## Правила

1. Гравець-тачка починає в позиції опори на руках, а двоє носіїв тримають по одній його нозі.
2. Носії починають спільний каскад із трьох м'ячів.
3. За сигналом команда рухається до фінішної лінії, підтримуючи активний каскад.
4. Команда повинна почати заново або вибуває, якщо м'ячі впали, гравець-тачка втратив рівновагу, носій відпустив ногу, або команда покинула свою доріжку.
5. Перемагає найшвидший пробіг без помилок.

## Варіанти

- Скоротіть дистанцію для молодших або менш фізично підготовлених груп.
- Дозвольте обмін одним або двома м'ячами перед спробою повного каскаду з трьох м'ячів.
- Використовуйте випробування на дальність замість гонки: як далеко команда може пройти без помилок?
- Дозвольте членам команди мінятися ролями після кожного раунду.

## Заходи безпеки

Зробіть дистанцію короткою та використовуйте м'яку, чисту поверхню. Негайно зупиніться, якщо відчуваєте перевантаження зап'ясть, плечей або спини. Не дозволяйте командам змагатися пліч-о-пліч, якщо доріжки недостатньо широкі, щоб уникнути зіткнень.
