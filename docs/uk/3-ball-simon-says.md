> [!info] Короткий опис
> Гра на команду та реакцію, де жонглери виконують лише правильні команди "Саймон каже", продовжуючи жонглювати трьома м'ячами.

![3-ball-simon-says](../img/3-ball-simon-says.jpg){ width=300 }

**Кількість гравців**: від 3 до 50 осіб  
**Складність**: середня  
**Матеріал**: Три м'ячі для жонглювання на кожного гравця  
**Тривалість**: приблизно 5-10 хвилин

## Опис гри

Усі гравці жонглюють трьома м'ячами, поки ведучий дає команди на рух або трюки. Гравці виконують лише ті команди, що починаються зі встановленої фрази, наприклад, "Саймон каже". Той, хто виконає хибну команду, проігнорує правильну команду, впустить м'яч або припинить жонглювати, вибуває з гри.

Можливі команди включають: обернутися, сісти, лягти, встати, плеснути в долоні, змінити патерн, рухатися вліво чи вправо, або завмерти.

## Підготовка

- Роздайте кожному гравцеві по три м'ячі та забезпечте достатньо особистого простору.
- Оберіть ведучого.
- Домовтеся, чи гравці вибувають з гри, чи отримують кумедні штрафні бали.

## Варіанти

- Для початківців використовуйте один м'яч або хустки.
- Зробіть гру кооперативною, підраховуючи, скільки команд група зможе пережити разом.
- Дозвольте вибулим гравцям стати помічниками ведучого.

## Заходи безпеки

Уникайте команд, які змушують гравців стрибати, бігти один на одного або рухатися наосліп, стежачи за своїми предметами.
