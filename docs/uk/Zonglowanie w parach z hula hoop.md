# Жонглювання в парах з хула-хупом

Вправа для пар, що розвиває співпрацю, ритм, таймінг та роботу з обручем.

## Етап I

Два хула-хупи на пару.

Працюємо синхронно:

1. Кочення.
2. Кидання.

## Етап II

Чотири хула-хупи на пару.

Працюємо синхронно:

1. Кочення.
2. Кидання.
3. Кочення та кидання.
4. Повторюємо всі етапи асинхронно.
