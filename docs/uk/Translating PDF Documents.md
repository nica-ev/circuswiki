# Посібник: Переклад PDF-документів за допомогою великих мовних моделей

## Вступ

Цей посібник окреслює процес перекладу вмісту PDF-документів, особливо тих, що містять неселективний текстовий вміст на основі зображень, за допомогою великих мовних моделей (LLM). Робочий процес включає оптимізацію PDF, вилучення тексту за допомогою оптичного розпізнавання символів (OCR), переклад тексту та, нарешті, переформатування перекладу у формат PDF.

**Передумови:**

*   Обліковий запис Google (для доступу до Google AI Studio).
*   Необов'язково: Програмне забезпечення для оптимізації PDF (наприклад, pdf24 Creator).
*   Необов'язково: Текстовий редактор або текстовий процесор, здатний працювати з Markdown та експортувати у PDF (наприклад, Obsidian, Microsoft Word).

## Крок 1: Підготовка PDF-документа

**Мета:** Зменшити розмір файлу PDF для оптимізації його обробки LLM, зберігаючи при цьому розбірливість тексту. LLM часто мають обмеження щодо розміру вхідних даних, а менші файли обробляються ефективніше.

**Міркування:**

*   **PDF на основі тексту:** Якщо текст у PDF можна виділити (тобто він вбудований електронно), зменшення розміру файлу зазвичай легше і дозволяє досягти менших розмірів без втрати якості.
*   **PDF на основі зображень:** Якщо сторінки PDF є зображеннями тексту (текст не можна виділити окремо), зменшення розміру включає стиснення зображень. Слід подбати про те, щоб не зменшувати якість настільки, щоб текст став нерозбірливим для OCR.

**Процедура (Приклад з використанням pdf24):**

1.  Відкрийте свій PDF-документ у такому інструменті, як pdf24 Creator ([https://www.pdf24.org/](https://www.pdf24.org/)).
2.  Використовуйте функції стиснення або зменшення розміру. Поширені ефективні налаштування включають:
    *   Увімкнення оптимізації для веб.
    *   Перетворення кольорів у відтінки сірого.
3.  Експериментуйте з рівнями стиснення, прагнучи до розміру файлу менше **5 МБ**, одночасно забезпечуючи чіткість і розбірливість тексту.
4.  Збережіть оптимізований PDF-файл.

## Крок 2: Вилучення тексту за допомогою Google AI Studio (Транскрипція/OCR)

**Мета:** Використовувати мультимодальні можливості LLM для виконання OCR на підготовленому PDF та вилучення текстового вмісту у структурованому форматі.

**Процедура:**

1.  Перейдіть до **Google AI Studio** ([https://aistudio.google.com/](https://aistudio.google.com/)) та увійдіть за допомогою свого облікового запису Google. Примітка: AI Studio — це насамперед інструмент для експериментів з моделями та підказками.
2.  Розпочніть нову сесію або чат.
3.  Прикріпіть оптимізований PDF-файл до своєї сесії (наприклад, за допомогою кнопки прикріплення або перетягування).
4.  Введіть таку підказку в область повідомлення користувача:
    ```
    Будь ласка, транскрибуйте доданий PDF. Він містить зображення з текстом, що потребує OCR. Виведіть транскрипцію у належному форматі Markdown, використовуючи заголовки та списки для створення структури, яка максимально відповідає макету оригінального документа.
    ```
5.  Налаштуйте параметри моделі:
    *   Зберігайте налаштування за замовчуванням, якщо у вас немає конкретних вимог.
    *   Встановіть **Температуру** на **0.1**. Нижча температура сприяє більш детермінованому та менш творчому виводу, що підходить для точної транскрипції.
6.  Надішліть підказку. Процес транскрипції може зайняти кілька хвилин (потенційно 4-6 хвилин або довше, залежно від розміру та складності PDF).
7.  Після завершення генерації скопіюйте отриманий текст Markdown.
    *   *Метод 1:* Використовуйте опцію копіювання, яка часто надається в інтерфейсі (наприклад, через меню, пов'язане з відповіддю).
    *   *Метод 2:* Вручну виділіть увесь згенерований текст і скопіюйте його (Ctrl+C або клацніть правою кнопкою миші -> Копіювати).
8.  Вставте скопійований текст Markdown у простий текстовий редактор (наприклад, Notepad, VS Code, Obsidian тощо).
9.  Збережіть цей вміст як текстовий файл. Рекомендується використовувати розширення `.txt` або `.md` (Markdown). Форматування Markdown допомагає зберегти структуру документа (заголовки, списки).

## Крок 3: Переклад вилученого тексту за допомогою Google AI Studio

**Мета:** Перекласти вилучений текст Markdown на бажану цільову мову, зберігаючи оригінальну структуру та форматування.

**Процедура:**

1.  У **Google AI Studio** розпочніть **новий чат**, щоб забезпечити свіжий контекст для завдання перекладу.
2.  Прикріпіть збережений файл `.txt` або `.md`, що містить вилучений текст Markdown.
3.  Введіть підказку для перекладу, вказавши вихідну та цільову мови. Приклад для перекладу з англійської на італійську:
    ```
    Будь ласка, перекладіть доданий файл Markdown (англійська) на італійську. Точно збережіть оригінальну структуру, форматування, тон та стиль мовлення.
    ```
    *   **Змініть підказку** відповідно до ваших конкретних вихідних та цільових мов (наприклад, "...перекладіть доданий файл Markdown (німецька) на іспанську..."). Якість перекладу може варіюватися залежно від мовної пари.
4.  Налаштуйте параметри моделі:
    *   Переконайтеся, що налаштування за замовчуванням є відповідними.
    *   Встановіть **Температуру** на **0.1**, щоб сприяти точності вихідного тексту та структури під час перекладу.
5.  Надішліть підказку. Переклад також може зайняти кілька хвилин, порівнянно з часом транскрипції.
6.  Після генерації скопіюйте перекладений текст Markdown, використовуючи методи, описані в Кроці 2 (кнопка копіювання в інтерфейсі або ручне виділення).

## Крок 4: Переформатування перекладеного тексту у PDF-документ

**Мета:** Конвертувати перекладений текст Markdown назад у PDF-документ для поширення або архівування.

**Процедура:**

1.  Вставте скопійований перекладений текст Markdown у відповідну програму.
2.  **Рекомендовано:** Використовуйте текстовий редактор або обробник документів, який розуміє форматування Markdown, щоб зберегти структуру (заголовки, списки тощо).
    *   **Obsidian** ([https://obsidian.md/](https://obsidian.md/)) — це безкоштовний інструмент, який добре працює з файлами Markdown і часто має можливості експорту в PDF (безпосередньо або через плагіни).
    *   Сучасні текстові процесори (наприклад, Microsoft Word) також можуть імпортувати або вставляти Markdown і дозволяти зберігати/експортувати у форматі PDF, хоча точність форматування може відрізнятися.
    *   Спеціалізовані конвертери Markdown у PDF також доступні онлайн або як програмне забезпечення для встановлення.
3.  Використовуйте функцію "Експортувати у PDF" або "Зберегти як PDF" програми.
4.  Перегляньте отриманий PDF, щоб переконатися, що форматування та вміст виглядають як очікувалося.

## Висновок

Цей посібник продемонстрував робочий процес використання Google AI Studio для транскрипції та перекладу PDF-документів, включаючи ті, що потребують OCR. Шляхом підготовки PDF, вилучення тексту за допомогою налаштованої LLM, перекладу результату та його переформатування користувачі можуть отримати перекладені версії своїх документів. Хоча цей метод пропонує безкоштовне або недороге рішення, користувачі повинні пам'ятати про потенційні відмінності в точності OCR та якості перекладу, особливо для складних макетів або менш поширених мов. Час обробки значною мірою залежить від розміру документа та завантаження сервера.
