> [!info] Короткий опис
> Турнірний формат гри в Бей-гому для початківців, де матчі один на один вирішуються досягненням двох перемог.

**Розмір групи**: 4-64 особи
**Складність**: Середня
**Матеріали**: Бей-гома, мотузки, ігровий майданчик, турнірна сітка
**Тривалість**: 15-60 хвилин

## **Опис гри**:

Турнірний матч — це поширений формат змагань з Бей-гоми. Гравці змагаються один на один і просуваються по турнірній сітці. Tokyo Beigoma зазначає, що детальні правила турніру можуть відрізнятися залежно від регіону, тому місцеві правила слід оголосити перед першим матчем.

Двоє гравців стають один проти одного. За спільною командою на старт обидва одночасно запускають свої Бей-гоми на майданчик. Перший гравець, який виграє два раунди, проходить далі.

Гравець виграє раунд, вибивши суперника з майданчика, обертаючись довше за суперника або отримавши перевагу через повторні промахи суперника за місцевими правилами.

## **Спрощене правило промаху майданчика для початківців**:

У строгому регламенті один промах майданчика може зараховуватися як програш. Для турнірів для початківців Tokyo Beigoma описує м'якше правило: гравець програє раунд лише після двох послідовних промахів майданчика.

Це допомагає новачкам залишатися в грі достатньо довго, щоб відчути справжнє змагання, зберігаючи при цьому певну напругу.

## **Перезапуски**:

Повторіть раунд, якщо:

- обидва гравці промахнулися майданчиком
- обидві дзиґи зіткнулися і одночасно покинули майданчик
- результат неможливо чітко визначити

## **Варіанти**:

Для досвідчених груп використовуйте суворі правила промаху майданчика та дозволяйте менше перезапусків.

Для дітей або гравців, які грають вперше, дозвольте більше спроб промаху майданчика, перш ніж зараховувати програш.

## **Примітки**:

Цей формат визначає чіткого переможця, але може швидко вибити новачків. Використовуйте тренувальні раунди перед початком турніру.
