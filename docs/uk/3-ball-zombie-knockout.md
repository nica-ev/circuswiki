> [!info] Короткий опис
> Тематична гра на вибування з жонглюванням, де жонглери з трьома м'ячами намагаються пережити переслідування в стилі зомбі.

![3-ball-zombie-knockout](../img/3-ball-zombie-knockout.jpg){ width=300 }

**Розмір групи**: від 5 до 40 гравців
**Складність**: середня
**Матеріал**: Три м'ячі для жонглювання для кожного активного гравця, розмічена арена
**Тривалість**: приблизно 5-10 хвилин

## Опис гри

Гравці жонглюють трьома м'ячами, уникаючи тиску з боку "зомбі". Гра поєднує витривалість у жонглюванні, гру в квача та грайливу тему жахів.

## Підготовка

- Розмітьте арену.
- Оберіть одного або кількох "зомбі" для початку.
- Визначте обмеження для руху "зомбі", наприклад, повільна ходьба, витягнуті вперед руки або заборона бігу.

## Правила

1. Усі гравці, крім "зомбі", починають жонглювати трьома м'ячами.
2. "Зомбі" рухаються по арені та намагаються торкнутися або "залякати" жонглерів у межах узгоджених обмежень.
3. Жонглер стає "зомбі" або вибуває, якщо він впустив м'яч, покинув арену або був легально "торкнутий".
4. Раунд триває доти, доки не залишиться один жонглер, який не є "зомбі", або доки всі гравці не стануть "зомбі".
5. Перемагає останній жонглер, що вижив, або "зомбі", якщо всі перетворилися.

## Варіанти

- Використовуйте перетворення замість вибування, щоб усі продовжували грати.
- Дозвольте "зомбі" не використовувати реквізит для безпеки новачків.
- Вимагайте від "зомбі" жонглювати одним м'ячем для просунутого варіанту.

## Заходи безпеки

Рух "зомбі" має бути повільним і передбачуваним. Не дозволяйте хапати, штовхати або лякати в тісних групах.
