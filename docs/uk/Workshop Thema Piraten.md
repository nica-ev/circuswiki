# Тема майстер-класу: Пірати

Особливо для дітей дошкільного віку рекомендується тематично інтегрувати різні циркові дисципліни. Популярною темою, безсумнівно, є "Пірати".

Прості способи включити вправи на балансування на канаті:

- перетинати глибоку ущелину в пошуках піратських скарбів

Подібним чином можна знайти тематичне застосування для (майже) всіх дисциплін.

- Повітряна акробатика: лазіння по кораблю в такелажі
- Жонглювання хустками: червоні хустки використовуються як вогонь, біля якого смажать зефір/яблука; вони стають гарячими, і їх потрібно перекидати з руки в руку
