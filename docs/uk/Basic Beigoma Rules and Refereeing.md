> [!info] Резюме
> Правила Бейґоми мають бути достатньо суворими, щоб створити напругу, і достатньо гнучкими, щоб новачки мали значущі спроби.

## **Початок раунду**:

Гравці стоять навколо майданчика зі своїми бейґомами, загорнутими та готовими. Поширений початок використовує спільний виклик, наприклад, `камаете, чітчі-но-чі`, після чого всі гравці кидають одночасно.

Для майстер-класів для початківців точне формулювання менш важливе, ніж чіткий спільний ритм. Усі повинні розуміти, коли відбувається кидок.

## **Поширені умови перемоги**:

### Перемога Рікі (Riki win)

Перемагає дзиґа, яка найдовше обертається на підлозі.

Поширеним правилом для близьких результатів є правило трьох секунд: якщо одна дзиґа обертається щонайменше на три секунди довше за іншу, вона перемагає. Якщо різниця менша, раунд повторюється.

### Перемога Хаджікі (Hajiki win)

Гравець перемагає, вибивши дзиґу суперника з майданчика.

Зазвичай це більш динамічна та тактична гра, ніж чиста гра на найдовше обертання.

### Командна перемога Хаджікі (Team Hajiki win)

У командних форматах сильнішим результатом може вважатися вибивання суперників, коли обидва гравці однієї команди залишаються обертатися на майданчику.

## **Повторні кидки та нічиї**:

Повторний кидок корисний, коли раунд не дає значущого результату. Поширені випадки:

- усі гравці промахуються по майданчику
- усі дзиґи вибиті одночасно
- дзиґи ніколи не торкаються одна одної в наборі правил, що вимагає контакту
- результат Рікі занадто близький, щоб його чітко оцінити

Фасилітатор повинен швидко оголошувати повторні кидки. Довгі дебати сповільнюють гру та знижують енергію.

## **Промахи майданчика**:

Промах майданчика означає, що бейґома не потрапила на ігровий майданчик. За суворими правилами це може одразу вважатися програшем або принести очки супернику.

Для дружніх до новачків правил турніру, Tokyo Beigoma описує дозвіл більшої гнучкості: наприклад, зараховувати промах майданчика як програш лише після двох послідовних промахів. Це запобігає програшу новачків без гри взагалі.

## **Принципи суддівства**:

- Оголосіть місцеві правила перед початком гри.
- Використовуйте одні й ті самі правила для всього раунду або турніру.
- У неясних ситуаціях дотримуйтесь рішення судді або організатора.
- Для груп новачків надавайте перевагу чіткому імпульсу над ідеальною точністю.
- Для серйозних матчів заздалегідь визначте промах майданчика, повторний кидок, контакт та близькі рішення Рікі.

## **Примітки до майстер-класу**:

Хорошим стандартом для змішаних груп є:

- тільки звичайні дзиґи
- повторний кидок, якщо всі промахуються
- поблажка для новачків за перший промах майданчика
- зараховуються як Рікі, так і Хаджікі
- рішення судді є остаточним після оголошення

## **Джерело**:

На основі термінології Tokyo Beigoma, правил турніру та рекомендацій щодо підрахунку очок.
