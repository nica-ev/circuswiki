# Хулахуп Інтеграл
Хулахуп Інтеграл — це педагогічний та мистецький проєкт, започаткований у Латинській Америці, який досліджує обруч як інструмент для навчання, вираження та соціальної трансформації. Його підхід поєднує гру, рух та інклюзивність, пропонуючи доступні можливості для людей будь-якого віку та походження. Через тренінги, майстер-класи та громадські акції проєкт сприяє розвитку колаборативних мереж та чутливих методологій, зосереджених на тілі, творчості та різноманітті.
