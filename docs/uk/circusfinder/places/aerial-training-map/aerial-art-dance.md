# Аероденс-танець

Аероденс-танець (Aerial Art Dance) внесено до списку відкритих тренувальних майданчиків для повітряної акробатики або циркового мистецтва на мапі "Циркові зали / Школи по всьому світу", створеній на основі краудсорсингу.

Вебсайт: [https://www.aerial-artdance.com/](https://www.aerial-artdance.com/)
