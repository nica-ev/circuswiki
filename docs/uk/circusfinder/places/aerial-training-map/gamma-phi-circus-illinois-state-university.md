# Цирк Ґамма Фі (Університет штату Іллінойс)

Цирк Ґамма Фі (Університет штату Іллінойс) внесено до списку відкритих місць для тренувань з повітряної акробатики або циркового мистецтва на мапі «Циркові зали / Школи по всьому світу», створеній спільнотою.

Вебсайт: [https://gammaphicircus.illinoisstate.edu](https://gammaphicircus.illinoisstate.edu)

## Джерело

Імпортовано зі звіту «Циркові зали / Школи по всьому світу» від 10.10.2026. У цій партії опубліковано лише записи з позначкою «відкрито». Положення на мапі вважається приблизним, оскільки координати походять із мапи, створеної спільнотою.
