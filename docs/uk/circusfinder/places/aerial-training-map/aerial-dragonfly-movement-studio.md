# Студія повітряної акробатики "Літаючий Дракон"

Студія повітряної акробатики "Літаючий Дракон" (Aerial Dragonfly Movement Studio) внесена до списку відкритих місць для тренувань з повітряної акробатики та циркового мистецтва на мапі "Циркові зали / Школи по всьому світу", створеній на основі даних від користувачів.

Вебсайт: [https://www.aerialdragonfly.com/](https://www.aerialdragonfly.com/)
