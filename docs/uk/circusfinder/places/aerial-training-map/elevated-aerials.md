# Elevated Aerials

Elevated Aerials зазначено як місце для тренувань з повітряної акробатики або циркового мистецтва на мапі «Циркові зали / Школи по всьому світу», створеній спільнотою.

Вебсайт: [https://elevated-aerials.com/](https://elevated-aerials.com/)

## Джерело

Імпортовано зі звіту «Циркові зали / Школи по всьому світу» від 10.10.2026. У цій партії опубліковано лише записи, позначені як відкриті. Положення на мапі вважається приблизним, оскільки координати походять із мапи, створеної спільнотою.
