# Академія тренувань "Чемпіон"

Академія тренувань "Чемпіон" (Champion Training Academy) внесена до списку відкритих місць для тренувань з повітряної акробатики або циркового мистецтва на карті "Циркові тренувальні зали / Школи по всьому світу", створеній на основі краудсорсингу.
