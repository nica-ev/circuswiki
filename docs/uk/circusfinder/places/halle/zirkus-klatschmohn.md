# Цирк Мак

Цирк Мак пропонує щорічні заняття для дітей, підлітків та дорослих у своїх опалюваних циркових наметах на площі Россплац. Серед пропозицій – повітряна акробатика, акробатика, вправи на рівновагу та жонглювання.

Безкоштовне ознайомче заняття можливе за попередньою домовленістю з адміністрацією цирку. Оскільки багато занять вже мають повну наповненість, може існувати список очікування.
