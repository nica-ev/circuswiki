# Ауґартен Ґрац

Ауґартен Ґрац зазначений на спільнотному JugglingMap як місце для тренувань з жонглювання або як клуб жонглерів.

## Тренування з жонглювання або клуб жонглерів

У теплу пору року ви можете зустріти жонглерів будь-якого дня та будь-коли, але найімовірніше — вдень/увечері. Ми зустрічаємося біля скейт-півтруби. Якщо хтось зі спільноти буде там, ви побачите об'єкти в повітрі. Змішана група жонглерів та спінерів. Під час навчального року ми віддаємо перевагу зустрічам у п'ятницю, пізно вдень.
