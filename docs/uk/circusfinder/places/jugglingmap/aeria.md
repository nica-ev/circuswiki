# AERIA

AERIA внесено до списку тренувальних студій або клубів з жонглювання на спільнотному ресурсі JugglingMap.

Місцезнаходження згідно з джерелом: Rue Édouard Delesalle, Lille, Hauts-de-France, France

## Тренувальна студія або клуб з жонглювання

AERIA — це студія пол-денсу та повітряної гімнастики на кільці, розташована в місті Лілль, Франція, за кілька хвилин ходьби від залізничного вокзалу.

Студія пропонує універсальний тренувальний простір з висотою стелі 4,40 м, що підходить для пол-денсу, повітряної гімнастики на кільці та інших повітряних дисциплін. Простір обладнано 3 точками кріплення для повітряних снарядів, а жердини можна демонтувати за потреби, що забезпечує гнучкість тренувального процесу.

Залежно від конфігурації та необхідного обладнання, простір може бути придатним для повітряних тренувань, жонглювання, акробатики, вправ на гнучкість та рухової практики.

Будь ласка, зв'яжіться з AERIA заздалегідь, щоб уточнити наявність місця та можливість використання необхідного обладнання/конфігурації для вашої дисципліни.
