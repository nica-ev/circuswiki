# Відкриті циркові тренування Утрехт

Відкриті циркові тренування Утрехт зазначені на підтримуваній спільнотою JugglingMap як тренування з жонглювання або клуб жонглювання.

Місцезнаходження, надане джерелом: Deken Roesstraat 2A, Утрехт, Утрехт, Нідерланди

## Тренування з жонглювання або клуб жонглювання

Місце для тренувань та спілкування для всіх циркових дисциплін. Ми орендуємо зал щороку з вересня до NJF десь у травні. Після NJF ми нерегулярно тренуємося на свіжому повітрі у парку Вільгельміна вечорами у четвер.

У залі є кілька точок для підвішування повітряних снарядів, але шовк/мотузку/обруч тощо потрібно приносити з собою.

Розклад, наданий джерелом: Чт 20:00–22:00

Доступ: обмежений: 5 євро за сесію
