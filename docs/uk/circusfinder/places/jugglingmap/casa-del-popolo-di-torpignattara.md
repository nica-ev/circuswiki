# Casa del Popolo di Torpignattara

Casa del Popolo di Torpignattara внесено до JugglingMap, керованої спільнотою, як місце для тренувань або клуб з жонглювання.

Місцезнаходження згідно з джерелом: Via Benedetto Bordoni, Roma, Lazio, Italia

## Тренування або клуб з жонглювання

Простір призначений для вільних тренувань та репетицій. Отже, це НЕ тільки жонглювання, але й театральні репетиції.
Щодо музики, то тут самоорганізація залежить від того, хто присутній. Будьте уважні, щоб не монополізувати акустичний простір. Навушники іноді корисні. Головне — спілкуватися та домовлятися з присутніми, щоб обрати найзручніше та найефективніше рішення для всіх.
Перед вільними тренуваннями/репетиціями проходить заняття з йоги, яке є лише одним із курсів, що проводяться у цьому просторі. Як тільки ми отримаємо афішу з усією програмою курсів на цей рік, ми завантажимо її сюди.
Давайте, вперед!

Розклад згідно з джерелом: Чт 11:30–18:00

Доступ: обмежений: Підтримка для покриття поточних витрат (туалетний папір, комунальні послуги тощо).
Якщо ви перебуваєте менше 3 годин, вирішуйте самі. Якщо ви перебуваєте більше 3 годин, залиште, якщо можете, 3 євро.
Також вітаються інші види обміну, якщо ви віддаєте перевагу, обговорімо.
Обов'язково залишайте місце чистим, як або навіть чистішим, ніж ви його знайшли.
У приміщенні:
- є велика зала площею 80 кв. м з ламінатом;
- немає спеціальної зони для повітряної акробатики;
- куточок для трав'яних напоїв з самообслуговуванням;
- приміщення зі столами та стільцями;
- WIFI;
- гучність музики слід тримати низькою.
