# Lowlines (Стаціонарний станок для хайлайну)

Lowlines (Стаціонарний станок для хайлайну) внесено до списку тренувань з жонглювання або клубів жонглювання на спільнотному ресурсі JugglingMap.

Місцезнаходження, надане джерелом: Museumpark Orientalis, 2, Profetenlaan, Heilig Landstichting, Gelderland, Nederland

## Тренування з жонглювання або клуб жонглювання

Це місце для тренувань з хайлайну від колективу Lowlines (які також трохи займаються жонглюванням).
Будь ласка, зв'яжіться з нами перед візитом, оскільки ми не завжди там присутні.
Конфігурація хайлайну: 70 м Dyneema з банджі.

Доступ: обмежений: Зв'яжіться з Lowlines електронною поштою або телефоном.

Контактна інформація, надана джерелом:

Вебсайт: https://lowlines.nl/ | Електронна пошта: slackline@lowlines.nl

Посилання або соціальні мережі, надані джерелом:

https://www.instagram.com/lowlines_nl/
