# Cirque Aria

Cirque Aria зазначено на мапі спільноти JugglingMap як місце для тренувань з жонглювання або клуб жонглювання.

Місцезнаходження, надане джерелом: Timco East, Leon Valley, Texas, United States

## Тренування з жонглювання або клуб жонглювання

Щотижневі зустрічі з жонглювання в Cirque Aria на західній стороні Сан-Антоніо. Приміщення з високими стелями та кондиціонером! Багато реквізиту для спроб, усі рівні досвіду вітаються. Приходьте практикуватися з іншими жонглерами або завітайте, щоб навчитися жонглювати. Ми також проводимо безкоштовну громадську циркову вечірку щопершої суботи з 17:00 до 20:00 в Cirque Aria з жонглюванням, флоу, парною акробатикою та повітряною акробатикою!
