# Жонглювання у парку Волерс

Жонглювання у парку Волерс (Jonglieren im Wohlerspark) позначено на мапі жонглювання, що підтримується спільнотою, як місце для тренувань з жонглювання або клуб жонглювання.

Місцезнаходження згідно з джерелом: Karl Moritz Gottsche, Wohlers Allee, Гамбург, Німеччина

## Тренування з жонглювання або клуб жонглювання

У цьому дуже красивому та заплутаному парку за гарної погоди завжди можна побачити десь жонглерів, людей, що займаються фулоу-артом, слеклайнерів та/або акробатів, зазвичай просто біля позначки.
