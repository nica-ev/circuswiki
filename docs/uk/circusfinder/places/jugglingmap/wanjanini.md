# Wanjanini

Wanjanini внесено до списку на ресурсі JugglingMap, який підтримується спільнотою, як циркова школа або майстерня з жонглювання.

Місцезнаходження, надане джерелом: Ротенбург (Вюмме), Нижня Саксонія, Німеччина

## Циркова школа або майстерня з жонглювання

У нас є дитячий та молодіжний цирк. Під час канікул діти залишаються у нас, сплять у циркових фургонах і тренують усілякі циркові номери.
Між тим, простір, включно з наметом, можна використовувати для різноманітних занять.
На вулиці розташована установка для середнього літаючого трапеції.

Вік: 8–81
