# Міст

Вільний простір для тренувань на найбільшому кампусі UNAM. Місце діє понад 15 років, де жонглери з Мехіко збираються щодня, особливо по п'ятницях у CU!

Розклад, наданий джерелом: Пт 16:00–20:00
