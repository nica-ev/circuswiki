# Парк Гіммель

Парк Гіммель зазначений у спільноті JugglingMap як місце для тренувань з жонглювання або клуб жонглювання.

Місцезнаходження згідно з джерелом: Бібліотека філії Гіммель, Іст 1-а Стріт, Тусон, Аризона, Сполучені Штати Америки.

## Тренування з жонглювання або клуб жонглювання
