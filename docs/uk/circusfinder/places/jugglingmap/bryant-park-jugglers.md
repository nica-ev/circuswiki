# Жонглери Брайант-парку

«Жонглери Брайант-парку» внесено до списку на JugglingMap, який підтримується спільнотою, як гурток чи клуб з навчання жонглювання.

## Навчання жонглюванню або клуб жонглерів

Жонглери жонглюють. Ми також навчаємо!
Реквізит для жонглювання надається безкоштовно для використання в парку під час визначеного часу для жонглювання, просто приходьте самі.

Нове місцезнаходження з квітня 2026 року:
Основне місце: на майданчику для гри в шаффлборд, південно-західний кут Брайант-парку (6-та авеню та 40-та вулиця)
Додаткові місця: Тераса за бібліотекою та галявина Брайант-парку
*Відомо, що група переміщується до різних місць у Брайант-парку. Якщо ви нікого не бачите, прогуляйтеся парком/бібліотекою та пошукайте, де літають булави.

Зустрічі по суботах проводяться лише з квітня по грудень. Усі інші зустрічі відбуваються цілий рік.
