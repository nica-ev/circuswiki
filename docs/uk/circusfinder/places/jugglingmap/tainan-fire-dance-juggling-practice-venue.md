# Місце для тренувань з вогняного танцю та жонглювання в Тайнані (Tainan Fire Dance & Juggling Practice Venue)

Місце для тренувань з вогняного танцю та жонглювання в Тайнані (Tainan Fire Dance & Juggling Practice Venue) внесено до спільнотного ресурсу JugglingMap як місце для тренувань або клуб жонглювання.

Місцезнаходження, надане джерелом: 飛撲雕像, 1, 大學路, 台南市, 臺灣

## Тренування з жонглювання або клуб жонглювання

Зазвичай це місце використовується клубом вогняного танцю Національного університету Чен Кун (National Cheng Kung University Fire Dance Club) для тренувань, але також запрошує до себе всіх охочих для звичайних тренувань з жонглювання.

Доступ: безкоштовний
