# NoFit State Circus

NoFit State Circus внесено до списку на керованій спільнотою JugglingMap як клуб чи місце для тренувань з жонглювання.

Місцезнаходження, надане джерелом: NoFit State Community Circus, Four Elms Road, Cardiff, Cymru / Wales, United Kingdom

## Тренування чи клуб з жонглювання

Заняття з жонглювання відбуваються щопершого та щотретього вівторка місяця.

Навчання жонглюванню також проводиться на молодіжних заняттях та громадських майстер-класах.

Розклад, наданий джерелом: Вт 18:00–19:30

Доступ: обмежений: рекомендована пожертва £2 (£1 для пільгових категорій)
