# River Park

River Park внесено до списку на JugglingMap, який підтримується спільнотою, як місце для тренувань з жонглювання або клуб жонглювання.

Місцезнаходження, надане джерелом: Гіллсборо, Північна Кароліна, США

## Тренування з жонглювання або клуб жонглювання

Слідкуйте за останніми оновленнями на Facebook, ми шукаємо приміщення. Ми зустрічаємося біля суботнього фермерського ринку в Гіллсборо, у River Park. Відкрито для всіх рівнів: хтось навчається, хтось жонглює десятиліцями, хтось передає булави, і ми готові навчити вас жонглювати теж!

Розклад, наданий джерелом: Субота 10:30–20:00

Доступ: безкоштовно
