# Circus Diedom

Circus Diedom внесено до списку циркових шкіл або майстерень з жонглювання на спільнотному ресурсі JugglingMap.

Місцезнаходження, надане джерелом: Beton-T, 4, Koningin Wilhelminalaan, Utrecht, Utrecht, Nederland

## Циркова школа або майстерня з жонглювання

Diedom розташований поруч із Beton T. Вхід знаходиться за адресою Koningin Wilhelminalaan 4c.

Цирк обладнаний для 5 основних дисциплін: маніпуляція предметами, баланс, повітряна гімнастика, акробатика та клоунада.

Тут високі стелі — 10 метрів. Тому багато повітряних гімнастів тренують тут свою дисципліну.

Щовівторка вранці та щочетверга ввечері проводяться відкриті тренування. Вартість для нечленів — 5 євро за тренування.

Перевіряйте вебсайт або Instagram для отримання додаткової інформації.

Вік: 6–99 років.
