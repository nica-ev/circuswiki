# b.Art

b.Art внесено до списку на JugglingMap, який підтримується спільнотою, як центр для тренувань з жонглювання або клуб жонглювання.

Місцезнаходження, надане джерелом: Schützenstraße, 56, Бамберг, Баварія, Німеччина

## Тренування з жонглювання або клуб жонглювання

Відкриті тренування, майстер-класи, резиденції, шоу.
Центр сучасного виконавського мистецтва.

Календар:
https://calendar.online/fab2e11fbb8440aa75c6

Відкриті тренування:
На власний ризик
За бажанням (рекомендовано 3 євро)
18+

Приміщення:
~ 50 кв. м з акробатичними матами та танцювальним покриттям
~ 4 м висоти
(3) точки для підвісного обладнання
(1) акробатична страховка (лонжа)
~7 м дзеркальна стіна

Технічне обладнання:
- Акустична система з мікшером
- Можливість затемнення ("чорна скринька")
- Атмосферне освітлення, кінематографічне/фото освітлення, фотоапаратура на запит

Доступ: обмежений: Не соромтеся приходити на відкриті тренування або зв'яжіться з нами для уточнень.
