# Місце для жонглювання в Герлі

Місце для жонглювання в Герлі (Juggling Place in Görli) зазначене на мапі жонглювання, що підтримується спільнотою (JugglingMap), як місце для тренувань з жонглювання або клуб жонглювання.

Місцезнаходження, надане джерелом: 3, Görlitzer Straße, Berlin, Deutschland

## Тренування з жонглювання або клуб жонглювання

Це безкоштовний простір для жонглювання в парку Герліц (Görlitzer Park). Ми зустрічаємося тут час від часу.

Доступ: безкоштовно
