# Circ.Us – відкритий простір для мистецтва

Circ.Us – відкритий простір для мистецтва зазначений у спільнотному проєкті JugglingMap як місце для тренувань з жонглювання або клуб жонглювання.

Місцезнаходження згідно з джерелом: Schaulust, 9, Beim Handelsmuseum, Бремен, Вільне Ганзейське місто Бремен, Німеччина.

## Тренування з жонглювання або клуб жонглювання

Відкриті тренування відбуваються щопершого вівторка місяця з 10:00 до 20:00.

Доступ: обмежений: 5-10 євро за весь день.
