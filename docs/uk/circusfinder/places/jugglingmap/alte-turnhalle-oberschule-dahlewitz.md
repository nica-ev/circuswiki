# Стара спортивна зала гімназії Далевіц

Стара спортивна зала гімназії Далевіц (Alte Turnhalle Oberschule Dahlewitz) внесена до спільнотного проєкту JugglingMap як місце для тренувань з жонглювання або гурток жонглювання.

Місцезнаходження згідно з джерелом: Oberschule Herbert Tschäpe, 63, Bahnhofstraße, Blankenfelde-Mahlow, Brandenburg, Deutschland

## Тренування з жонглювання або гурток жонглювання

Відкрита спільнота Flowarts. За гарної погоди ми зустрічаємося на пляжі Lido біля озера Рангсдорфер-Зее (Rangsdorfer See).
Найкраще зв'язатися з нами заздалегідь, щоб уточнити місце проведення тренувань.

Розклад згідно з джерелом: Пн 19:30–21:30
