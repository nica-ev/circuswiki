# Sorin Sirkus

Sorin Sirkus — фінська молодіжна циркова організація, яка щотижня залучає понад 600 учнів за підтримки близько 30 співробітників. Організація працює на місцевому, національному та міжнародному рівнях, сприяючи розвитку циркового мистецтва та педагогіки. З 1985 року Sorin Sirkus проводить курси для всіх вікових груп, включно зі спеціалізованими програмами для людей з інвалідністю, молоді з груп ризику та сімей, які потребують підтримки. Щорічна різдвяна вистава збирає понад 11 000 глядачів. Тут навчають жонглюванню, повітряній акробатиці, балансуванню, акробатиці та клоунаді. Щотижневі заходи включають адаптовані програми для людей з порушеннями зору, дітей у лікарнях, ув'язнених та молоді на реабілітації. Приміщення доступне для людей на візках, обладнане пандусами, адаптованим освітленням та аудіодескрипцією для відвідувачів з порушеннями зору та слуху.
