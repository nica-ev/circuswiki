# Lolly Jar Circus

Lolly Jar Circus — це єдина в Південній Австралії повністю інклюзивна соціальна циркова школа, яка пропонує циркову підготовку для дітей та молоді з усіма можливостями. Їхня основна місія — використовувати цирк як інструмент соціального розвитку, з особливим акцентом на інклюзію, особливо для молоді з інвалідністю та тих, хто перебуває в соціальному ризику.

Учасники розвивають фізичну координацію, впевненість у собі та самовираження через такі види діяльності, як жонглювання, акробатика та балансування. Важливо, що Lolly Jar Circus забезпечує привітне, чутливе до сенсорних потреб та адаптивне до різноманітних стилів навчання середовище. Їхні тренери спеціально навчені обізнаності щодо інвалідності, практикам, що враховують травму, та комунікаційним стратегіям для нейрорізноманітних учасників.

Організація активно сприяє інклюзії братів і сестер, дозволяючи дітям з інвалідністю та без неї навчатися та грати разом на одних заняттях. Окрім регулярних занять, вони також проводять виїзні майстер-класи у спеціальних школах, закладах для людей з інвалідністю та віддалених громадах, роблячи цирк доступним для тих, хто інакше міг би бути виключеним.
