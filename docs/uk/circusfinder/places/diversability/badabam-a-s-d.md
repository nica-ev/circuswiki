# BadaBam A.S.D.

Ця організація сприяє інклюзивним цирковим програмам у школах та спеціалізованим курсам для молоді з інвалідністю, співпрацюючи з кооперативами та психологами. Вона полегшує шляхи інтеграції, починаючи з індивідуальних занять або занять у малих групах, перш ніж перевести учасників до загальних класів. Спеціалізуючись на повітряних дисциплінах, організація адаптує всі циркові мистецтва до індивідуальних здібностей, зосереджуючись переважно на дітях та підлітках для сприяння розвитку, інклюзії та самовираження.
