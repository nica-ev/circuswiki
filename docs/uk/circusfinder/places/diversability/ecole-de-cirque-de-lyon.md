# Циркова школа Ліона

Циркова школа Ліона прагне зробити циркове мистецтво доступним для людей з інвалідністю через свою програму "Handi-cirque". Ця ініціатива пропонує індивідуальні майстер-класи та адаптовані курси, розроблені для задоволення унікальних потреб як дітей, так і дорослих, забезпечуючи інклюзивне та підтримуюче середовище для вивчення циркових дисциплін. Школа тісно співпрацює з різними установами, включаючи будинки-інтернати, медико-освітні інститути та терапевтично-освітні центри, для розробки індивідуальних проєктів та ознайомчих майстер-класів. Інтегруючи людей з інвалідністю до своїх звичайних занять та канікулярних майстер-класів, Циркова школа Ліона сприяє соціальній інклюзії та особистісному розвитку через циркове мистецтво.
