# LuneNUOVE

Кооператив LUNEnuove, що базується в Centro Armonico Terapeutico (CAT), працює у сфері соціальної опіки з 2002 року. Він зосереджується на освіті, терапії, навчанні та дослідженнях для людей будь-якого віку, сприяючи соціальній справедливості, інклюзії та добробуту в гармонії з природою та тваринами. Кооператив реалізує два основні проєкти: пет-терапію та освітні заходи для людей з інвалідністю, а також навчальні курси з його цілісного підходу, який інтегрує природу, догляд за тваринами, музикотерапію, йогу, арт-терапію тощо. CAT присвячений проведенню заходів на свіжому повітрі для людей з інвалідністю та інклюзивних громадських майстер-класів.
