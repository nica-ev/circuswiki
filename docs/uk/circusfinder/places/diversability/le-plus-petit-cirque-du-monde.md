# Найменший цирк світу

Найменший цирк світу (PPCM), розташований у Баньо, Франція, присвячений сприянню соціальної інклюзії через циркове мистецтво. Їхні ініціативи включають спеціалізовані майстер-класи для осіб з когнітивними порушеннями або психологічними розладами, такими як аутизм.

Ці майстер-класи зосереджені на психомоторному розвитку та проводяться у співпраці з медичними працівниками, щоб гарантувати відповідність специфічним потребам кожної групи. Заняття зазвичай проводяться щотижня, тривають одну годину на групу, а тривалість програм варіюється від десяти занять до повного року. Підхід PPCM наголошує на адаптивності, забезпечуючи доступність заходів для всіх учасників, незалежно від їхніх рухових чи когнітивних викликів.
