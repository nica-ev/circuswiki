# Acirkaos Circo Social

ACIRKAOS Circo Social, що базується на Менорці, Іспанія, є неприбутковою організацією, яка займається просуванням циркового мистецтва як інструментів для освіти, соціальної інтеграції та розвитку громади. Їхній комплексний педагогічний підхід заохочує учасників відкривати для себе цирк через гру, стимулюючи уяву, фізичні навички та виконавське мистецтво, водночас наголошуючи на вихованні цінностей для дітей, молоді та дорослих.

Ключовим напрямком діяльності ACIRKAOS є їхня відданість інклюзивності, особливо через програми, розроблені для людей з інвалідністю. Організація проводила майстер-класи для Фонду осіб з інвалідністю Менорки (Fundación de Personas con Discapacidad de Menorca), демонструючи свою відданість інтеграції людей з інвалідністю у свою діяльність.

ACIRKAOS також організовує Європейські зустрічі соціального цирку (European Social Circus Encounters), які об'єднують молодіжних працівників з різних країн для обміну досвідом та методологіями у сфері соціального цирку. Ці заходи включають семінари, майстер-класи та вистави, створюючи атмосферу навчання та культурного обміну.
