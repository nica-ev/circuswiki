# Варіете Соціале / Центр психічного здоров'я Пльзень, Ледовець

Варіете Соціале — це соціальна циркова ініціатива від Ledovec, z.s., спрямована на дестигматизацію та деінституціоналізацію через інтерактивні виступи. Спираючись на свій багаторічний досвід роботи з проєктом Cirkus Paciento у психіатричних лікарнях та соціальних службах, вони пропонують спільні вистави на циркову тематику, які активно залучають як користувачів послуг, так і персонал. Ці виступи розроблені для того, щоб оживити рутину, розвинути креативність та представити організації у новому світлі для громадськості. Наголошуючи на терапевтичних перевагах, учасників заохочують досліджувати ролі, що виходять за межі традиційних ідентичностей пацієнта чи персоналу, що призводить до взаємного відкриття прихованих талантів та здібностей. Варіете Соціале доступне для заходів у психіатричних лікарнях, стаціонарних та амбулаторних соціальних службах, особливо під час фестивалів чи днів відкритих дверей, що об'єднують людей з обмеженими можливостями з ширшою спільнотою. Їхній гнучкий підхід дозволяє швидко створювати вистави або проводити тривалі заходи для глибшого терапевтичного досвіду, забезпечуючи відповідність кожної вистави конкретним потребам приймаючої служби. Фінансова підтримка від таких організацій, як Міністерство культури та фонд Život umělce, забезпечує доступність для більшості служб.
