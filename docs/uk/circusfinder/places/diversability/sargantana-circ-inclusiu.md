# Sargantana Circ Inclusiu

Sargantana Circ Inclusiu, заснована у 2022 році Сезаром Гарсіа Пересом, сприяє інклюзивності через сучасний цирк. Компанія поєднує цирк, театр, танець, живу музику та магію для створення міждисциплінарних вистав.

Ключова ініціатива "Finestra Inclusiva", започаткована у 2014 році, використовує соціальний цирк для залучення осіб з функціональними відмінностями та молоді, яка перебуває під загрозою виключення. Учасники тренуються в клоунаді, акробатиці, балансуванні та жонглюванні, що завершується публічними виступами. Проєкт співпрацював з понад 20 асоціаціями, підтримуючи людей з аутизмом, психічними захворюваннями та тих, хто проходить реабілітацію від залежностей. Він отримав нагороди за свій вплив.

Окрім соціальних проєктів, Sargantana Circ Inclusiu організовує фестиваль Valencirc та надає консультаційні послуги. Їхня робота сприяє інклюзивності та мистецьким інноваціям у цирковому світі.
