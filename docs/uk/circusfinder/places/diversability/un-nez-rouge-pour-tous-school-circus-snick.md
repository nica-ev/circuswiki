# Червоний Ніс для Всіх / Шкільний Цирк "Снік"

"Червоний Ніс для Всіх" зосереджується на інтеграції людей з інвалідністю у виконавське мистецтво, зокрема через циркові вистави. Їхні постановки мають на меті стерти межі між виконавцями без інвалідності та тими, хто має інвалідність, створюючи середовище, де відмінності приймаються та відзначаються. Одна з їхніх помітних вистав, "EVOLUTION", є прикладом цієї місії, представляючи різноманітний акторський склад, який демонструє мистецький потенціал інклюзивності. Завдяки таким ініціативам "Червоний Ніс для Всіх" не тільки надає платформу для виконавців будь-яких можливостей, але й підвищує обізнаність про цінність різноманітності у мистецтві.
