# MáSzínház

MáSzínház — це інклюзивна спільнота виконавських мистецтв в Угорщині, яка зосереджена на розвитку соціальних та творчих навичок учасників, особливо людей з інтелектуальними порушеннями. Через спільні мистецькі заняття вони допомагають розвивати здібності учасників та демонструвати ці таланти на публічних виступах, сприяючи видимості та прийняттю.

Організація проводить регулярні мистецькі майстер-класи, спрямовані на розвиток навичок та особистісне зростання. Окрім майстер-класів, вони також представляють інклюзивні театральні вистави, надаючи учасникам платформу для демонстрації своїх талантів. MáSzínház також пропонує освітні програми для шкіл, заохочуючи емпатію та розуміння серед учнів.

MáSzínház присвячує себе інтеграції молодих людей з інтелектуальними порушеннями у свої програми. Вони використовують техніки партисипаторного театру для сприяння соціальній взаємодії, впевненості та відчуття приналежності. Їхня місія наголошує на суспільстві, де кожного визначають його дії, а не обмеження.
