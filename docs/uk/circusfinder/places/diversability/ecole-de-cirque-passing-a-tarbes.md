# Циркова школа Passing у Тарбі

Passing — це циркова школа, заснована у 1999 році, яка пропонує доступні та ігрові циркові мистецтва для людей будь-якого віку та рівня підготовки. Керуючись цінностями поваги, довіри, співпраці та різноманіття, школа проводить тижневі майстер-класи, річні заняття та індивідуальні програми (наприклад, сімейні чи тематичні сесії), які запрошують кожного відкрити для себе жонглювання, акробатику, цирковий велосипед, повітряну гімнастику та багато іншого — без тиску виступів.

Їхні програми адаптуються до різноманітної аудиторії — шкіл, дитячих садків, спеціалізованих закладів, сімей та громадських груп — забезпечуючи інклюзивний досвід, що поважає індивідуальний ритм та творчість кожного. Завдяки сильному духу співпраці, Passing також оживляє цирк у містах Верхніх Піренеїв, таких як Вік-ан-Бігор, П'єрфіт-Несталас та Баньєр-де-Бігор, подорожуючи зі своїм обладнанням та поширюючи радість через спільну практику.

Через виступи за участю учнів, проєкти, що реалізуються спільнотою, та досвід у неконкурентній педагогіці, цирк Passing справді для всіх — він об'єднує людей, культури та можливості через мистецтво ігрового руху.
