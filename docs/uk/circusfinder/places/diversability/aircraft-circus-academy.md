# Циркова академія AirCraft

Циркова академія AirCraft, член FEDEC, пропонує циркові заняття та майстер-класи для будь-якого віку та рівня підготовки, включно зі спеціалізованими заняттями для осіб з особливими освітніми потребами (ООП). Тут навчають повітряній акробатиці (на полотнах, кільці, трапеції), жонглюванню, хула-хупам, поі, обертанню тарілок і ходінню по канату. Їхні програми розроблені як для людей, що сидять, так і для тих, хто може рухатися, включно з особами з інвалідністю, деменцією та хворобою Паркінсона. Заняття можуть бути адаптовані до потреб учасників, пропонуючи групові уроки, одноразові майстер-класи або індивідуальні заняття.
