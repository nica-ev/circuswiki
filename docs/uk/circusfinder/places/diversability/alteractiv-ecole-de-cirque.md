# AlterActiv, Циркова Школа

AlterActiv — це мультикультурна спортивна асоціація, яка пропонує різноманітні програми, зокрема циркове мистецтво та бойові мистецтва. Їхня Циркова Школа проводить щорічні курси, вікенди та канікулярні майстер-класи для людей будь-якого віку. Окрім загальної циркової підготовки, AlterActiv прагне до інклюзивності через свою програму "Handi Cirque - Cirque Adapté". Ця ініціатива пропонує адаптовані циркові курси, спеціально розроблені для дітей з інвалідністю, з урахуванням тих, хто може потребувати присутності батьків під час занять. Програма спрямована на створення інклюзивного середовища, де діти з інвалідністю можуть досліджувати та насолоджуватися цирковим мистецтвом разом зі своїми однолітками.
