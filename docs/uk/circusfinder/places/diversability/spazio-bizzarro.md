# Spazio Bizzarro

Spazio Bizzarro, заснований у 2012 році Асоціацією Tra Le Nuvole, є центром сучасного цирку, розташованим у Касатеново, Лекко, Італія. Він слугує культурним осередком, пропонуючи курси, майстер-класи та мистецьку підготовку з різних циркових дисциплін для дітей, підлітків та дорослих.

Навчальна програма центру охоплює широкий спектр дисциплін, зокрема повітряну акробатику, жонглювання, балансування, клоунаду, танці, спів та театр. Ці програми спрямовані на розвиток креативності, самовираження та фізичної форми учасників.

Spazio Bizzarro відданий інклюзивності та соціальній взаємодії, активно сприяючи різноманіттю через діяльність, яка залучає всіх людей, забезпечуючи можливість участі для кожного. Вони пропонують спеціалізовані програми, такі як курси соціального цирку, розроблені для залучення осіб з інвалідністю та тих, хто походить з незахищених верств населення, використовуючи циркове мистецтво як засіб соціальної інтеграції та особистісного розвитку.

Окрім регулярних курсів, Spazio Bizzarro організовує освітні проєкти для шкіл, надаючи учням практичний досвід у цирковому мистецтві через майстер-класи та керовані заходи. Вони також проводять літні табори та професійні тренінги з повітряних дисциплін, за підтримки Міністерства культури та схвалення Асоціації сучасного цирку Італії (ACCI).
