# Імхотеп Сірк

«Імхотеп Сірк» (Imhotep Cirque), заснований у 1987 році та розташований у Вілленав-д'Орнон, Франція, займається популяризацією циркового мистецтва для людей з інвалідністю. Їхні спеціалізовані майстер-класи призначені для дітей та дорослих з ментальними (наприклад, аутизм, синдром Дауна, інтелектуальні порушення), фізичними та сенсорними особливостями. Основні цілі цих програм — розвиток самовираження, підвищення самооцінки, сприяння співпраці та створення безпечного, неконкурентного середовища для учасників, де вони можуть досліджувати циркові види діяльності. Заняття проводять досвідчені та сертифіковані інструктори в доступних приміщеннях, обладнаних різноманітним цирковим реквізитом. Співпраця з установами, що звертаються за послугами, гарантує, що кожна програма адаптована до конкретних потреб учасників, з невеликими групами та відповідною тривалістю занять для максимального залучення та користі.
