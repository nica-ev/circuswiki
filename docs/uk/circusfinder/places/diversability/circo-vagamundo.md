# Circo VagaMundo

Circo VagaMundo, що базується в Алжезурі, Португалія, є соціальним та освітнім цирком, який рішуче відданий інклюзії через циркове мистецтво. Організація вірить, що кожен, незалежно від здібностей, повинен мати доступ до творчого самовираження, особистісного розвитку та зв'язку зі спільнотою через цирк. З 2014 року Circo VagaMundo реалізує кілька цільових проєктів для молоді з інвалідністю, співпрацюючи з місцевими та міжнародними партнерами.

Організація розробляє інклюзивні майстер-класи, адаптовані до потреб молоді з фізичними, інтелектуальними або розладами розвитку. Ці майстер-класи досліджують циркові техніки, такі як жонглювання, балансування, акробатика та клоунада, використовуючи підхід, що наголошує на індивідуальних здібностях, співпраці та веселощах. Circo VagaMundo співпрацював з такими установами, як APPADM, Escolhas (São Teotónio) та терапевтичними організаціями, пропонуючи регулярні інклюзивні заняття та публічні виступи.

Інтегруючи учасників з інвалідністю та без неї у свої заходи, Circo VagaMundo сприяє розвитку емпатії, впевненості в собі та видимості для молоді з інвалідністю через радісну та надихаючу мову цирку.
