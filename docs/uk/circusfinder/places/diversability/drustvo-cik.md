# Товариство CIK

Асоціація CIK — це словенська громадська організація, яка зосереджується на роботі з молоддю та освіті через циркову педагогіку та соціальні ігри. Вона навчає молодіжних працівників, оснащуючи їх творчими методами для залучення молоді та одночасно сприяючи психічному благополуччю. Циркова педагогіка поєднує сучасний цирк, театр та ігри для розвитку командної роботи, довіри та стійкості. Соціальні ігри заохочують самоусвідомлення та розглядають соціальні проблеми. CIK також сприяє психічній гігієні, міжнародній мобільності та європейській співпраці. Вона проводить майстер-класи, вистави та професійні консультації, прагнучи розвивати циркову педагогіку в Словенії та за її межами.
