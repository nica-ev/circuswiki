# Асоціація Graine de Cirque

Graine de Cirque — це відома циркова школа, заснована у 1990 році. Школа пропонує різноманітні програми, спрямовані на популяризацію та викладання циркового мистецтва для людей будь-якого віку та рівня підготовки.

Важливим аспектом місії Graine de Cirque є її відданість інклюзивності. Організація пропонує адаптовані циркові майстер-класи, спеціально розроблені для людей з інвалідністю, забезпечуючи доступність для тих, хто має фізичні та ментальні особливості. Ці індивідуальні програми спрямовані на сприяння особистісному розвитку, творчості та соціальній інтеграції через заняття цирковим мистецтвом. Приміщення обладнані пандусами та доступними туалетами для зручності учасників з порушеннями мобільності.

Graine de Cirque співпрацює зі школами, дозвіллєвими центрами та спеціалізованими установами для реалізації освітніх проєктів та інтервенцій як на своїй території під шатрами, так і поза її межами у різних закладах. Ця діяльність підкреслює їхню відданість тому, щоб зробити циркове мистецтво доступним для широкої аудиторії, включно з тими, хто проживає у малозабезпечених громадах.
