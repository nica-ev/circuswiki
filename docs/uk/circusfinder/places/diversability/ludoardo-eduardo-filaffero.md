# Ludoardo (Едуардо Філафферо)

Едуардо пропонує циркові заняття для молоді з інвалідністю. Він проводить індивідуальні заняття, групові майстер-класи та навчання інструкторів, зосереджуючись на людях з фізичними та когнітивними порушеннями, розладами навчання та психологічними викликами. Заняття варіюються від освітніх програм до тімбілдингу та виступів, використовуючи функціональне жонглювання та адаптовані циркові мистецтва для сприяння інклюзії, особистісному зростанню та соціальним зв'язкам.
