# Teatrazione ASDC School Of Circus Theater / CircUsAbility

TeatrAzionE — це школа циркової вистави, розташована в Турині, Італія, яка пропонує широкий спектр циркових курсів та виступів для будь-якого віку. Окрім загальної підготовки з повітряної акробатики, жонглювання, балансування, наземної акробатики та клоунади, школа проводить спеціалізовані адаптовані циркові програми, розроблені для людей з інвалідністю. До них входять цільові майстер-класи для людей з фізичними, інтелектуальними, психологічними чи сенсорними порушеннями, а також розладами нейророзвитку.

TeatrAzionE також приділяє значну увагу підготовці майбутніх циркових педагогів, особливо у сфері інклюзивного та адаптованого циркового мистецтва, оснащуючи їх навичками для роботи з різними групами населення. Їхній інклюзивний підхід гарантує, що цирк стає інструментом самовираження, розширення можливостей та соціальної інтеграції для людей з будь-якими здібностями. Через свою освітню та мистецьку діяльність TeatrAzionE просуває бачення цирку як трансформаційного, доступного та творчого досвіду для всіх.
