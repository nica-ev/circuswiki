# Циркова школа Ball'istik

Циркова школа Ball'istik через свою програму "Handicirque" прагне зробити циркове мистецтво доступним для людей з інвалідністю. Ця ініціатива спрямована на сприяння особистісному розвитку шляхом підвищення самостійності, виразності, креативності та соціальної взаємодії. Учасники опановують різноманітні циркові техніки, зокрема жонглювання, балансування, повітряну трапецію та акробатику, адаптовані до різних можливостей. Педагогічний підхід робить акцент на толерантності, пропонуючи різноманітні та відкриті заняття, де пріоритетом є довіра, повага та задоволення від процесу, а не результат виступу.
