# Circo all'inCirca

Circo all'inCirca — це сучасна циркова асоціація з Удіне, Італія, яка займається популяризацією та розвитком циркового мистецтва через різноманітні культурні заходи, виступи та освітні програми. Вони пропонують курси для дітей, підлітків та дорослих, зосереджуючись на таких дисциплінах, як акробатика, жонглювання, повітряна гімнастика та техніки балансування.

У співпраці з "La Nostra Famiglia" Circo all'inCirca започаткувала проєкт "Circo Adattato" (Адаптований цирк), спрямований на забезпечення доступності циркового мистецтва для осіб з особливими освітніми потребами та інвалідністю. Ця ініціатива передбачає вивчення та адаптацію циркових дисциплін і обладнання для освітніх закладів, де беруть участь особи з інтелектуальними та/або фізичними вадами. Проєкт зосереджений на створенні прототипів та матеріалів, які дозволяють особам з різними видами інвалідності відчути емоції, пов'язані з цирковими заняттями, такі як баланс, підвішування та гнучкість. Кінцева мета — сприяти інклюзивності та особистісному розвитку через індивідуалізований цирковий досвід.

Прагнення Circo all'inCirca до інклюзивності поширюється на організацію фестивалів та соціальних проєктів, які заохочують мистецький обмін між молодими професіоналами, компаніями, студентами та ентузіастами. Їхні зусилля сприяють ширшому розумінню та оцінці сучасного цирку як інструменту соціальної інтеграції та мистецького самовираження.
