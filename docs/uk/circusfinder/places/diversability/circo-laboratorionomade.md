# Circo Laboratorio Nomade

Circo Laboratorio Nomade, заснована у 2009 році в Кріспіано, Таранто, Італія, присвячена розвитку особистості через поєднання спорту та мистецтва. Організація пропонує різноманітні програми, що охоплюють такі види діяльності, як польоти, жонглювання, стрибки, перевертання та скелелазіння, спрямовані на колективний розвиток.

Значна увага в їхній роботі приділяється ініціативам соціального цирку, використовуючи циркове мистецтво як інноваційні інструменти для освіти та соціальної інтеграції. Ці програми спеціально розроблені для підтримки дітей, молоді та дорослих з інвалідністю або тих, хто переживає економічні труднощі, сприяючи інклюзивності та розширенню можливостей через творче самовираження.
