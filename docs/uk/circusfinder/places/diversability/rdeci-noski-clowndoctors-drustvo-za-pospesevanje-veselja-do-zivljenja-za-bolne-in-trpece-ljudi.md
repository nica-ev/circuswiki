# Червоні Носики — Клоун-лікарі, організація для підтримки радості життя хворих та стражденних людей

«Червоні Носики» (Rdeči Noski) — це словенська громадська організація, член Red Noses International, що діє на національному рівні. Її місія — дарувати сміх та радість тим, хто її потребує, зосереджуючись на візитах клоунів до лікарень, закладів для догляду за літніми людьми та установ спеціальної освіти. Їхня програма «Pester orkester» включає «Naša draga škatla» («Наша дорога скринька») — виставу, адаптовану для дітей та дорослих з інтелектуальними порушеннями. Використовуючи імпровізацію, фізичну комедію та інтерактивну взаємодію, їхні професійні клоуни підтримують та налагоджують зв'язок з аудиторією. У 2023 році вони провели 35 вистав «Naša draga škatla» для людей з особливими потребами.
