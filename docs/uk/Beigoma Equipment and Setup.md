> [!info] Резюме
> Для бейґоми потрібно лише кілька предметів, але кожен з них важливий: металевий дзиґа, підготовлена мотузка, тканинний ігровий майданчик та достатньо місця навколо нього для безпечних кидків.

## **Основне обладнання**:

### Дзиґи Бейґома

Бейґома — це маленькі металеві дзиґи, що обертаються. Для новачків та змішаних груп спочатку використовуйте звичайні, немодифіковані дзиґи. Це підвищує фактор удачі та зменшує перевагу досвідчених гравців з налаштованим обладнанням.

Для просунутої гри гравці можуть використовувати модифіковані дзиґи. Їх можна налаштувати для тривалого обертання, сильнішого удару або більшої маневреності на майданчику.

### Мотузки

Мотузки для бейґоми тонкі й потребують вузлів, оскільки дзиґа не має центрального стрижня. У поширеній початковій конфігурації використовують два вузли близько один до одного біля одного кінця мотузки. Кінчик бейґоми розташовується між цими вузлами на початку намотування.

Тримайте напоготові запасні мотузки. Мотузки зношуються, брудняться або швидко губляться в умовах майстерні.

### Ігровий майданчик / юка

Ігровий майданчик зазвичай являє собою міцну тканину, натягнуту на відро, бочку або низьку раму. Тканина має бути достатньо тугою, щоб утримувати дзиґи, але сформованою з невеликим заглибленням, щоб дзиґи рухалися до центру, а не одразу котилися геть.

Для публічних майстерень одного майданчика рідко буває достатньо. Кілька менших майданчиків скорочують час очікування та полегшують поділ новачків від досвідчених гравців.

### Матеріали для підрахунку очок

Структуровані ігри потребують наочних матеріалів для підрахунку очок. Залежно від формату, використовуйте:

- індивідуальні картки для запису очок
- блокові картки для запису очок
- турнірні таблиці
- сітки турнірів
- командні картки
- ручки або маркери, прикріплені до ігрової станції

## **Налаштування майстерні**:

Розмістіть майданчик на стійкій поверхні, де люди можуть стояти навколо нього, не створюючи натовпу. Зберігайте невелику буферну зону навколо майданчика, оскільки металеві дзиґи можуть вистрибувати під час зіткнень.

Для відкритих заходів розділіть простір на три зони:

- **Зона практики**: намотування та перші кидки без підрахунку очок.
- **Ігрова зона**: структуровані матчі для гравців, які вже вміють кидати.
- **Зона налаштування або декорування**: опціональний стіл для персоналізації або модифікації дзиґ.

## **Примітки для фасилітатора**:

Почніть зі звичайних дзиґ та простих правил. Додавайте модифіковані дзиґи, формати підрахунку очок або турнірні структури лише після того, як група зрозуміє базовий кидок.

Для дітей зробіть пояснення коротким і дозвольте їм швидко спробувати. Бейґома стає зрозумілою через повторні спроби, а не через довгі словесні інструкції.
