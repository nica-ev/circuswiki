> [!info] Короткий опис
> Гра на витривалість із великою кількістю предметів для жонглерів, що використовують сім булав.

![[../img/7-club-endurance.jpg|300]]

**Кількість гравців**: від 2 до 30
**Складність**: висока
**Матеріал**: Сім булав для жонглювання на кожного гравця
**Тривалість**: приблизно 3–15 хвилин

## Опис гри

Гравці намагаються якомога довше утримувати в повітрі сім булав. Перемагає той, хто продемонструє найдовший підтверджений час без помилок.

## Підготовка

- Використовуйте дуже відкритий простір із чітким розмежуванням між жонглерами.
- Визначте старт: одночасний старт, стартове вікно або індивідуальні спроби.
- Призначте суддів або використовуйте відеозапис, якщо точний час має вирішальне значення.

## Правила

1. Гравці розпочинають жонглювання сімома булавами відповідно до узгодженого правила старту.
2. Спроба триває доти, доки гравці утримують сім булав у визначеному візерунку.
3. Падіння, збирання, перезапуск або зменшення кількості булав до менш ніж семи завершує спробу.
4. Переможцем стає гравець із найдовшою безперервною підтвердженою спробою.
5. Якщо кілька гравців перевищують часовий ліміт, проведіть фінал або оголосіть спільних переможців.

## Варіанти

- Використовуйте індивідуальні спроби для безпеки та чіткішого суддівства.
- Проведіть версію майстер-класу для встановлення особистих рекордів.
- Для просунутого підрахунку балів вимагайте чистого збирання булав після завершення спроби.

## Заходи безпеки

Ця гра призначена лише для досвідчених жонглерів. Жонглювання сімома булавами потребує значної висоти та простору для маневру.
