> [!info] Короткий опис
> Гра на витривалість з великою кількістю предметів для жонглерів, що використовують сім булав.

![7-club-endurance](../img/7-club-endurance.jpg){ width=300 }

**Кількість учасників**: від 2 до 30 гравців
**Складність**: висока
**Матеріал**: Сім булав для жонглювання на кожного гравця
**Тривалість**: приблизно 3-15 хвилин

## Опис гри

Гравці намагаються якомога довше утримувати в повітрі сім булав. Перемагає той, хто продемонструє найдовший підтверджений час безперервного жонглювання.

## Підготовка

- Використовуйте дуже відкритий простір із чітким розмежуванням між жонглерами.
- Визначте правила старту: одночасний старт, стартове вікно або індивідуальні спроби.
- Призначте суддів або використовуйте відеозапис, якщо точний час є критично важливим.

## Правила

1. Гравці розпочинають жонглювання сімома булавами згідно з узгодженим правилом старту.
2. Спроба триває доти, доки гравці утримують сім булав у визначеному патерні.
3. Втрата булави, збирання, перезапуск або зменшення кількості булав до менш ніж семи завершує спробу.
4. Переможцем стає гравець, який показав найдовший безперервний підтверджений час жонглювання.
5. Якщо кілька гравців перевищують ліміт часу, проведіть фінал або оголосіть спільних переможців.

## Варіації

- Використовуйте індивідуальні спроби для безпеки та чіткішого суддівства.
- Проведіть версію для майстер-класу з особистими рекордами.
- Для просунутого підрахунку балів вимагайте чисте збирання булав після завершення спроби.

## Заходи безпеки

Ця гра призначена виключно для досвідчених жонглерів. Жонглювання сімома булавами вимагає значної висоти та простору для маневру.
