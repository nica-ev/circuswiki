> [!info] Короткий опис
> Формат нарахування очок для бейґоми для індивідуальної або командної гри, де різні типи перемог приносять різну кількість балів.

**Розмір групи**: 2–40 осіб
**Складність**: Середня
**Матеріали**: Бейґома, мотузки, ігровий майданчик, бланк для запису результатів, ручки
**Тривалість**: 10–15 хвилин на матч

## **Опис гри**:

«Матч за очками» можна грати як індивідуальну гру або як командну. Основна ідея полягає в тому, що різні види перемог мають різну вартість у балах. Це спонукає до тактичних рішень під час матчу: ризикована атака «хаджікі» може коштувати більше, ніж безпечна перемога «рікі».

Для командної гри створіть команди з 2–4 гравців. Намагайтеся якомога рівномірніше розподілити досвідчених гравців та новачків. Двоє гравців від кожної команди стають навколо майданчика, тож одночасно кидають чотири гравці.

Після кожного раунду запишіть бали для команди-переможниці у бланку для запису результатів і змінюйте гравців, якщо команда складається з більш ніж двох учасників. Перша команда, яка досягне узгодженої цільової кількості очок, перемагає. Tokyo Beigoma пропонує 15 балів як можливу ціль.

Для індивідуальної гри використовуйте той самий основний процес без ротації команди. Заздалегідь визначте, як будуть нараховуватися бали за промахи майданчика та особливі ситуації.

## **Нарахування очок**:

Приклад командного підрахунку очок:

- Перемога команди «хаджікі»: 7 балів
- Перемога «хаджікі»: 5 балів
- Перемога «рікі»: 3 бали
- Нічия або «паккан»: 1 бал для кожної сторони

Нижчі значення балів роблять матч довшим. Вищі значення роблять кожен раунд більш вирішальним.

## **Правила**:

- Змінюйте членів команди після нарахування очок, коли команди складаються з більш ніж двох гравців.
- Якщо всі промахнулися майданчиком, переграйте з тими ж гравцями.
- Якщо протилежні дзиґи ніколи не торкаються згідно з правилами, що вимагають контакту, переграйте з тими ж гравцями.
- Дотримуйтесь вказівок судді або організатора, якщо результат незрозумілий.

## **Варіанти**:

Використовуйте нижчі значення для майстер-класів, де групі потрібно більше повторних спроб.

Використовуйте індивідуальний підрахунок очок, коли гравців недостатньо для збалансованих команд.

## **Примітки**:

Це один із найефективніших форматів для груп зі змішаним рівнем навичок, оскільки система нарахування балів може винагороджувати як тактичні атаки, так і стабільне обертання.
