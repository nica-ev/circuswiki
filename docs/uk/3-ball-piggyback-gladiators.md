> [!info] Короткий опис
> Варіант гри «Гладіатори» для команд, де один гравець, якого несе партнер, жонглює трьома м'ячами, поки інший переміщує його ареною.

![3-ball-piggyback-gladiators](../img/3-ball-piggyback-gladiators.jpg){ width=300 }

**Кількість гравців**: від 4 до 30
**Складність**: важка
**Матеріали**: три м'ячі для жонглювання на пару, розмічена арена
**Тривалість**: приблизно 5-10 хвилин

## Опис гри

Пари виходять на арену, де один гравець несе іншого на спині. Той, кого несуть, підтримує жонглювання трьома м'ячами, поки пари намагаються безпечно вибити інших учасників.

## Підготовка

- Сформуйте пари, отримавши чітку згоду на носіння.
- Розмітьте невелику арену та тримайте глядачів подалі від країв.
- Дуже суворо визначте допустимі втручання; найбезпечніший варіант — атакувати лише жонглювання, а не того, хто несе.

## Правила

1. Кожна пара починає з одного носія та одного жонглера, якого несуть.
2. За сигналом гравець, якого несуть, починає жонглювати трьома м'ячами, а носій рухається ареною.
3. Пари намагаються змусити інших жонглерів, яких несуть, впустити м'ячі, одночасно захищаючи власне жонглювання.
4. Пара вибуває, якщо жонглер впускає м'яч, пасажир падає, носій стає небезпечним або відбувається недозволений контакт.
5. Остання пара з активним жонглюванням трьома м'ячами перемагає.

## Варіанти

- Використовуйте правила без контакту та нараховуйте очки лише за витривалість.
- Дозвольте носіям мінятися після кожного раунду.
- Використовуйте жонглювання одним м'ячем для груп із різним рівнем підготовки.

## Заходи безпеки

Цю гру слід розглядати як гру для досвідчених учасників. Уникайте її з втомленими групами, на твердих підлогах або якщо пари не підходять одна одній для носіння.
