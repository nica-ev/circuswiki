# Képek

Ez egy 4-8 fős csoportoknak szánt tevékenység.

## I. szakasz

A csoportok felváltva 7 másodpercet kapnak arra, hogy testükkel „képet” alkossanak.

A jelszó lehet mindenki számára nyilvános, vagy titkos a többi csoport számára. Ez utóbbi esetben csoportos pantomimjátékot játszunk.

Példajelszavak:

- virágcserép
- virág
- esernyő
- autó
- asztal
- fésű
- turmixgép
- bögre
- tányér

## II. szakasz

3-7 másodperccel meghosszabbítjuk a visszaszámlálást. A cél és a szabályok ugyanazok, de a csoport használhat cirkuszi kellékeket.
