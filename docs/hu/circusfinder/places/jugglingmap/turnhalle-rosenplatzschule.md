# Turnhalle Rosenplatzschule

A Turnhalle Rosenplatzschule a közösség által fenntartott JugglingMap-en szerepel zsonglőr edzésként vagy zsonglőr klubként.

Helyszín a forrás által megadva: Spichernstraße, Osnabrück, Niedersachsen, Németország

## Zsonglőr edzés vagy zsonglőr klub

A bejárat a Rosenplatz iskola mögött található, a 11-es színpaddal szemben.
Egy akrojóga csoporttal együtt zsonglőrködünk.
Lehetőség van légtornász eszközök felfüggesztésére.

Menetrend a forrás által megadva: Szerda 20:00–22:00

Hozzáférés: ingyenes
