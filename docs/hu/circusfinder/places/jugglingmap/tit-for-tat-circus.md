# Tit for Tat Circus

A Tit for Tat Circus a közösség által fenntartott JugglingMap-en szerepel zsonglőr edzőhelyként vagy zsonglőr klubként.

Helyszín a forrás által megadottan: Mivart Studios, Mivart Street, Bristol, Anglia, Egyesült Királyság

## Zsonglőr Edzőhely vagy Zsonglőr Klub

A Tit for Tat vándorcirkusz-színház társulatának központja. Próbatermek bérelhetők, alacsony költségű edzési díjakkal művészek számára, amikor nincsenek lefoglalva. Tagsági rendszerek is elérhetők edzésre.

Elérés: korlátozott: lépjen velünk kapcsolatba az info@titfortatcircus.com címen.
