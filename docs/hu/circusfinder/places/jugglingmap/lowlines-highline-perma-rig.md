# Lowlines (Highline perma rig)

A Lowlines (Highline perma rig) a közösség által fenntartott JugglingMap-en szerepel zsonglőr edzőhelyként vagy zsonglőr klubként.

Helyszín a forrás által megadva: Museumpark Orientalis, 2, Profetenlaan, Heilig Landstichting, Gelderland, Nederland

## Zsonglőr edzőhely vagy zsonglőr klub

Ez a Lowlines kollektíva (akik zsonglőrködéssel is foglalkoznak egy kicsit) highline edzőhelye.
Kérjük, érkezés előtt vegye fel velünk a kapcsolatot, mert nem vagyunk ott minden nap.
Highline felszerelés: 70 méter Dyneema bungee-vel.

Elérés: korlátozott: Lépjen kapcsolatba a Lowlines-szal e-mailben vagy telefonon.

Kapcsolat a forrás által megadva:

Weboldal: https://lowlines.nl/ email: slackline@lowlines.nl

Linkek vagy közösségi fiókok a forrás által megadva:

https://www.instagram.com/lowlines_nl/
