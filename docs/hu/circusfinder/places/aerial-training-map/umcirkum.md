# UmCirkum

Az UmCirkum egy nyitott légtornász vagy cirkusz edzőhelyként szerepel a "Circus Gyms / Schools Around the World" (Cirkusz edzőtermek / iskolák világszerte) térképen, amely közösségi szerkesztésű.

Weboldal: [https://www.umcirkum.cz/](https://www.umcirkum.cz/)

## Forrás

Importálva a [Circus Gyms / Schools Around the World](https://datastudio.google.com/reporting/2ff68cae-8df4-46f2-b2e6-8ef6d0e328c1/page/Gj9BE) jelentésből, 2026-10-10-én. Csak a nyitottként megjelölt forrásbejegyzések kerültek közzétételre ebben a tételben. A térképen elfoglalt hely hozzávetőlegesnek tekintendő, mivel a koordináták egy közösségi szerkesztésű térképről származnak.
