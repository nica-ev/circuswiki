# Defy Gravity

A Defy Gravity egy nyílt légtorna vagy cirkuszoktatási helyszínként szerepel a "Circus Gyms / Schools Around the World" (Cirkusztermek / Iskolák a világ körül) crowdsourcing útján összegyűjtött térképen.

Weboldal: [https://defygravityph.com/](https://defygravityph.com/)

## Forrás

A "Circus Gyms / Schools Around the World" (Cirkusztermek / Iskolák a világ körül) jelentésből importálva, 2026-10-10-én. Csak a "nyílt" jelöléssel ellátott forrásbejegyzések kerülnek közzétételre ebben a tételben. A térképen szereplő helyzet hozzávetőlegesnek tekintendő, mivel a koordináták egy crowdsourcing útján összegyűjtött térképről származnak.
