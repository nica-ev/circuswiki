# Dance Studio Lite

A Dance Studio Lite egy nyílt légtorna vagy cirkusz edzőhelyként szerepel a "Circus Gyms / Schools Around the World" (Cirkusztermek / Iskolák a világ körül) közösségi térképen.

Weboldal: [http://lightdance163.ru/](http://lightdance163.ru/)

## Forrás

A "Circus Gyms / Schools Around the World" (Cirkusztermek / Iskolák a világ körül) jelentésből importálva, 2026-10-10-én. Ebben a közzétételben csak a nyíltként megjelölt forrásbejegyzések szerepelnek. A térképen jelölt hely csupán megközelítő értékű, mivel a koordináták egy közösségi térképről származnak.
