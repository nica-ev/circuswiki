# Inner Diva Studios

Az Inner Diva Studios egy nyitott légtorna vagy cirkusz-edzőhelyként szerepel a "Circus Gyms / Schools Around the World" (Cirkusztermek / Iskolák a világ körül) crowdsourcing útján összeállított térképen.

Weboldal: [https://innerdivastudios.com/](https://innerdivastudios.com/)

## Forrás

A "Circus Gyms / Schools Around the World" jelentésből importálva, 2026-10-10-én. Ebben a kötegben csak a nyitottként megjelölt forrásrekordok jelennek meg. A térképen elfoglalt hely hozzávetőlegesnek tekintendő, mivel a koordináták egy crowdsourcing útján összeállított térképről származnak.
