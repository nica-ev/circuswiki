# The Aerial House

A The Aerial House egy nyitott légtorna vagy cirkuszoktatási helyszínként szerepel a "Circus Gyms / Schools Around the World" (Cirkusztermek / Iskolák a világ körül) crowdsource módszerrel összeállított térképen.

Weboldal: [https://theaerialhouse.com](https://theaerialhouse.com)

## Forrás

A "Circus Gyms / Schools Around the World" jelentésből importálva, 2026-10-10-én. Ebben a közzétételben csak a nyitottként megjelölt forrásrekordok szerepelnek. A térképen jelölt helyszín hozzávetőlegesnek tekintendő, mivel a koordináták egy crowdsource módszerrel összeállított térképről származnak.
