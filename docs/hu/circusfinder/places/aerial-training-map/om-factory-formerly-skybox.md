# Om Factory (korábban SkyBox)

Az Om Factory (korábban SkyBox) egy nyitott légtorna vagy cirkusz edzőhelyként szerepel a "Circus Gyms / Schools Around the World" (Cirkusztermek / Iskolák a világ körül) gyűjtött adatbázisú térképen.

Weboldal: [http://www.omfactory.yoga/](http://www.omfactory.yoga/)

## Forrás

A "Circus Gyms / Schools Around the World" jelentésből importálva [itt](https://datastudio.google.com/reporting/2ff68cae-8df4-46f2-b2e6-8ef6d0e328c1/page/Gj9BE), 2026-10-10-én. Ebben a közzétételben csak a nyitottként megjelölt forrásrekordok szerepelnek. A térképen jelölt helyzet hozzávetőlegesnek tekintendő, mivel az adatok egy gyűjtött adatbázisú térképről származnak.
