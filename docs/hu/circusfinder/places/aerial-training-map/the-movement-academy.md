# A Mozgás Akadémia

A Mozgás Akadémia (The Movement Academy) a "Circus Gyms / Schools Around the World" (Cirkusztermek / Iskolák a Világban) térképen egy nyílt légtorna vagy cirkusz edzőhelyként szerepel.

Weboldal: [https://themovementacademy.com.au/](https://themovementacademy.com.au/)

## Forrás

A "Circus Gyms / Schools Around the World" jelentésből importálva, 2026.10.10-én. Ebben a közzétételben csak a nyíltként megjelölt forrásrekordok szerepelnek. A térképen elfoglalt hely hozzávetőlegesnek tekintendő, mivel a koordináták egy közösségi térképezésből származnak.
