# Athletic Playground

Az Athletic Playground egy nyitott légtorna vagy cirkusz-edzőhelyként szerepel a "Circus Gyms / Schools Around the World" (Cirkusz edzőtermek / iskolák világszerte) crowdsourcing útján összegyűjtött térképen.

Weboldal: [https://www.tapgym.com/](https://www.tapgym.com/)

## Forrás

A "Circus Gyms / Schools Around the World" jelentésből importálva, 2026-10-10-én. Ebben a közzétételben csak a nyitottként megjelölt forrásrekordok szerepelnek. A térképen jelölt hely csupán megközelítő értékű, mivel a koordináták egy crowdsourcing útján összeállított térképről származnak.
