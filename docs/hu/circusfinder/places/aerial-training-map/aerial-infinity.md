# Aerial Infinity

Az Aerial Infinity egy nyitott légtorna vagy cirkusz edzőhelyként szerepel a "Circus Gyms / Schools Around the World" (Cirkusztermek / Iskolák a világ körül) közösségi térképen.

Weboldal: [https://www.aerial-infinity.at/](https://www.aerial-infinity.at/)

## Forrás

A "Circus Gyms / Schools Around the World" jelentésből importálva, 2026-10-10-én. Csak a nyitottként megjelölt forrásrekordok kerültek közzétételre ebben a tételben. A térképen elfoglalt hely hozzávetőlegesnek tekintendő, mivel a koordináták egy közösségi térképről származnak.
