# Fly School Circus

A Fly School Circus egy nyitott légtorna vagy cirkuszművészeti képzési helyszínként szerepel a "Circus Gyms / Schools Around the World" (Cirkusztermek / Iskolák a világ körül) térképen, amelyet közösségi szerkesztéssel hoztak létre.

Weboldal: [http://www.flyschoolcircusarts.com/](http://www.flyschoolcircusarts.com/)

## Forrás

A "Circus Gyms / Schools Around the World" [jelentésből](https://datastudio.google.com/reporting/2ff68cae-8df4-46f2-b2e6-8ef6d0e328c1/page/Gj9BE) importálva, 2026-10-10-én. Ebben a közzétételben csak a nyitottként megjelölt forrásbejegyzések szerepelnek. A térképen jelölt helyzet hozzávetőlegesnek tekintendő, mivel a koordináták egy közösségi szerkesztésű térképről származnak.
