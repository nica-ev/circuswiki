# Freestyle Fitness

A Freestyle Fitness egy nyitott légtorna vagy cirkusz edzőhelyként szerepel a "Circus Gyms / Schools Around the World" (Cirkusztermek / Iskolák a világ körül) közösségi térképen.

Weboldal: [http://freestyle-fitness.co.uk/](http://freestyle-fitness.co.uk/)

## Forrás

Importálva a "Circus Gyms / Schools Around the World" jelentésből 2026-10-10-én. Ebben a kötegben csak a nyitottként megjelölt forrásrekordok jelennek meg. A térképen elfoglalt hely hozzávetőlegesnek tekintendő, mivel a koordináták egy közösségi térképről származnak.
