# Springfield Aerial Fitness

A Springfield Aerial Fitness egy nyitott légtorna- vagy cirkusztréning helyszínként szerepel a "Circus Gyms / Schools Around the World" (Cirkusztermek / Iskolák a Világban) crowdsourcing térképen.

Weboldal: [https://sgfaerialfitness.com](https://sgfaerialfitness.com)

## Forrás

A "Circus Gyms / Schools Around the World" jelentésből importálva 2026-10-10-én. Csak a nyitottként megjelölt forrásrekordok kerülnek közzétételre ebben a tételben. A térképen elfoglalt hely hozzávetőlegesnek tekintendő, mivel a koordináták egy crowdsourcing térképről származnak.
