# Atrium Space

Az Atrium Space egy nyitott légtorna vagy cirkusztréning helyszínként szerepel a "Circus Gyms / Schools Around the World" (Cirkusztermek / Iskolák a világ körül) térképen, amelyet közösségi szerkesztéssel hoztak létre.

Weboldal: [https://www.theatrium.space/](https://www.theatrium.space/)

## Forrás

A "Circus Gyms / Schools Around the World" jelentésből importálva, 2026-10-10-én. Ebben a kötegben csak a nyitottként megjelölt forrásrekordok jelennek meg. A térképen jelölt helyzet hozzávetőlegesnek tekintendő, mivel a koordináták egy közösségi szerkesztésű térképről származnak.
