# Skybound Aerial Arts Collective

A Skybound Aerial Arts Collective egy nyitott légtorna- vagy cirkuszpedagógiai képzési helyszínként szerepel a "Circus Gyms / Schools Around the World" (Cirkusztermek / Iskolák a világ körül) crowdsourcing útján gyűjtött térképen.

Weboldal: [https://skyboundaerial.com/](https://skyboundaerial.com/)

## Forrás

A "Circus Gyms / Schools Around the World" jelentésből importálva [2026-10-10](https://datastudio.google.com/reporting/2ff68cae-8df4-46f2-b2e6-8ef6d0e328c1/page/Gj9BE). Ebben a kötegben csak a "nyitott" jelöléssel ellátott forrásrekordok jelennek meg. A térképen jelölt pozíció hozzávetőlegesnek tekintendő, mivel a koordináták egy crowdsourcing útján gyűjtött térképről származnak.
