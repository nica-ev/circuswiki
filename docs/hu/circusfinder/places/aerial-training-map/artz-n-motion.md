# Artz 'N Motion

Az Artz 'N Motion egy nyitott légtorna vagy cirkuszoktatási helyszínként szerepel a "Circus Gyms / Schools Around the World" (Cirkusztermek / Iskolák a világ körül) gyűjtött adatokat tartalmazó térképen.

Weboldal: [https://artznmotion.com](https://artznmotion.com)

## Forrás

A "Circus Gyms / Schools Around the World" jelentésből importálva, 2026-10-10-én. Ebben a közzétételben csak a nyitottként megjelölt forrásrekordok szerepelnek. A térképen jelölt helyszín hozzávetőlegesnek tekintendő, mivel a koordináták egy közösségi gyűjtésű térképről származnak.
