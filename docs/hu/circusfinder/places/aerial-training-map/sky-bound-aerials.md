# Sky Bound Aerials

A Sky Bound Aerials egy nyitott légtorna vagy cirkuszoktatási helyszínként szerepel a "Circus Gyms / Schools Around the World" (Cirkusztermek / Iskolák a világ körül) térképen, amely közösségi alapon frissül.

Weboldal: [https://skyboundaerials.ca](https://skyboundaerials.ca)

## Forrás

A "Circus Gyms / Schools Around the World" jelentésből importálva, 2026-10-10-én. Csak a nyitottként megjelölt forrásrekordok kerültek közzétételre ebben a tételben. A térképen jelölt helyzet hozzávetőlegesnek tekintendő, mivel a koordináták egy közösségi alapú térképről származnak.
