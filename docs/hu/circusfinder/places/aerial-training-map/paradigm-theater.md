# Paradigm Theater

A Paradigm Theater egy légtornász vagy cirkuszos edzőhelyként szerepel a "Circus Gyms / Schools Around the World" (Cirkusz edzőtermek / iskolák világszerte) térképen, amelyhez az adatok közösségi gyűjtésből származnak.

Weboldal: [https://theparadigm.studio/](https://theparadigm.studio/)

## Forrás

A "Circus Gyms / Schools Around the World" [jelentésből](https://datastudio.google.com/reporting/2ff68cae-8df4-46f2-b2e6-8ef6d0e328c1/page/Gj9BE) importálva, 2026-10-10-én. Ebben a közzétételben csak a "nyílt" jelöléssel ellátott forrásbejegyzések szerepelnek. A térképen jelölt hely pontosnak csak megközelítőleg tekinthető, mivel a koordináták egy közösségi gyűjtésű térképről származnak.
