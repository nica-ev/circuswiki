# Urban Evolution

Az Urban Evolution egy nyitott légtorna vagy cirkusz-edzőhelyként szerepel a "Circus Gyms / Schools Around the World" (Cirkusztermek / Iskolák a Világban) térképen, amely crowdsourcing útján jött létre.

Weboldal: [https://www.urbanevo.com/](https://www.urbanevo.com/)

## Forrás

Importálva a "Circus Gyms / Schools Around the World" jelentésből 2026-10-10-én. Ebben a kötegben csak a "nyitott" jelöléssel ellátott forrásrekordok jelennek meg. A térképen elfoglalt hely hozzávetőlegesnek tekintendő, mivel a koordináták egy crowdsourcing útján összeállított térképről származnak.
