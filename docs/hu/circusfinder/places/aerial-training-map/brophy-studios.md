# Brophy Studios

A Brophy Studios egy nyitott légtorna vagy cirkuszoktatási helyszínként szerepel a "Circus Gyms / Schools Around the World" (Cirkusztermek / Iskolák a világ körül) térképen, amelyet közösségi összefogással hoztak létre.

Weboldal: [https://www.facebook.com/brophyaerialstudios](https://www.facebook.com/brophyaerialstudios)

## Forrás

A "Circus Gyms / Schools Around the World" jelentésből importálva, 2026-10-10-én. Ebben a közzétételben csak a nyíltként megjelölt forrásbejegyzések szerepelnek. A térképen jelölt helyzet hozzávetőlegesnek tekintendő, mivel a koordináták egy közösségi térképezésből származnak.
