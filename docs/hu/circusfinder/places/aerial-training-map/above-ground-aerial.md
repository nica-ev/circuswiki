# Above Ground Aerial

Az Above Ground Aerial egy nyitott légtorna vagy cirkuszoktatási helyszínként szerepel a "Circus Gyms / Schools Around the World" (Cirkusztermek / Iskolák a világ körül) közösségi térképen.

Weboldal: [https://www.abovegroundaerial.org/](https://www.abovegroundaerial.org/)

## Forrás

A "Circus Gyms / Schools Around the World" (Cirkusztermek / Iskolák a világ körül) jelentésből importálva, 2026-10-10-én. Csak a "nyitott" (open) jelölésű forrásbejegyzések kerültek közzétételre ebben a tételben. A térképen szereplő helyzet hozzávetőlegesnek tekintendő, mivel a koordináták egy közösségi térképről származnak.
