# Les Fortiches – Sommières-i cirkusziskola

A franciaországi Sommières-ben működő Les Fortiches cirkusziskola „Cirque Adapté” (Alkalmazkodó cirkusz) programot kínál, amely oktatási és terápiás eszközként szolgál testi vagy mentális fogyatékossággal élő személyek számára. Ez a kezdeményezés az egyéni és kollektív kísérletezésre összpontosít, célja pedig a résztvevők megerősítése a cirkuszművészetek sokszínű diszciplínáin keresztül. Minden projektet a Les Fortiches pedagógiai csapatával együttműködve dolgoznak ki, biztosítva egy személyre szabott megközelítést, amely a technikai teljesítmény helyett az egyéni fejlődést részesíti előnyben. Ez a módszertan specifikus értékeléseket foglal magában a résztvevők fejlődésének nyomon követésére és támogatására.
