# Juggling s šátky – základy

Juggling s šátky je díky pomalému letu (způsobenému vysokým odporem vzduchu) obzvláště vhodný pro naučení se základů žonglování s hody.

Často lze v krátké době dosáhnout úspěchu až k žonglování se 3 šátky.

Pro začátečníky je také velmi užitečné používat šátky různých barev, aby získali lepší přehled o tom, co se děje.
