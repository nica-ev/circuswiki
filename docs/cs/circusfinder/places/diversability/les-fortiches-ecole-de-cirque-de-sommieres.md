# Les Fortiches École de Cirque de Sommières

Les Fortiches, cirkusová škola sídlící ve francouzském Sommières, nabízí program „Cirque Adapté“. Tento program slouží jako vzdělávací a terapeutický nástroj pro osoby s tělesným nebo mentálním postižením. Tato iniciativa se zaměřuje na osobní a kolektivní experimentování s cílem posílit účastníky prostřednictvím rozmanitých cirkusových disciplín. Každý projekt je vyvíjen ve spolupráci s pedagogickým týmem Les Fortiches, což zajišťuje individuální přístup, který upřednostňuje osobní pokrok před technickým výkonem. Tato metodika zahrnuje specifická hodnocení pro sledování a podporu vývoje každého účastníka.
