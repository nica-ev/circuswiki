# AlterActiv, Cirkusová škola

AlterActiv je multikulturní a sportovní sdružení, které nabízí různé programy, včetně cirkusových a bojových umění. Jejich cirkusová škola pořádá každoroční kurzy, víkendová setkání a prázdninové workshopy pro lidi všech věkových kategorií. Kromě obecné cirkusové výuky se AlterActiv zavazuje k inkluzivitě prostřednictvím svého programu „Handi Cirque – Cirque Adapté“. Tato iniciativa nabízí upravené cirkusové kurzy speciálně navržené pro děti s postižením, které mohou vyžadovat přítomnost rodiče během lekcí. Program si klade za cíl vytvořit inkluzivní prostředí, kde si děti s postižením mohou spolu se svými vrstevníky objevovat a užívat cirkusová umění.
