# Tit for Tat Circus

Tit for Tat Circus je na komunitním serveru JugglingMap uveden jako místo pro trénink žonglování nebo jako žonglérský klub.

Místo podle zdroje: Mivart Studios, Mivart Street, Bristol, Anglie, Spojené království

## Trénink žonglování nebo žonglérský klub

Sídlo kočovné cirkusové divadelní společnosti Tit for Tat. K pronájmu jsou k dispozici zkušební prostory s nízkými cenami pro umělce, pokud nejsou plně obsazené. Nabízí se také členské programy pro trénink.
