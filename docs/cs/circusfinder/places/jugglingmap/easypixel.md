# EasyPixel

EasyPixel je na komunitním JugglingMapu uveden jako obchod s žonglovacími potřebami.

## Obchod s žonglovacími potřebami

EasyPixel je společnost specializující se na inovativní LED pixelové rekvizity pro flow artisty, performery a baviče. Navrhujeme a vyrábíme programovatelné LED rekvizity, které kombinují technologii, kreativitu a vizuální představení.
