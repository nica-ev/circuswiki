# NoFit State Circus

NoFit State Circus je na komunitním JugglingMapu uveden jako místo pro trénink žonglování nebo jako žonglérský klub.

Místo podle zdroje: NoFit State Community Circus, Four Elms Road, Cardiff, Cymru / Wales, Spojené království

## Trénink žonglování nebo žonglérský klub

Žonglérský klub se koná první a třetí úterý v měsíci.

Žonglování se vyučuje také na lekcích pro mládež a na komunitních workshopech.

Rozvrh dodaný zdrojem: Út 18:00–19:30

Vstupné: omezené: doporučený příspěvek 2 £ (1 £ pro znevýhodněné)
