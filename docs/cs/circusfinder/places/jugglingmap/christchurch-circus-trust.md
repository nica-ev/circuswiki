# Christchurch Circus Trust

Christchurch Circus Trust je na komunitně spravované mapě JugglingMap uveden jako centrum pro nácvik žonglování nebo žonglérský klub.

Rozvrh dodaný zdrojem: Út 19:15–20:45, St 18:00–20:00

Přístup: omezený: Prosím, přihlaste se online, zejména pokud máte zájem o závěsné místo. 7,50–15 $
