# NICA e.V. / Tohuwabohu Halle e.V.

NICA e.V. è una rete e un'organizzazione circense con sede a Halle (Saale). Sviluppa metodi circensi inclusivi, connette professionisti e organizzazioni e fornisce risorse per la pedagogia circense. Tohuwabohu Halle e.V. è l'organizzazione locale associata che si occupa delle attività circensi pratiche e della convention Tohuwabohu.

Il segnaposto indica l'indirizzo dell'ufficio pubblicato sul sito web ufficiale di NICA: Thüringer Straße 30, Haus 1, Eingang 2, Raum 206.
