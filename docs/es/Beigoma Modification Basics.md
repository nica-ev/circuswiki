> [!info] Resumen
> La modificación de un Beigoma no es solo para ganar. Es una forma de explorar el equilibrio, la fricción, el peso, el tiempo de giro, el comportamiento de ataque y la artesanía personal.

## **¿Por qué modificar un Beigoma?**:

Un Beigoma normal se puede usar de inmediato, pero los jugadores avanzados a menudo modifican las peonzas para cambiar su comportamiento. Tokyo Beigoma describe diferentes objetivos: mayor tiempo de giro, resistencia a ser derribado, movimiento más rápido o un acabado más pulido.

Para talleres, la modificación puede tratarse como una investigación de materiales. Los jugadores hacen un cambio, prueban el resultado, observan lo que sucedió y ajustan de nuevo.

## **Objetivos comunes**:

### Giro largo / Riki-goma

Un Riki-goma se ajusta para girar durante mucho tiempo. El trabajo se centra en encontrar y refinar el punto de giro y hacer que la rotación sea estable.

### Comportamiento de ataque / Hajiki

Una peonza estilo Hajiki es útil para derribar otras peonzas. Puede moverse más activamente por el suelo en lugar de permanecer quieta en el centro.

### Estabilidad

Eliminar las marcas de fundición ásperas y limpiar el punto de contacto puede hacer que la peonza se comporte de manera más predecible.

### Pulido y acabado

Algunas modificaciones son estéticas o táctiles. Tokyo Beigoma tiene ejemplos de pulido estilo espejo utilizando limas, papel de lija y pulimento para metales.

## **Herramientas típicas**:

- limas para metal
- limas finas
- papel de lija de varios granos
- paño para limpiar
- pulimento para metales (opcional)
- sargento, tornillo de banco u otro método de sujeción seguro para trabajos avanzados

## **Seguridad**:

El limado de metal crea bordes afilados y polvo. Utiliza protección ocular cuando sea apropiado, mantén las herramientas controladas y limpia el área de trabajo antes de volver a jugar.

No realices modificaciones con limas de metal con un grupo a menos que el facilitador pueda supervisar adecuadamente el uso de las herramientas.

## **Uso en talleres**:

Un ciclo útil para talleres es:

1. Haz girar una peonza sin modificar y obsérvala.
2. Haz un pequeño cambio.
3. Hazla girar de nuevo.
4. Compara el resultado.
5. Decide si continuar, detenerte o intentar un objetivo diferente.

Esto mantiene la actividad como una investigación en lugar de una competición pura.
