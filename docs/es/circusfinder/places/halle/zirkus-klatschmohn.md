# Circo Klatschmohn

El Circo Klatschmohn ofrece clases semanales durante todo el año para niños, jóvenes y adultos en sus carpas de circo climatizadas en Rossplatz. La oferta incluye, entre otras cosas, artes aéreas, acrobacia, equilibrio y malabares.

Es posible realizar una clase de prueba gratuita previa cita con la oficina del circo. Dado que muchas clases están completas, puede haber una lista de espera.
