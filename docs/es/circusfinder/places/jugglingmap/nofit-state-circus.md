# NoFit State Circus

NoFit State Circus aparece en JugglingMap, un mapa mantenido por la comunidad, como un club o centro de entrenamiento de malabares.

Ubicación proporcionada por la fuente: NoFit State Community Circus, Four Elms Road, Cardiff, Cymru / Gales, Reino Unido.

## Club o Centro de Entrenamiento de Malabares

El club de malabares se celebra el primer y tercer martes de cada mes.

Las clases para jóvenes y los talleres comunitarios también enseñan malabares.

Horario proporcionado por la fuente: Martes de 18:00 a 19:30.

Acceso: Donación sugerida de 2 £ (1 £ para estudiantes o personas con descuento).
