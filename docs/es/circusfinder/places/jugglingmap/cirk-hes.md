# Cirk Hes

Cirk Hes aparece en JugglingMap, mantenido por la comunidad, como una escuela de circo o taller de malabares.

Ubicación proporcionada por la fuente: Clodgey Lane, Helston, Inglaterra, Reino Unido.

## Escuela de Circo o Taller de Malabares

Cálido en invierno, luminoso y ventilado todo el año, con una altura de 6,5 a 8,2 metros. Suelo de colchonetas profesionales, con una base de hormigón pulido liso y nivelado debajo, lo que permite elegir entre diferentes superficies. Espacio de circo totalmente equipado, preparado para circo aéreo y acrobático, y para correr por las paredes, así como para todo tipo de malabares y Flow (sombreros, estrellas Dapo, poi, bastones, mazas, pelotas, aros, diábolo, palos chinos, cajas de cigarros, abanicos, banderas, Rola Bola, zancos, monociclos). El entrenamiento libre está disponible todo el año, excepto durante 2 semanas en Navidad.

Edades: 6–85
