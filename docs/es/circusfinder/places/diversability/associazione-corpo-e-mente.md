# Associazione Corpo E Mente

Este programa ofrece actividades circenses para jóvenes con discapacidades, centrándose en malabares y equilibrio mediante el método Quat Props y el enfoque educativo Circo Sfera. Atiende a personas con Parkinson, afasia, TDAH, necesidades educativas especiales (NEE) y autismo (especialmente Asperger). Las clases estructuradas se imparten dos veces por semana y abarcan acrobacias aéreas y de suelo, equilibrio y malabares, con sesiones personalizadas disponibles. El espacio es totalmente accesible, con rampas y acceso para sillas de ruedas para garantizar la inclusión de todos los participantes.
