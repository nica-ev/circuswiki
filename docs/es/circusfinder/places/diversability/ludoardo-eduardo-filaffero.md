# Ludoardo (Eduardo Filaffero)

Eduardo ofrece actividades circenses para jóvenes con discapacidad. Imparte sesiones individuales, talleres grupales y formación para instructores, centrándose en personas con discapacidades físicas y cognitivas, trastornos de aprendizaje y desafíos psicológicos. Las actividades abarcan desde programas educativos hasta creación de equipos y espectáculos, utilizando malabares funcionales y artes circenses adaptadas para promover la inclusión, el crecimiento personal y la conexión social.
