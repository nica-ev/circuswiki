# Les Fortiches École de Cirque de Sommières

Les Fortiches, escuela de circo ubicada en Sommières, Francia, ofrece un programa de "Cirque Adapté" diseñado para servir como herramienta educativa y terapéutica para personas con discapacidades físicas o mentales. Esta iniciativa se centra en la experimentación personal y colectiva, con el objetivo de empoderar a los participantes a través de las diversas disciplinas de las artes circenses. Cada proyecto se desarrolla en colaboración con el equipo pedagógico de Les Fortiches, garantizando un enfoque adaptado que prioriza el progreso individual sobre el rendimiento técnico. Esta metodología incluye evaluaciones específicas para monitorizar y apoyar la evolución de cada participante.
