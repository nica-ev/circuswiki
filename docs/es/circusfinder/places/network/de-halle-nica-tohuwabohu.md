# NICA e.V. / Tohuwabohu Halle e.V.

NICA e.V. es una red y organización de circo con sede en Halle (Saale). Desarrolla métodos de circo inclusivos, conecta a profesionales y organizaciones, y proporciona recursos para la pedagogía circense. Tohuwabohu Halle e.V. es la organización local asociada detrás de las actividades circenses prácticas y la convención Tohuwabohu.

El marcador muestra la dirección de la oficina publicada en el sitio web oficial de NICA: Thüringer Straße 30, Haus 1, Eingang 2, Raum 206.
