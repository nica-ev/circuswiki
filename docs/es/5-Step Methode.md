# Método de 5 Pasos

Enfoque funcional ![200](../img/5-Step.png#side_right)

## 1) **Conceptos antes que componentes**

Actividades de [[Tisch bzw. Körperjonglage]] para desarrollar la comprensión y la experiencia de la tarea. Esto también puede incluir el uso del [Juggleboard](Juggleboard.md) o dispositivos similares.

## 2) **Capacidad de secuenciación**

Secuencia [[Cow jumps over the moon]] para desarrollar la capacidad de secuenciación bilateral, necesaria para la sincronización de la cascada de 3 bolas.

Enfoque clásico ![200](../img/Classical%203-Step.png#side_left)

## 3) **Continuación clásica**

Práctica de lanzamientos con una, dos, tres bolas. Véase también los modelos clásicos de aprendizaje de malabares (aprendizaje lineal).
	
---

La principal diferencia con el modelo clásico es, por tanto, la introducción de dos nuevos pasos. El uso de dispositivos como el Juggleboard o [[Tisch/Körperjonglage]] para comprender el concepto de forma más sencilla, así como la secuencia de práctica claramente definida ("[[Cow jumps over the moon]]") de Craig.

> *Opinión*: No me parece revolucionariamente diferente, es simplemente una extensión del modelo clásico.
