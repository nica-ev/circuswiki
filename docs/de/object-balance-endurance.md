> Die Spieler balancieren einen vereinbarten Gegenstand, wie z. B. eine Keule oder sogar ein Einrad, auf dem Kinn oder einem anderen definierten Gleichgewichtspunkt.

![[../img/games-club-balance-guiness.jpg|300]]

**Gruppengröße**: 3 bis 60 Spieler
**Schwierigkeitsgrad**: schwer
**Material**: Keulen, Einräder oder andere Balance-Objekte
**Dauer**: ca. 5-15 Minuten

## Spielbeschreibung

Die Spieler balancieren einen vereinbarten Gegenstand, wie z. B. eine Keule oder sogar ein Einrad, auf dem Kinn oder einem anderen definierten Gleichgewichtspunkt. Der letzte Spieler, der noch balanciert, gewinnt.

## Variationen

Fügen Sie Bewegung oder einen kleinen Hindernisparcours hinzu, wenn das einfache Balancieren zu leicht ist.

## Sicherheitshinweise

Halten Sie den Spielbereich frei und definieren Sie die Grenzen, bevor die Runde beginnt. Bei Kontaktspielen zielen Sie auf Requisiten statt auf Körper. Bei Wurf-, Fahr-, Balance- oder Akrobatikspielen lassen Sie genügend Platz für Fehlschläge und beenden Sie die Runde, wenn die Gruppe beginnt, unsichere Risiken einzugehen.
