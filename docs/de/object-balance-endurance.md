> [!info] Kurzbeschreibung
> Die Spieler balancieren einen vereinbarten Gegenstand, z. B. eine Keule oder sogar ein Einrad, auf dem Kinn oder einer anderen definierten Balancefläche.

![games-club-balance-guiness](../img/games-club-balance-guiness.jpg){ width=300 }

**Gruppengröße**: 3 bis 60 Spieler
**Schwierigkeitsgrad**: schwer
**Material**: Keulen, Einräder oder andere Balance-Gegenstände
**Dauer**: ca. 5-15 Minuten

## Spielbeschreibung

Die Spieler balancieren einen vereinbarten Gegenstand, z. B. eine Keule oder sogar ein Einrad, auf dem Kinn oder einer anderen definierten Balancefläche. Der letzte Spieler, der noch balanciert, gewinnt.

## Variationen

Fügen Sie Bewegung oder einen kleinen Hindernisparcours hinzu, wenn das einfache Balancieren zu leicht ist.

## Sicherheitshinweise

Halten Sie den Spielbereich frei und definieren Sie die Grenzen, bevor die Runde beginnt. Bei Kontaktspielen zielen Sie auf Requisiten statt auf Körper. Bei Wurf-, Fahr-, Balance- oder akrobatischen Spielen lassen Sie genügend Platz für Fehlversuche und beenden Sie die Runde, wenn die Gruppe beginnt, unsichere Risiken einzugehen.
