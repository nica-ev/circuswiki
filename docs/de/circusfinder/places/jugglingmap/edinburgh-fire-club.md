# Edinburgh Fire Club

Der Edinburgh Fire Club ist auf der von der Community gepflegten JugglingMap als Jonglier-Training oder Jonglier-Club aufgeführt.

Standort laut Quelle: Pavilion Cafe, Melville Drive, Edinburgh, Alba / Schottland, Vereinigtes Königreich

## Jonglier-Training oder Jonglier-Club

Jeden Montag um 20:00 Uhr, organisiert von der lokalen Fire-Spinning-Community. Alle sind willkommen, eine kleine Spende für Brennstoff wird erbeten.
