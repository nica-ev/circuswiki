# Les Fortiches École de Cirque de Sommières

A Les Fortiches, escola de circo localizada em Sommières, França, oferece um programa de "Cirque Adapté" concebido para servir como ferramenta educativa e terapêutica para indivíduos com deficiências físicas ou mentais. Esta iniciativa foca-se na experimentação pessoal e coletiva, com o objetivo de capacitar os participantes através das diversas disciplinas das artes circenses. Cada projeto é desenvolvido em colaboração com a equipa pedagógica da Les Fortiches, garantindo uma abordagem personalizada que prioriza o progresso individual em detrimento do desempenho técnico. Esta metodologia inclui avaliações específicas para monitorizar e apoiar a evolução de cada participante.
