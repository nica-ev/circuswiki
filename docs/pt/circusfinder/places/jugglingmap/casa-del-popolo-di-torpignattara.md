# Casa del Popolo di Torpignattara

A Casa del Popolo di Torpignattara está listada no JugglingMap, mantido pela comunidade, como um local de treino ou clube de malabarismo.

Localização fornecida pela fonte: Via Benedetto Bordoni, Roma, Lazio, Italia

## Treino ou Clube de Malabarismo

O espaço é para Treino e Ensaios Livres. Portanto, NÃO é apenas para malabarismo, mas também para ensaios teatrais.
Quanto à música, a autogestão é feita com base em quem está presente. Tenha cuidado para não monopolizar o espaço acústico. Fones de ouvido são, às vezes, úteis. O importante é conversar e organizar-se com os presentes para escolher a solução mais confortável e eficaz para todxs.
Antes do Treino/Ensaios Livres, há uma aula de Yoga, que é apenas um dos cursos realizados no Espaço. Assim que tivermos o cartaz com toda a programação dos cursos deste ano, iremos carregá-lo aqui.
Força!

Horário fornecido pela fonte: Qui 11:30–18:00

Acesso: restrito: Contribuição para despesas básicas do local (papel higiênico, contas, etc.):
 Se ficar menos de 3 horas, você decide. Se ficar mais de 3 horas, contribua, se puder, com 3 euros.
 Outros tipos de troca também são bem-vindos; se preferir, podemos conversar.
 É obrigatório deixar o local limpo como ou ainda mais limpo do que foi encontrado.
 No local:
- há uma sala grande de 80 m² com piso laminado;
- sem área para acrobacias;
- um canto de chás autogerido;
- ambientes com mesas e cadeiras;
- WIFI;
- o volume da música deve ser mantido baixo.
