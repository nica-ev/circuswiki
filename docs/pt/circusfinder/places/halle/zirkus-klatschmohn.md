# Circo Klatschmohn

O Circo Klatschmohn oferece cursos semanais para crianças, jovens e adultos durante todo o ano, em suas tendas de circo aquecidas na Rossplatz. A oferta inclui, entre outras coisas, artes aéreas, acrobacia, equilíbrio e malabarismo.

Um treino experimental gratuito é possível mediante acordo prévio com o escritório do circo. Como muitos cursos estão lotados, pode haver uma lista de espera.
