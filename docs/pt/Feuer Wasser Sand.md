> [!info] Descrição Curta
> Um jogo de comandos onde o grupo reage rapidamente a palavras-chave anunciadas e encontra movimentos ou posições adequadas.

**Tamanho do Grupo**: A partir de 4 participantes
**Dificuldade**: Fácil
**Material**: Elevações (ex: bancos), opcionalmente um tambor
**Duração do Jogo**: 5-15 minutos

## **Descrição do Jogo**:

Todos os jogadores movem-se livremente pelo espaço. Se houver um tambor disponível, o facilitador pode ditar um ritmo com o qual os jogadores caminham pelo espaço – ora mais rápido, ora mais devagar. Em seguida, o facilitador pode gritar vários comandos que os jogadores devem executar.

**Comandos**:

**Fogo**: Com este comando, o facilitador aponta na direção onde está "a arder". Por isso, os jogadores devem mover-se o mais rápido possível para o lado oposto, para se afastarem o máximo possível do fogo.

**Água**: Todos os jogadores devem subir para algo elevado o mais rápido possível, de modo a não tocarem mais no chão.

**Areia**: Quando este comando é gritado, todos se deitam rapidamente de bruços no chão para não afundarem na areia.

**Gelo**: Todos congelam no lugar.

**Sol**: Todos os jogadores deitam-se de costas no chão, como se estivessem a apanhar sol.

**Pastilha elástica**: Este comando faz com que todos os jogadores tenham de se colar a uma parede.

**Café**: Os jogadores sentam-se de pernas cruzadas no chão e batem palmas três vezes.

**Refrigerante**: Tal como um refrigerante num copo, cada um se levanta direito e estica um braço para cima, este é o canudo.

**Besouro**: Todos se deitam de costas, esticam braços e pernas para o ar e tentam, em vão, virar-se novamente durante alguns segundos.

**Batatas fritas**: Com este comando, é preciso deitar-se lado a lado em grupos de três. (Se o número de jogadores não for divisível por três, grupos de quatro também servem)

**Tempestade**: Todos têm de se agarrar a algo para não serem levados pelo vento.

Em relação aos termos, pode-se ser muito criativo e inventar muitos outros comandos para jogar. Este jogo também pode ser jogado com eliminação, onde o mais lento ou aquele que se comporta incorretamente é eliminado.

## **Variantes**:

"Salva-se quem puder" é o nome desta variante do jogo. O princípio é o mesmo, só que o facilitador pode ser ainda mais criativo. Pois sempre que ele diz "salva-se quem ... puder", os jogadores têm de executar este comando. Exemplo: "Salva-se quem puder saltar num pé só". O que ele insere no espaço em branco está totalmente ao seu critério. Seja saltar num pé só, enfiar o dedo no nariz ou rodar em círculo, tudo o que o facilitador imaginar é possível.
