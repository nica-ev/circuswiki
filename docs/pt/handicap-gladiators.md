> [!info] Descrição Curta
> Esta é uma rodada de gladiadores com restrições adicionais para equilibrar as diferenças de habilidade.

**Tamanho do Grupo**: 3 a 60 jogadores  
**Dificuldade**: média  
**Material**: Clavas de malabarismo ou adereços de gladiador acordados  
**Duração**: aprox. 5-15 minutos

## Descrição do Jogo

Esta é uma rodada de gladiadores com restrições adicionais para equilibrar as diferenças de habilidade. Jogadores mais fortes podem ter que pular, manter um padrão de malabarismo específico, segurar clavas sob os braços ou mover-se com uma clava entre as pernas.

## Variações

Use desvantagens para tornar as finais de níveis mistos mais lúdicas, em vez de punir jogadores habilidosos.

## Notas de Segurança

Mantenha a área de jogo livre e defina os limites antes do início da rodada. Para jogos de contato, mire nos adereços em vez dos corpos. Para jogos de arremesso, montaria, equilíbrio ou acrobáticos, deixe espaço suficiente para tentativas falhas e interrompa a rodada se o grupo começar a correr riscos inseguros.
