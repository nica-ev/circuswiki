> [!info] Breve Descrição
> Um jogo de reação em círculo, onde comandos são rapidamente respondidos com palavras, movimentos e pequenas figuras.

**Tamanho do Grupo**: 6-25 pessoas
**Dificuldade**: média
**Material**: nenhum
**Duração do Jogo**: 10-15 minutos

## **Descrição do Jogo**:

Um jogo de círculo para grupos pequenos a médios.

Todos ficam em círculo, uma pessoa vai para o centro.
A pessoa no centro (P1) começa a apontar para qualquer pessoa (P2) no círculo. É importante apontar claramente para alguém, estabelecendo contato visual, de modo que fique muito claro quem é o alvo.

Agora, pode-se escolher entre as seguintes regras:

**"Bibbel Di Babbel Di Buh"**: Esta frase é dita por P1 e, antes que a frase termine, P2 deve dizer "Buh". Se P2 for muito lento, P2 vai para o centro.

**"Buh"**: Se P1 disser "Buh", P2 não deve reagir. Se P2 disser algo de qualquer maneira, P2 vai para o centro.

**"Torradeira"**: P1 diz "Torradeira" - as pessoas à direita e à esquerda de P2 viram-se para P2 e estendem as mãos ao lado de P2, P2 salta e grita "Bing" (P2 é a torrada, os outros formam a torradeira). Quem fizer algo errado vai para o centro.

**"Torradeira avariada"**: Este comando é semelhante a "Torradeira". As pessoas à direita e à esquerda de P2 formam novamente a torradeira, P2 é a torrada, mas desta vez P2 fica parado, os outros dois saltam e gritam "Bing".

**"Máquina de lavar"**: As pessoas à direita e à esquerda de P2 seguram as mãos para cima e para baixo, de modo que juntas formem um grande círculo à frente de P2 - elas formam a máquina de lavar, P2 gira a cabeça dentro deste círculo - a roupa que está a ser lavada.

**"Canguru a vomitar"**: P2 segura as duas mãos à frente e forma a bolsa do canguru. As duas pessoas à direita e à esquerda de P2 inclinam-se sobre a bolsa e fazem sons altos de vómito.
