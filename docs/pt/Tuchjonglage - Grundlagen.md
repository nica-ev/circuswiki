# Malabarismo com Lenços - Fundamentos

O malabarismo com lenços é particularmente adequado para aprender os fundamentos do malabarismo de arremesso, devido ao movimento de voo lento (devido à alta resistência do ar dos lenços).

Muitas vezes, o sucesso no aprendizado, até mesmo para malabarizar com 3 lenços, pode ser alcançado em um curto espaço de tempo.

Para iniciantes, também é muito útil usar lenços de cores diferentes para ter uma melhor visão do que está acontecendo.
