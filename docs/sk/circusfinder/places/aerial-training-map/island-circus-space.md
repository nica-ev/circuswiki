# Priestor ostrovného cirkusu

Priestor ostrovného cirkusu (Island Circus Space) je uvedený ako otvorené miesto na tréning leteckej akrobacie alebo cirkusu v mapách cirkusových telocviční/škôl po celom svete, ktoré sú zostavované komunitou.

Webstránka: [https://www.islandcircusspace.com](https://www.islandcircusspace.com)
