# NICA e.V. / Tohuwabohu Halle e.V.

NICA e.V. je cirkusová sieť a organizácia so sídlom v Halle (Saale). Vyvíja inkluzívne cirkusové metódy, spája praktikov a organizácie a poskytuje zdroje pre cirkusovú pedagogiku. Tohuwabohu Halle e.V. je pridružená miestna organizácia stojaca za praktickými cirkusovými aktivitami a konferenciou Tohuwabohu.

Značka zobrazuje adresu kancelárie zverejnenú na oficiálnej webovej stránke NICA: Thüringer Straße 30, Haus 1, Eingang 2, Raum 206.
