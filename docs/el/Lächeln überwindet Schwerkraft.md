## **Το Χαμόγελο Ξεπερνά τη Βαρύτητα**
**Γράμμα από τον Toby Philpott, Ευρωπαίο Διευθυντή της IJA**
[Kaskade 001](Kaskade%20001.md#Lächeln%20überwindet%20Schwerkraft)

Εδώ και δύο χρόνια κατέχω τον τίτλο «Ευρωπαίος Διευθυντής της Διεθνούς Ένωσης Ζογκλέρ» (IJA). Είναι ένας τίτλος που θα άρεσε στον W.C. Fields, καθώς ακούγεται σημαντικός και μυστηριώδης (και δεν σημαίνει σχεδόν τίποτα). Δεν «διευθύνω» κανέναν και περνάω το μεγαλύτερο μέρος του χρόνου μου στην Αγγλία.

![Kaskade00104](../img/Kaskade-001-04.png){ align=left }

Η IJA ξεκίνησε ως μια μικρή παρέα φίλων και τώρα είναι ένας μεγάλος οργανισμός με εκατοντάδες μέλη στην Αμερική. Η πρώτη ευρωπαϊκή συνάντηση ζογκλέρ ήταν επίσης μια μικρή παρέα φίλων στην Αγγλία, αλλά ήταν το πρώτο βήμα για να δικαιολογήσουμε τη λέξη «Διεθνής». Σήμερα, αυτή η συνάντηση προσελκύει ανθρώπους από περισσότερες από δέκα διαφορετικές χώρες.

Οι συναντήσεις μεγαλώνουν και έρχονται πολλοί μη-μέλη. Οι περισσότεροι από αυτούς δεν βλέπουν κανένα λόγο να γίνουν μέλη της IJA, αν το μόνο που κερδίζουν είναι ένα αμερικανικό περιοδικό και μια λίστα διευθύνσεων που δεν θα χρησιμοποιήσουν ποτέ.

Μπορώ να το καταλάβω αυτό. Αν δεν υπήρχε η IJA, θα εξακολουθούσα να θέλω να συναντώ άλλους ζογκλέρ (όχι μόνο αυτούς που έμαθαν από εμένα), θα ήθελα να ξέρω πού να αγοράσω εξοπλισμό, πού να δω παραστάσεις, πού να κάνω υπαίθριες εμφανίσεις. Θα ήθελα ακόμα να ανταλλάσσω ιδέες και να βλέπω ανθρώπους που κάνουν καλύτερα ζογκλερικά από εμένα. Έχω καταφέρει τα περισσότερα από αυτά και πριν ακούσω για την IJA, αλλά έχω δει και κάνει περισσότερα από τότε που αρχίσαμε να οργανώνουμε συναντήσεις στην Ευρώπη. Αυτές οι συναντήσεις είναι ο καλύτερος λόγος για να υπάρχει ένας επίσημος οργανισμός. Δεν είναι συνδικαλιστική οργάνωση, ούτε μπορούμε να κανονίσουμε παραστάσεις ή ακόμα και να εγγυηθούμε φιλίες.

Πιστεύω ότι η Ευρώπη πρέπει να έχει έναν εκπρόσωπο στο αμερικανικό Διοικητικό Συμβούλιο της IJA, ο οποίος θα διατηρεί επαφή με τα παλιά μέλη στις ΗΠΑ και σε άλλες χώρες, και θα αρχίσει να κάνει τον οργανισμό πραγματικά διεθνή.

Όταν μπαίνω στην αίθουσα μιας συνάντησης ζογκλέρ, βλέπω δύο βασικούς τύπους ανθρώπων. Κάποιοι δουλεύουν, ιδρώνουν και τελειοποιούν τεχνικές, ξεπερνώντας τα δικά τους όρια. Τους αποκαλώ «Ολυμπιονίκες», για να τονίσω αυτή την αναζήτηση της τελειότητας, το αθλητικό πνεύμα και την αύρα των Ελλήνων θεών και θεαινών, των υπερηρώων.

Άλλοι έχουν έρθει για να παίξουν, γελούν και αστειεύονται, πειραματίζονται, αυτοσχεδιάζουν, ανταλλάσσουν ιδέες και διασκεδάζουν. Τους αποκαλώ «Περιοδεύοντες Παίκτες» και είναι οι θνητοί, οι γελωτοποιοί, που χρησιμοποιούν την ικανότητά τους για αυτοσχεδιασμό, όπως όλοι οι περιοδεύοντες και οι παίκτες πρέπει να κάνουν.

Μπορεί να σκέφτεσαι ότι κάποιος με τίτλο όπως «Ευρωπαίος Διευθυντής» θα ήταν «Ολυμπιονίκης». Στην πραγματικότητα, άρχισα να κάνω ζογκλερικά ως χόμπι κατά τη διάρκεια μιας τεμπέλικης φάσης της ζωής μου. Τώρα έχω πίσω μου μερικά χρόνια ως performer και δάσκαλος, αλλά θέλω πάντα να μεταδίδω τη διασκέδαση, δεν περιμένω χρυσό μετάλλιο.

Χρειαζόμαστε τους ήρωες και τους κλόουν. Οι Ολυμπιονίκες μπορούν να μας δείξουν τι είναι δυνατό με αφοσίωση, θέτουν νέα πρότυπα και μπορούν να απολαύσουν ένα κοινό που μπορεί πραγματικά να εκτιμήσει την εργασία που κρύβεται σε κάθε κίνηση.

Οι Περιοδεύοντες Παίκτες είναι αυτοί που φέρνουν νέους ανθρώπους, βοηθούν τους νέους ζογκλέρ να ξεκινήσουν, διαδίδουν τον λόγο και διασκεδάζουν.

Θα διαβάσεις αυτό σε ένα περιοδικό που ανέλαβαν δύο Γερμανοί, οι οποίοι θα ήθελαν να δουν περισσότερους Ευρωπαίους στην IJA.

Το γράφω ως γράμμα επειδή δεν είμαι δημοσιογράφος και κάνω τα λάθη μου δημόσια, όπως συνήθως. Αν θέλεις αυτό το περιοδικό να συνεχίσει, παρακαλώ γράψε στους εκδότες του περιοδικού ή στείλε φωτογραφίες. Αν θέλεις η Ευρώπη να παίξει σημαντικότερο ρόλο στην IJA, γράψε μου και θα προσπαθήσω να εξηγήσω τη θέση μας στα άλλα μέλη του Διοικητικού Συμβουλίου. Αν προτιμάς μια ανεξάρτητη ευρωπαϊκή ομάδα, τότε ξεκίνα και ίδρυσέ την. Νομίζω ότι θα ήταν κρίμα να διασπαστούμε εντελώς από έναν οργανισμό που υπάρχει εδώ και 37 χρόνια και έχει μέλη σε πολλές χώρες.

Παρεμπιπτόντως, αν πιστεύεις ότι ένας πραγματικός Ολυμπιονίκης θα ήταν καλύτερος εκπρόσωπος για την Ευρώπη, τότε μπορείς να θέσεις υποψηφιότητα εσύ ο ίδιος, ή βρες έναν πολιτικό ζογκλέρ που θα είναι ο εκπρόσωπός μας για το 1985.
Εν τω μεταξύ, ελπίζω να σε δω στις λίγες μέρες που θα είμαστε μαζί. Και μην ξεχνάς: το χαμόγελο ξεπερνά τη βαρύτητα. (Αυτό είναι ένα καλό σύνθημα για να κερδίσεις εκλογές, ή για να προκαλέσεις πονοκεφάλους στους μεταφραστές μας.)
