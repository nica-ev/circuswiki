## Αρχιτεκτονική Συστήματος

>

>```mermaid
>flowchart LR
>A(Περιεχόμενα) --> B(Έλεγχος εκδόσεων)
>C(Λογισμικό επεξεργασίας) --> A

> [!info] Επισκόπηση της αρχιτεκτονικής
>```mermaid
>flowchart LR
>A[Obsidian] <--> B{Αρχεία}
>B <--> C(Github Desktop)

> *   **Obsidian:** Ένας προαιρετικός, αλλά από εμένα προτεινόμενος επεξεργαστής κειμένου για την επεξεργασία αρχείων Markdown.
> *   **Αρχεία:** Τα αρχεία Markdown που περιέχουν το περιεχόμενο της τεκμηρίωσής μου.

> *   **Github Pages:** Μια δωρεάν υπηρεσία για τη δημοσίευση της ιστοσελίδας μου.
> *   **MkDocs:** Ένα εργαλείο για την αυτόματη δημιουργία της ιστοσελίδας από τα αρχεία Markdown μου.
> *   **MkDocs-Material:** Ένα θέμα για το MkDocs που προσφέρει μια μοντέρνα και ελκυστική διάταξη.

## Συστατικά αναλυτικά

### 1. Markdown

> [!info] Markdown ως βάση
> Χρησιμοποιώ τη [μορφή Markdown](Markdown.md) για την τεκμηρίωσή μου. Το Markdown είναι μια απλή γλώσσα σήμανσης που μου επιτρέπει να μορφοποιώ κείμενο με απλές μορφοποιήσεις (π.χ. επικεφαλίδες, λίστες, συνδέσμους).

**Πλεονεκτήματα:**

*   Είναι εύκολο στην εκμάθηση και χρήση, επιτρέποντάς μου να επικεντρωθώ στο περιεχόμενο.
*   Είναι ανεξάρτητο από πλατφόρμα, ώστε να μπορώ να συνεχίσω την εργασία μου σε οποιαδήποτε συσκευή.
*   Είναι ιδανικό για τον έλεγχο εκδόσεων, επιτρέποντάς μου να παρακολουθώ και να διαχειρίζομαι τις αλλαγές.
*   Είναι ανθεκτικό στο χρόνο και όχι ιδιόκτητο, δίνοντάς μου τη βεβαιότητα ότι η εργασία μου θα παραμείνει προσβάσιμη μακροπρόθεσμα.

[Markdown](Markdown.md){ .md-buttons }

### 2. Obsidian

> [!info] Obsidian ως επεξεργαστής κειμένου
> Το [Obsidian](Obsidian%20Setup.md) είναι ένας προαιρετικός, αλλά από εμένα προτεινόμενος επεξεργαστής κειμένου. Μου προσφέρει τα ακόλουθα πλεονεκτήματα:

*   Μπορώ να αποθηκεύω τα δεδομένα μου τοπικά και να τα επεξεργάζομαι εκτός σύνδεσης, κάτι που μου δίνει ευελιξία και έλεγχο.
*   Μπορώ να συνδέω εύκολα αρχεία και να τα δικτυώνω μεταξύ τους, κάτι που με βοηθά να οργανώνω σύνθετες πληροφορίες.
*   Μπορώ να επισημαίνω αρχεία με ετικέτες και να τα διαχειρίζομαι εύκολα, κάτι που μου προσφέρει μια επιπλέον διάσταση οργάνωσης.
*   Μπορώ να απεικονίζω τα δεδομένα μου γραφικά, κάτι που με βοηθά να αναγνωρίζω μοτίβα και σχέσεις.
*   Μπορώ να επεκτείνω τη λειτουργικότητα του Obsidian μέσω plugins, επιτρέποντάς μου να προσαρμόζω το εργαλείο στις συγκεκριμένες ανάγκες μου.

### 3. Git και Github

> [!info] Git για έλεγχο εκδόσεων
> Το [Git](https://git-scm.com/) είναι ένα σύστημα ελέγχου εκδόσεων που μου επιτρέπει να παρακολουθώ και να διαχειρίζομαι τις αλλαγές στην τεκμηρίωση. Το [Github](https://github.com/) είναι μια διαδικτυακή υπηρεσία που μου επιτρέπει να αποθηκεύω τα αποθετήρια Git μου και να συνεργάζομαι με άλλους.

**Πλεονεκτήματα:**

*   Έλεγχος εκδόσεων: Κάθε αλλαγή τεκμηριώνεται και μπορεί να ανακληθεί ανά πάσα στιγμή, κάτι που με βοηθά να αποφεύγω λάθη και να διατηρώ την επισκόπηση.
*   Συνεργασία: Πολλοί άνθρωποι μπορούν να εργάζονται ταυτόχρονα στην τεκμηρίωση, δίνοντάς μου τη δυνατότητα να ενσωματώνω σχόλια και συνεισφορές από άλλους.
*   Αντίγραφο ασφαλείας: Η τεκμηρίωσή μου είναι ασφαλής και δημιουργείται τακτικά αντίγραφο ασφαλείας, δίνοντάς μου τη βεβαιότητα ότι η εργασία μου δεν θα χαθεί.

### 4. Github Desktop

> [!info] Github Desktop ως εργαλείο
> Το [Github Desktop](../_inbox/Github%20Desktop.md) είναι ένα γραφικό περιβάλλον για το Git, που μου επιτρέπει να χρησιμοποιώ το Git εύκολα και χωρίς γραμμή εντολών.

**Πλεονεκτήματα:**

*   Εύκολη χρήση, που διευκολύνει τη χρήση του Git.
*   Δεν απαιτούνται γνώσεις γραμμής εντολών, εξοικονομώντας μου χρόνο και κόπο.
*   Απλοποιεί τη ροή εργασίας μου, επιτρέποντάς μου να επικεντρωθώ στη δημιουργία περιεχομένου.

### 5. MkDocs

> [!info] MkDocs ως γεννήτρια ιστοσελίδων
> Το [MkDocs](https://mkdocs.org) είναι μια στατική γεννήτρια ιστοσελίδων που μετατρέπει τα αρχεία Markdown μου σε μια στατική ιστοσελίδα.

**Πλεονεκτήματα:**

*   Εύκολη δημιουργία ιστοσελίδων, επιτρέποντάς μου να δημοσιεύω την τεκμηρίωσή μου γρήγορα και εύκολα.
*   Γρήγορη ενημέρωση, επιτρέποντάς μου να βλέπω τις αλλαγές σε πραγματικό χρόνο.
*   Συνεπής διάταξη, εξασφαλίζοντας μια επαγγελματική και ομοιόμορφη παρουσίαση της τεκμηρίωσής μου.
*   Προεπισκόπηση εκτός σύνδεσης, επιτρέποντάς μου να ελέγχω την τεκμηρίωσή μου πριν τη δημοσιεύσω.

### 6. Github Pages

> [!info] Github Pages για φιλοξενία
> Το [Github Pages](../_inbox/Github%20Pages.md) είναι μια δωρεάν υπηρεσία φιλοξενίας από το Github, που μου επιτρέπει να δημοσιεύω εύκολα την ιστοσελίδα μου στο διαδίκτυο.

**Πλεονεκτήματα:**

*   Δωρεάν φιλοξενία, επιτρέποντάς μου να δημοσιεύω την τεκμηρίωσή μου χωρίς επιπλέον κόστος.
*   Εύκολη δημοσίευση, αφαιρώντας την τεχνική υλοποίηση της δημοσίευσης από εμένα.
*   Αξιόπιστο, δίνοντάς μου τη βεβαιότητα ότι η τεκμηρίωσή μου είναι διαθέσιμη ανά πάσα στιγμή.

### 7. MkDocs-Material

> [!info] MkDocs-Material ως θέμα
> Το [MkDocs-Material](https://squidfunk.github.io/mkdocs-material/) είναι ένα θέμα για το MkDocs που προσφέρει μια μοντέρνα και ελκυστική διάταξη.

**Πλεονεκτήματα:**

*   Μοντέρνος σχεδιασμός, κάνοντας την τεκμηρίωσή μου να φαίνεται επαγγελματική και σύγχρονη.
*   Προσαρμόσιμο, επιτρέποντάς μου να προσαρμόζω τη διάταξη στις συγκεκριμένες ανάγκες μου.
*   Φιλικό προς τον χρήστη, διευκολύνοντας τη χρήση της τεκμηρίωσης.

### 8. MkDocs-Publisher

> [!info] MkDocs-Publisher ως συλλογή plugins
> Το [MkDocs-Publisher](https://github.com/mkdocs-publisher/mkdocs-publisher) είναι μια συλλογή από plugins του MkDocs που απλοποιούν τη συνεργασία με το Obsidian και προσφέρουν επιπλέον λειτουργίες.

**Πλεονεκτήματα:**

- **Απλοποιημένη ενσωμάτωση Obsidian:** Αυτόματη προσαρμογή της σύνταξης Markdown του Obsidian (Callouts, Wikilinks κ.λπ.).
- **Επεκταμένα μεταδεδομένα:** Ενσωμάτωση ετικετών και κατηγοριών από το frontmatter του Obsidian.

## Ροή εργασίας

> [!info] Η ροή εργασίας μου
> Εδώ είναι η τυπική ροή εργασίας μου:

1.  Δημιουργώ και επεξεργάζομαι αρχεία Markdown με έναν επεξεργαστή κειμένου (προαιρετικά Obsidian).
2.  Αποθηκεύω τα αρχεία Markdown τοπικά.
3.  Μεταφέρω τις αλλαγές μου στο αποθετήριο Git χρησιμοποιώντας το Github Desktop.
4.  Δημιουργώ αυτόματα την ιστοσελίδα με το MkDocs.
5.  Δημοσιεύω την ιστοσελίδα με το Github Pages.

## Εναλλακτικές για τη δημιουργία περιεχομένου

> [!info] Εναλλακτικές για τη δημιουργία περιεχομένου
> Γνωρίζω ότι δεν είναι όλοι εξοικειωμένοι με το Markdown και το Git. Γι' αυτό προσφέρω τις ακόλουθες εναλλακτικές:

1.  **Wordpress:** Το περιεχόμενο μπορεί να δημιουργηθεί στο Wordpress ως σελίδα.
2.  **Αρχείο κειμένου, αρχείο Word:** Το περιεχόμενο μπορεί να δημιουργηθεί ως αρχείο κειμένου, αρχείο Word (ή σε άλλες τυπικές μορφές).

Σε αυτές τις περιπτώσεις, μπορώ να ενσωματώσω το περιεχόμενο στο σύστημα.
