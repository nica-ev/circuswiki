> [!info] Σύντομη Περιγραφή
> Ένα παιχνίδι εντολών-αντιδράσεων όπου οι ζογκλέρ ακολουθούν μόνο έγκυρες εντολές τύπου «Ο Άρχοντας να σου φυλάει» διατηρώντας τρεις μπάλες σε κίνηση.

![3-ball-simon-says](../img/3-ball-simon-says.jpg){ width=300 }

**Μέγεθος Ομάδας**: 3 έως 50 παίκτες
**Δυσκολία**: μέτρια
**Υλικά**: Τρεις μπάλες ζογκλερικής ανά παίκτη
**Διάρκεια**: περίπου 5-10 λεπτά

## Περιγραφή Παιχνιδιού

Όλοι οι παίκτες κάνουν ζογκλερικά με τρεις μπάλες, ενώ ένας «καλών» δίνει εντολές κίνησης ή κόλπων. Οι παίκτες ακολουθούν μόνο τις εντολές που ξεκινούν με τη συμφωνημένη φράση, για παράδειγμα «Ο Άρχοντας να σου φυλάει». Όποιος ακολουθήσει λανθασμένη εντολή, αγνοήσει έγκυρη εντολή, ρίξει τις μπάλες ή σταματήσει το ζογκλερικό, βγαίνει εκτός παιχνιδιού.

Πιθανές εντολές περιλαμβάνουν στροφή, κάθισμα, ξάπλωμα, όρθια στάση, χτύπημα παλαμάκων, αλλαγή μοτίβου, κίνηση αριστερά ή δεξιά, ή πάγωμα.

## Προετοιμασία

- Δώστε σε κάθε παίκτη τρεις μπάλες και αρκετό προσωπικό χώρο.
- Επιλέξτε έναν καλών.
- Συμφωνήστε αν οι παίκτες αποκλείονται ή λαμβάνουν αστείους πόντους ποινής.

## Παραλλαγές

- Για αρχάριους, χρησιμοποιήστε μία μπάλα ή μαντήλια.
- Κάντε το συνεργατικό μετρώντας πόσες εντολές μπορεί να επιβιώσει ολόκληρη η ομάδα.
- Αφήστε τους αποκλεισμένους παίκτες να γίνουν βοηθοί καλούντες.

## Σημειώσεις Ασφαλείας

Αποφύγετε εντολές που αναγκάζουν τους παίκτες να πέσουν, να συγκρουστούν μεταξύ τους, ή να κινηθούν τυφλά ενώ παρακολουθούν τα αντικείμενά τους.
