> [!info] Σύντομη Περιγραφή
> Οι αναβάτες διασχίζουν μια λωρίδα όσο πιο αργά γίνεται, χωρίς να σταματούν, να κάνουν ρελαντί ή να βγαίνουν εκτός πίστας.

**Μέγεθος Ομάδας**: 3 έως 60 παίκτες
**Δυσκολία**: δύσκολο
**Υλικά**: Μονόκυκλα, δείκτες λωρίδας
**Διάρκεια**: περίπου 5-15 λεπτά

## Περιγραφή Παιχνιδιού

Οι αναβάτες διασχίζουν μια λωρίδα όσο πιο αργά γίνεται, χωρίς να κάνουν ρελαντί, να σταματούν ή να βγαίνουν εκτός πίστας. Ο τελευταίος νόμιμος αναβάτης που θα περάσει τη γραμμή τερματισμού κερδίζει.

## Παραλλαγές

Χρησιμοποιήστε στενές λωρίδες για προχωρημένους αναβάτες και πιο φαρδιές λωρίδες για αρχάριους.

## Σημειώσεις Ασφαλείας

Διατηρήστε τον χώρο παιχνιδιού καθαρό και ορίστε τα όρια πριν ξεκινήσει ο γύρος. Για παιχνίδια επαφής, στοχεύστε αντικείμενα και όχι σώματα. Για παιχνίδια ρίψης, ποδηλασίας, ισορροπίας ή ακροβατικά, αφήστε αρκετό χώρο για αποτυχημένες προσπάθειες και σταματήστε τον γύρο εάν η ομάδα αρχίσει να παίρνει επικίνδυνα ρίσκα.
