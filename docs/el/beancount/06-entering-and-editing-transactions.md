# 06 - Εισαγωγή και Επεξεργασία Συναλλαγών

Οι περισσότερες εγγραφές προέρχονται από εισαγόμενα τραπεζικά δεδομένα, αλλά οι χρήστες εξακολουθούν να χρειάζεται να ελέγχουν, να ταξινομούν, να διορθώνουν και μερικές φορές να εισάγουν συναλλαγές χειροκίνητα.

## Κατάσταση Συναλλαγής

Τα λογιστικά βιβλία χρησιμοποιούν συνήθως το `!` σε εισαγόμενες συναλλαγές:

```beancount
2026-03-12 ! "Πληρωτέος" "Κείμενο Τράπεζας"
```

Χρησιμοποιήστε αυτό ως τον κανονικό δείκτη, εκτός αν η ομάδα αποφασίσει μια αυστηρότερη σύμβαση κατάστασης.

## Βασική Εγγραφή Εισοδήματος

```beancount
2026-01-15 ! "Max Mustermann" "Εισφορά Μέλους 2026"
  Περιουσιακά Στοιχεία:Τράπεζα:Sparkasse-NICA:Ελεύθερα-Χρήματα  60.00 EUR
  Έσοδα:Συνδρομή Συλλόγου
```

## Βασική Εγγραφή Εξόδου

```beancount
2026-01-20 ! "Όνομα Παρόχου" "Τιμολόγιο 123"
  Έξοδα:Γραφείο:Διάφορα  25.00 EUR
  Περιουσιακά Στοιχεία:Τράπεζα:Sparkasse-NICA
```

## Έσοδα Έργου

```beancount
2026-02-10 ! "Φορέας Χρηματοδότησης" "Πληρωμή επιχορήγησης έργου 25-ZGV"
  Περιουσιακά Στοιχεία:Τράπεζα:Sparkasse-NICA:25-ZGV  5000.00 EUR
  Έσοδα:Έργο:25-ZGV:Υλικά
```

## Έξοδα Έργου

```beancount
2026-02-15 ! "Όνομα Ατόμου" "Αμοιβή έργου 25-ZGV"
  Έξοδα:Έργο:25-ZGV:Αμοιβή  450.00 EUR
  Περιουσιακά Στοιχεία:Τράπεζα:Sparkasse-NICA:25-ZGV
```

## Εσωτερική Μετακίνηση μεταξύ Έργου και Ελεύθερων Κεφαλαίων

Μερικές φορές μια συναλλαγή πρέπει να κατανείμει χρήματα τράπεζας μεταξύ ενός λογαριασμού περιουσιακών στοιχείων ειδικά για το έργο και ελεύθερων κεφαλαίων. Ο πραγματικός τραπεζικός λογαριασμός είναι ένας φυσικός λογαριασμός Sparkasse, αλλά το λογιστικό βιβλίο παρακολουθεί τα εσωτερικά υπόλοιπα του έργου ξεχωριστά.

```beancount
2026-02-20 ! "Εσωτερική κατανομή" "Μεταφορά υπολειπόμενων κεφαλαίων έργου σε ελεύθερα χρήματα"
  Περιουσιακά Στοιχεία:Τράπεζα:Sparkasse-NICA:Ελεύθερα-Χρήματα  100.00 EUR
  Περιουσιακά Στοιχεία:Τράπεζα:Sparkasse-NICA:25-ZGV      -100.00 EUR
```

Πραγματοποιήστε εσωτερικές μεταφορές μόνο όταν κατανοείτε γιατί πρέπει να αλλάξει το εσωτερικό υπόλοιπο του έργου.

## Επιστροφές χρημάτων σε άτομα

Εάν κάποιος πλήρωσε ιδιωτικά και του επιστραφούν τα χρήματα αργότερα, το καθαρό μοτίβο είναι συνήθως να καταγραφεί η δαπάνη έναντι μιας υποχρέωσης και στη συνέχεια να εκκαθαριστεί η υποχρέωση με την τραπεζική πληρωμή.

```beancount
2026-03-01 ! "Κατάστημα" "Υλικά που αγοράστηκαν από τον Marc"
  Έξοδα:Έργο:25-ZGV:Υλικά  35.00 EUR
  Υποχρεώσεις:Άτομο:Marc-Bielert
```

```beancount
2026-03-05 ! "Marc Bielert" "Επιστροφή χρημάτων για υλικά"
  Υποχρεώσεις:Άτομο:Marc-Bielert  35.00 EUR
  Περιουσιακά Στοιχεία:Τράπεζα:Sparkasse-NICA
```

## Ασφαλής Επεξεργασία

Πριν την επεξεργασία, ελέγξτε:

- Βρίσκεστε στο σωστό λογιστικό βιβλίο του συλλόγου.
- Δεν επεξεργάζεστε την παραγόμενη έξοδο εισαγωγής σαν να ήταν το τελικό λογιστικό βιβλίο.
- Η ημερομηνία της συναλλαγής είναι σωστή.
- Το ποσό χρησιμοποιεί τελεία ως υποδιαστολή, για παράδειγμα `12.50 EUR`.
- Τα ονόματα των λογαριασμών είναι γραμμένα ακριβώς όπως οι υπάρχοντες λογαριασμοί.
- Οι συναλλαγές έργου χρησιμοποιούν με συνέπεια τον λογαριασμό περιουσιακών στοιχείων του έργου και την κατηγορία εσόδων/εξόδων του έργου.

Μετά την επεξεργασία, αποθηκεύστε το αρχείο, επαναφορτώστε το Fava, ελέγξτε για σφάλματα και επιθεωρήστε τη σχετική σελίδα λογαριασμού.
