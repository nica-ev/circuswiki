# AirCraft Circus Academy

Η AirCraft Circus Academy, μέλος του FEDEC, προσφέρει μαθήματα και εργαστήρια τσίρκου για όλες τις ηλικίες και ικανότητες, συμπεριλαμβανομένων ειδικών συνεδριών για άτομα με Ειδικές Εκπαιδευτικές Ανάγκες (ΕΕΑ). Διδάσκουν εναέριες δεξιότητες (εναέριοι ιστοί, στεφάνι, τραπέζι), ζογκλερικά, χούλα χουπ, poi, περιστροφή πιάτων και περπάτημα σε τεντωμένο σχοινί. Τα προγράμματά τους απευθύνονται τόσο σε άτομα που κάθονται όσο και σε άτομα που κινούνται, συμπεριλαμβανομένων ατόμων με αναπηρίες, άνοια και Πάρκινσον. Οι δραστηριότητες μπορούν να προσαρμοστούν στις ανάγκες των συμμετεχόντων, με επιλογές για ομαδικά μαθήματα, μεμονωμένα εργαστήρια ή ιδιωτικές συνεδρίες.
