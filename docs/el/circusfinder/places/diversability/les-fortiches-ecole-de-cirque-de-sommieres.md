# Les Fortiches Σχολή Τσίρκου της Σομιέρ

Οι Les Fortiches, μια σχολή τσίρκου που βρίσκεται στη Σομιέρ της Γαλλίας, προσφέρει ένα πρόγραμμα "Cirque Adapté" (Προσαρμοσμένο Τσίρκο) σχεδιασμένο να λειτουργεί ως εκπαιδευτικό και θεραπευτικό εργαλείο για άτομα με σωματικές ή νοητικές αναπηρίες. Αυτή η πρωτοβουλία εστιάζει στην προσωπική και συλλογική πειραματική διαδικασία, με στόχο την ενδυνάμωση των συμμετεχόντων μέσω των ποικίλων κλάδων των τεχνών του τσίρκου. Κάθε έργο αναπτύσσεται σε συνεργασία με την παιδαγωγική ομάδα των Les Fortiches, διασφαλίζοντας μια εξατομικευμένη προσέγγιση που δίνει προτεραιότητα στην ατομική πρόοδο έναντι της τεχνικής απόδοσης. Αυτή η μεθοδολογία περιλαμβάνει συγκεκριμένες αξιολογήσεις για την παρακολούθηση και υποστήριξη της εξέλιξης κάθε συμμετέχοντα.
