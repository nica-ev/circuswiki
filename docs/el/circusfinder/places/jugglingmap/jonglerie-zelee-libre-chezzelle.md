# Ελεύθερη Ζηλωτή Ζογκλερική - @Chezzelle

Η Ελεύθερη Ζηλωτή Ζογκλερική - @Chezzelle αναφέρεται στον χάρτη ζογκλερικής που συντηρείται από την κοινότητα ως χώρος προπόνησης ή λέσχη ζογκλερικής.

Τοποθεσία όπως παρέχεται από την πηγή: Maison des jeunes "Chez Zelle", 3, Voie des Hennuyers, Ottignies-Louvain-la-Neuve, Brabant wallon, Βέλγιο / Belgique / Belgien

## Προπόνηση Ζογκλερικής ή Λέσχη Ζογκλερικής

Θέλεις να ανακαλύψεις τη ζογκλερική ή να βελτιώσεις τις τεχνικές σου;
Ελάτε μαζί μας κάθε Κυριακή από τις 16:00 έως τις 18:00 στην αίθουσα της Ελεύθερης Ζηλωτής Ζογκλερικής (JZL) στο σπίτι των νέων Chez Zelle! Είτε είσαι αρχάριος/α είτε έμπειρος/η, αυτός ο χώρος είναι ανοιχτός σε όλους για να προπονηθείτε, να ανταλλάξετε ιδέες και να διασκεδάσετε. 🎪
Ο εξοπλισμός είναι διαθέσιμος (σε περιορισμένη ποσότητα), αλλά αν έχεις τον δικό σου, μη διστάσεις να τον φέρεις!
Σημαντική σημείωση: Απαιτείται κάρτα μέλους του σπιτιού των νέων για τη συμμετοχή (1,50€ για το έτος).
Σε περιμένουμε κάθε Κυριακή για να κάνουμε ζογκλερικά! 🤹‍♀️

Πρόσβαση: περιορισμένη: Ετήσια συνδρομή (1,5 ευρώ)
