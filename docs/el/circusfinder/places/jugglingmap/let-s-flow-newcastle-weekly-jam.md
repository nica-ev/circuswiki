# Ας Ροήσουμε! Εβδομαδιαίο Jam στο Νιούκασλ

Το Let's Flow! Newcastle weekly jam αναφέρεται στον χάρτη JugglingMap, που συντηρείται από την κοινότητα, ως χώρος προπόνησης ή λέσχη για juggling.

Τοποθεσία όπως παρέχεται από την πηγή: Foreshore Park, Newcastle, New South Wales, Αυστραλία

## Προπόνηση Juggling ή Λέσχη Juggling

• Δευτέρες | 5:30-7:30 μ.μ.
• Train Sheds, Foreshore Park (Wharf Rd)

Ελάτε να συμμετάσχετε σε αυτόν τον μικρό ρυθμό μαζί μας!
Κάθε Δευτέρα μαζευόμαστε για να περιστραφούμε, να αυτοσχεδιάσουμε, να μάθουμε, να συνδεθούμε και να εμβαθύνουμε την κοινότητά μας.

Νιώστε ασφαλείς να σκοντάψετε, να μπερδευτείτε και να ρίξετε το αντικείμενό σας ενώ μαθαίνετε νέα κόλπα. Όλα τα επίπεδα δεξιοτήτων είναι ευπρόσδεκτα, από περίεργους αρχάριους έως έμπειρους καλλιτέχνες.
- Παρέχεται μουσική
- Δεν απαιτείται εμπειρία
- Φιλικό προς την οικογένεια
- Φέρτε τα αντικείμενά σας + ενθαρρύνεται η ανταλλαγή επιπλέον αντικειμένων
- Ετοιμάστε ένα πικνίκ ή σνακ

Ελάτε όπως είστε και κινήστε το σώμα σας. Φέρτε τους φίλους σας, τα παιδιά σας και την περιέργειά σας!

Συχνά ακολουθεί Fire Jam μετά το Flow Jam μας από τις 7:30 μ.μ. Ελέγξτε τις εβδομαδιαίες ενημερώσεις στο Facebook event μας για να επιβεβαιώσετε τη φωτιά.
