# Cirque Aria

Το Cirque Aria αναφέρεται στον χάρτη JugglingMap, ο οποίος συντηρείται από την κοινότητα, ως χώρος εκπαίδευσης ή σύλλογος για το ζογκλερικό.

Τοποθεσία όπως παρέχεται από την πηγή: Timco East, Leon Valley, Texas, Ηνωμένες Πολιτείες

## Εκπαίδευση Ζογκλερικού ή Σύλλογος Ζογκλερικού

Εβδομαδιαία συνάντηση ζογκλερικού στο Cirque Aria στη δυτική πλευρά του Σαν Αντόνιο. Εσωτερικός χώρος, ψηλά ταβάνια και κλιματισμός! Πολλά αντικείμενα για να δοκιμάσετε, όλα τα επίπεδα εμπειρίας είναι ευπρόσδεκτα. Ελάτε να εξασκηθείτε με άλλους ζογκλέρ ή ελάτε να μάθετε να κάνετε ζογκλερικό. Έχουμε επίσης ένα δωρεάν κοινοτικό πάρτι τσίρκου κάθε πρώτη Σάββατο από τις 5-8 μ.μ. στο Cirque Aria με ζογκλερικό, flow, partner acro και εναέριες!
