# Flow-Treff Wetzikon

Το Flow-Treff Wetzikon αναφέρεται στον χάρτη JugglingMap, που συντηρείται από την κοινότητα, ως χώρος προπόνησης ή λέσχη για juggling.

Τοποθεσία όπως παρέχεται από την πηγή: 40, Zürcherstrasse, Wetzikon, Zürich, Schweiz/Suisse/Svizzera/Svizra

## Προπόνηση Juggling ή Λέσχη Juggling

Για απόλυτους αρχάριους: Πώς γίνεται ένα Flow Treff; Τι να περιμένει κανείς αν σας επισκεφτεί;
Προσφέρουμε μια ευρύχωρη αίθουσα, θερμαινόμενη τους ψυχρότερους μήνες, για να βελτιώσουμε τις δεξιότητές μας. Στην συνάντηση δεν υπάρχει σταθερό πρόγραμμα, οι συμμετέχοντες οργανώνονται μόνοι τους για ανταλλαγή τρικ, εργαστήρια ή ατομική προπόνηση. Κατόπιν αιτήματος ή προειδοποίησης, υπάρχει και η δυνατότητα να παίξουμε/προπονηθούμε με φωτιά, αλλά συνήθως παραμένουμε με τα εργαλεία εξάσκησης και στην αίθουσα. Κατά τη διάρκεια της συνάντησης, παίζουμε διάφορη μουσική στην αίθουσα, και κάθε εβδομάδα στήνεται μια άνετη γωνιά με καναπέ για να κάνουμε διάλειμμα και να συζητήσουμε. Αυτό που πρέπει να αναφερθεί είναι ότι κατά τη διάρκεια των συναντήσεών μας επιτρέπεται το κάπνισμα στην αίθουσα.

Πόσοι άνθρωποι έρχονται συνήθως;
Αυτήν τη στιγμή είμαστε μεταξύ 15-25 Flowmies που παρακολουθούν τακτικά τις συναντήσεις μας. Οι περισσότεροι προέρχονται από την περιοχή της Ζυρίχης, αλλά μερικοί ταξιδεύουν και από πιο μακριά.

Είναι ευπρόσδεκτα όλα τα εργαλεία; Τι είδους εργαλεία χρησιμοποιείτε συνήθως;
Ευπρόσδεκτα είναι όλα τα εργαλεία και είμαστε πολύ ποικιλόμορφοι ως προς τα εργαλεία που χρησιμοποιούμε για εξάσκηση και ροή. Φυσικά, εξαρτάται πάντα λίγο από το ποιος βρίσκεται στη συνάντηση, αλλά πιστεύω ότι, γενικά, έχουμε σχεδόν όλα τα εργαλεία που εκπροσωπούνται.
Δυστυχώς, η οροφή της αίθουσάς μας δεν είναι πολύ ψηλή και μπορεί να είναι λίγο χαμηλή για κάποιους jongleurs (π.χ. αυτούς που κάνουν juggling με 7 ρόπαλα), αλλά για τους περισσότερους αυτό δεν θα πρέπει να αποτελεί πρόβλημα.

Πόσο συχνά και πού συναντιέστε;
Συναντιόμαστε κάθε Τετάρτη από τις 19:00 στην Kulturfabrik Wetzikon. Η συνάντηση πραγματοποιείται στη μεγάλη αίθουσα εκδηλώσεων. Οι συναντήσεις μας είναι "ανοιχτές", αλλά συνήθως τελειώνουν γύρω στα μεσάνυχτα.
Κατά τους καλοκαιρινούς μήνες, Ιούλιο/Αύγουστο, η συνάντηση κάνει διάλειμμα. Κατά τη διάρκεια αυτής της περιόδου, η κοινότητα οργανώνει περιστασιακά δικές της συναντήσεις στο Greifensee, για να συνεχίσουμε να συνδεόμαστε.

Πρέπει να έχει κανείς ένα συγκεκριμένο επίπεδο δεξιοτήτων, ή μπορούν να συμμετέχουν τόσο αρχάριοι όσο και επαγγελματίες;
Καλωσορίζουμε όλα τα επίπεδα δεξιοτήτων.
Είμαστε πρόθυμοι να βοηθήσουμε στην έναρξη με διάφορα εργαλεία, να συνεχίσουμε να αναπτυσσόμαστε μαζί αν είστε ήδη λίγο πιο έμπειροι, ή να μάθουμε νέα πράγματα από εσάς.
Το πιο σημαντικό είναι το κίνητρο και το ενδιαφέρον για το Flow.

Αν κάποιος θέλει να σας ακολουθήσει, μπορεί απλώς να εμφανιστεί αυθόρμητα ή πρέπει να εγγραφεί;
Είμαστε μια ανοιχτή ομάδα και όλοι οι νέοι και παλιοί Flowmies μπορούν να συμμετέχουν στις συναντήσεις μας χωρίς προηγούμενη εγγραφή. Η συμμετοχή είναι δωρεάν, αλλά χαιρόμαστε πάντα για σνακ προς κοινή χρήση.
