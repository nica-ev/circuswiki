# Juggling Calling

Το Juggling Calling αναφέρεται στον JugglingMap, που συντηρείται από την κοινότητα, ως κατάστημα για ζογκλερικά.

Τοποθεσία όπως παρέχεται από την πηγή: Chemin des Eymaries, Thénac, Nouvelle-Aquitaine, Γαλλία

## Κατάστημα Ζογκλερικών

Κατασκευαστές εξοπλισμού για καλλιτέχνες της φωτιάς, από καλλιτέχνες της φωτιάς

Είμαι πρώτα απ' όλα καλλιτέχνης της φωτιάς. Για χρόνια ταξίδευα, έδινα παραστάσεις και προπονούμουν, αναζητώντας συνεχώς καλύτερο εξοπλισμό. Τα περισσότερα από αυτά που υπήρχαν δεν ανταποκρίνονταν στις ανάγκες μου, οπότε άρχισα να φτιάχνω τα δικά μου. Το 2018 άρχισα να κατασκευάζω εξοπλισμό για άλλους καλλιτέχνες ενώ ήμουν καθ' οδόν, και αυτή η εμμονή έγινε το Juggling Calling. Σήμερα είμαστε μια ομάδα 5 ατόμων, παράγοντας τα πάντα από την αρχή, προμηθευόμενοι, κατασκευάζοντας και προσαρμόζοντας κάθε κομμάτι εξοπλισμού μόνοι μας. Η ίδια νοοτροπία που με ώθησε να ξεκινήσω εξακολουθεί να καθοδηγεί τα πάντα: να φτιάχνουμε εξοπλισμό που οι καλλιτέχνες θέλουν πραγματικά να χρησιμοποιούν, χωρίς να μετατραπούμε σε μια απρόσωπη διαφημιστική μηχανή. Εδώ θα βρείτε: • Εξοπλισμό κατασκευασμένο από υλικά που έχουμε δοκιμάσει και επιλέξει εδώ και πολλά χρόνια • Σχέδια που έχουν διαμορφωθεί από μια δεκαετία πρωτοτυποποίησης, παρατήρησης και χρήσης εξοπλισμού φωτιάς σε παραστάσεις • Προσαρμοσμένες επιλογές ώστε ο εξοπλισμός σας να ταιριάζει στο στυλ σας • Εξαρτήματα και υλικά αν προτιμάτε να φτιάξετε τον δικό σας εξοπλισμό. Προσεγγίζω αυτή τη δουλειά τόσο ως τεχνίτης όσο και ως καλλιτέχνης. Οι τέχνες της φωτιάς και του flow είναι ακόμα νέες, και υπάρχει πολλά ακόμα να εξερευνηθούν σε υλικά, σχεδιασμό εξοπλισμού και καλλιτεχνική κατεύθυνση. Αν σας ενδιαφέρει πώς αισθάνεται ο εξοπλισμός σας, πόσο διαρκεί και οι λεπτομέρειες που κάνουν έναν εξοπλισμό πραγματικά ικανοποιητικό στη χρήση, βρίσκεστε στο σωστό μέρος. (Οι περισσότερες) παραγγελίες ετοιμάζονται και αποστέλλονται εντός 3 εργάσιμων ημερών.
— Guillaume
