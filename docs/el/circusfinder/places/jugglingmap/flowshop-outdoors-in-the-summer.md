# Flowshop (σε εξωτερικό χώρο το καλοκαίρι)

Το Flowshop (σε εξωτερικό χώρο το καλοκαίρι) αναφέρεται στον χάρτη JugglingMap, που συντηρείται από την κοινότητα, ως χώρος προπόνησης ή λέσχη για juggling.

Τοποθεσία όπως παρέχεται από την πηγή: Dahlia garden, Seattle, Washington, United States

## Προπόνηση Juggling ή Λέσχη Juggling

(Δεν θα συναντηθούμε ξανά εδώ μέχρι τον Μάιο του 2027! Δείτε τη σχετική καταχώρηση Flowshop σε εσωτερικό χώρο για τον χειμώνα του 2026)

Ελάτε μαζί μας κάθε Τρίτη για το FlowShop! Συναντιόμαστε στον γρασίδι κοντά στο θερμοκήπιο και τον κήπο με τις ντάλιες (και τα δύο εμφανίζονται στους χάρτες Google!).

Το FlowShop είναι μια εβδομαδιαία συνάντηση για καλλιτέχνες του flow, jugglers, χορευτές και άλλους καλλιτέχνες της κίνησης, για να έρθουν μαζί για εξάσκηση και παιχνίδι. Οι εκδηλώσεις μας είναι ανοιχτές σε άτομα όλων των προελεύσεων, δεξιοτήτων και επιπέδων εμπειρίας.

Ενδιαφέρεστε να διδάξετε ένα εργαστήριο; Συμπληρώστε την αίτησή μας εδώ: https://forms.gle/jDiSjYLTsEAHubhP8

------------------------------------------------------------------------
**Πώς θα μας βρείτε στο Volunteer Park:** Χρησιμοποιήστε GPS για να πλοηγηθείτε στον Dahlia Garden του Volunteer Park. Θα μπορείτε να δείτε το Volunteer Park Conservatory στο τέλος του δρόμου (Είναι ένα λευκό κτίριο με πολλά παράθυρα). Όταν το θερμοκήπιο είναι πίσω σας, θα μας δείτε στον κάτω γρασίδι λόφο.

------------------------------------------------------------------------
**Τι να περιμένω στο FlowShop;**

Φιλικά πρόσωπα και φιλόξενοι χώροι. Οι ανοιχτές συγκεντρώσεις είναι ένας άναρχος χρόνος για να έρθουμε μαζί και να εξασκήσουμε τέχνες flow, ενώ παράλληλα χτίζουμε συνδέσεις και κοινότητα. Πολλοί αγαπούν να διδάσκουν! Όλα τα αντικείμενα, τα επίπεδα δεξιοτήτων και οι τρόποι κίνησης ενθαρρύνονται και είναι ευπρόσδεκτα!

Δεν έχετε δικό σας αντικείμενο; Έχουμε πάντα επιπλέον για να μοιραστούμε.
