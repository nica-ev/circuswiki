# Τσίρκο Παπαρούνα

Το Τσίρκο Παπαρούνα προσφέρει εβδομαδιαία μαθήματα για παιδιά, εφήβους και ενήλικες καθ' όλη τη διάρκεια του έτους, στις θερμαινόμενες τέντες του τσίρκου στην πλατεία Ρος (Rossplatz). Το πρόγραμμα περιλαμβάνει, μεταξύ άλλων, εναέρια ακροβατικά, ακροβατική, ισορροπία και ζογκλερικά.

Μια δωρεάν δοκιμαστική συνάντηση είναι δυνατή κατόπιν προηγούμενης συνεννόησης με το γραφείο του τσίρκου. Δεδομένου ότι πολλά μαθήματα είναι πλήρως καλυμμένα, μπορεί να υπάρχει λίστα αναμονής.
