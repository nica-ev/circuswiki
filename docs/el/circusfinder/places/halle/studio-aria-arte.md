# Studio aria arte

Το **Studio aria arte** προσφέρει Pole Dance, Aerial Hoop, Aerial Silk, Stretching, Body Power, καθώς και μαθήματα για παιδιά και εφήβους.

Το τρέχον πρόγραμμα μαθημάτων και οι δοκιμαστικές ώρες αναρτώνται μέσω του διαδικτυακού συστήματος κρατήσεων του στούντιο.
