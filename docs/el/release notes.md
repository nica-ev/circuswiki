>[!info]
>Αυτές οι σημειώσεις έκδοσης παρέχουν μόνο μια γενική επισκόπηση. Μικρές αλλαγές (όπως μεμονωμένες νέες σελίδες, τροποποιήσεις υπάρχοντος περιεχομένου) δεν αναφέρονται όλες. Ωστόσο, μπορούν να εντοπιστούν λεπτομερώς στο ιστορικό του αποθετηρίου.

>[!info]- **Έκδοση:** v0.04 - **Ημερομηνία Έκδοσης**: 9 Ιουνίου 2026
>**Περιεχόμενο**
>- Εκτεταμένη υποστήριξη για πολύγλωσσο περιεχόμενο: Το περιεχόμενο βρίσκεται πλέον δομημένο κάτω από τον κατάλογο `docs/<sprache>`.
>- Προστέθηκαν νέες και ενημερωμένες μεταφράσεις για πολλές περιγραφές παιχνιδιών και σελίδες έργων.
>- Εισήχθη υλικό εργαστηρίου στα Πολωνικά και ενσωματώθηκε στην πολύγλωσση δομή περιεχομένου.
>- Ενοποιήθηκε περαιτέρω η δομή περιεχομένου και μεταδεδομένων για τα παιχνίδια.
>
>**Τεχνικά**
>- Ο γεννήτορας ιστοσελίδων άλλαξε από MkDocs/MkDocs Material σε Zensical.
>- Εισήχθη νέα πολύγλωσση δομή για τη δημιουργία και τη δοκιμή (build and staging).
>- Τα Γερμανικά παραμένουν η προεπιλεγμένη γλώσσα χωρίς πρόθεμα γλώσσας. Άλλες γλώσσες θα δημοσιεύονται με κωδικούς γλώσσας, π.χ. `/en/`, `/pl/`, `/es/`.
>- Εισήχθη κεντρική διαμόρφωση γλώσσας μέσω του `tools/config/languages.json`.
>- Ενημερώθηκε η ανάπτυξη στο GitHub Pages για τη νέα δομή Zensical.
>- Επεκτάθηκαν σημαντικά τα εργαλεία τοπικής μετάφρασης και η κονσόλα προγραμματιστή: Έλεγχοι υγείας, προγραμματισμός παρτίδων, κατάσταση μετάφρασης, προβολές γραφημάτων, εργαλεία πλοήγησης, ροές εργασίας επιδιόρθωσης συνδέσμων και καθαρισμού.
>- Προστέθηκαν εναλλάκτης γλώσσας, ενδείξεις κατάστασης μετάφρασης και σελίδες πτώσης (fallback) για ελλείπουσες μεταφράσεις.
>- Βελτιώθηκαν οι πίνακες στην τελική έξοδο της ιστοσελίδας: ταξινομήσιμοι πίνακες, καλύτερη απεικόνιση πυκνών πινάκων και προαιρετικά αναδιπλούμενα τμήματα σελίδων.
>
>**Διορθώθηκαν**
>- Οι εσωτερικοί σύνδεσμοι και οι σύνδεσμοι Markdown σε μεταφρασμένες σελίδες διατηρούνται και επιδιορθώνονται με μεγαλύτερη αξιοπιστία.
>- Η πολύγλωσση πλοήγηση και η δομή των διευθύνσεων URL σταθεροποιήθηκαν.
>- Βελτιώθηκε η απόκριση της πλοήγησης, ειδικά σε συνδυασμό με το μενού "hamburger" του Zensical για κινητά.

>[!info]- **Έκδοση:** v0.03 - **Ημερομηνία Έκδοσης**: 11 Μαρτίου 2025
>**Περιεχόμενο**
>- Προστέθηκαν περιγραφές που έλειπαν για παιχνίδια.
>
>**Τεχνικά**
>- Προστέθηκε εικονίδιο (Favicon) + λογότυπο.
>- Ανασχεδιασμός διεπαφής χρήστη (UI).
>- Η πλοήγηση πρώτου επιπέδου βρίσκεται πλέον στην κεφαλίδα της σελίδας, ενώ η δεξιά μπάρα πλοήγησης προσαρμόζεται ανάλογα με το περιεχόμενο.
>- Οι πίνακες μπορούν να ταξινομηθούν κάνοντας κλικ στις κεφαλίδες τους.
>
>**Διορθώθηκαν**
>- Οι ετικέτες (tags) λειτουργούν ξανά.

>[!info]- **Έκδοση:** v0.02 - **Ημερομηνία Έκδοσης**: 26 Φεβρουαρίου 2025
>**Τεχνικά**

>- Μπάρα αποδοχής cookies (Cookie Banner).
