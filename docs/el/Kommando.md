> [!info] Σύντομη Περιγραφή
> Ένα παιχνίδι αντίδρασης με αλλαγές θέσεων, όπου οι συμμετέχοντες αναζητούν γρήγορα νέες θέσεις με βάση κατάλληλες εντολές.

**Μέγεθος Ομάδας**: 6 έως 25 συμμετέχοντες
**Δυσκολία**: εύκολο
**Υλικά**: χαλάκια ή άλλες σημάνσεις θέσεων
**Διάρκεια Παιχνιδιού**: 4 έως 7 λεπτά

## **Περιγραφή Παιχνιδιού**:

Κάθε παίκτης, εκτός από έναν, κάθεται σε ένα χαλάκι ή σε μια άλλη, σαφώς σηματοδοτημένη θέση. Οι θέσεις είναι διατεταγμένες σε κύκλο και στη μέση του κύκλου βρίσκεται ο παίκτης που δεν έχει θέση. Αυτός δίνει τώρα μια συγκεκριμένη εντολή, για παράδειγμα λέει: «Εντολή: όποιος έχει πάει ποτέ στη Βαλτική Θάλασσα» ή «Εντολή: όποιος φοράει πράσινες κάλτσες» ή ό,τι του έρθει εκείνη τη στιγμή. Όλοι οι παίκτες στους οποίους αφορά η εντολή, πρέπει τώρα να σηκωθούν γρήγορα και να βρουν μια νέα θέση. Ο παίκτης στη μέση μπορεί να προσπαθήσει να αρπάξει μια από τις θέσεις που ελευθερώνονται. Αν τα καταφέρει, αυτός που θα μείνει έξω πρέπει να δώσει μια νέα εντολή. Επιπλέον, υπάρχουν οι ακόλουθες τρεις εντολές που μπορούν να δοθούν ανά πάσα στιγμή, όταν κάποιος βρίσκεται στη μέση:

- Εντολή αριστερά: Όλοι πρέπει να μετακινηθούν στη θέση αριστερά τους.
- Εντολή δεξιά: Όλοι πρέπει να μετακινηθούν στη θέση δεξιά τους.
- Εντολή γύρω-γύρω: Όλοι πρέπει να κάνουν ένα γύρο γύρω από τη δική τους θέση και να καθίσουν ξανά.

Αυτές οι εντολές χρησιμεύουν μόνο για να δοθεί περισσότερη κίνηση στο παιχνίδι, όχι για να βρει ο παίκτης στη μέση μια θέση.
