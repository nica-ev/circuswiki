> [!info] Με λίγα λόγια
> Το CircusWiki είναι μια δημόσια, επιμελημένη συλλογή γνώσεων για την εκπαίδευση στον τσίρκο, τα παιχνίδια κίνησης, την συμπεριληπτική πρακτική και συναφή θέματα. Αναπτύσσεται από ανθρώπους που μοιράζονται τις εμπειρίες, τα υλικά και τις ιδέες τους.

Το CircusWiki προορίζεται ως μια συλλογικά δημιουργημένη, επιμελημένη και δημόσια πηγή. Πολλά καλά παιχνίδια, μέθοδοι, ιδέες για εργαστήρια και αποκτηθείσα εμπειρία υπάρχουν μόνο σε μεμονωμένες ομάδες, σε παλιούς ιστότοπους, σε αρχεία PDF, σε σημειωματάρια ή στο μυαλό ανθρώπων που εργάζονται πρακτικά.

Θέλουμε να συλλέξουμε, να οργανώσουμε, να μεταφράσουμε και να καταστήσουμε αυτές τις γνώσεις προσβάσιμες μακροπρόθεσμα. Για αυτό χρειαζόμαστε τη συμβολή σας από την πρακτική σας εργασία.

Δεν χρειάζεται να χρησιμοποιήσετε GitHub, να γνωρίζετε Markdown ή να γράψετε έτοιμα άρθρα. Ακατέργαστο υλικό είναι ευπρόσδεκτο.

## Τι μπορείτε να συνεισφέρετε

Οι καλές συνεισφορές μπορεί να έχουν πολύ διαφορετική μορφή:

- ένα παιχνίδι κίνησης που λειτουργεί καλά στην ομάδα σας
- μια άσκηση, μέθοδος ή δομή εργαστηρίου
- μια παραλλαγή για συμπεριληπτικές ή μικτές ομάδες
- συμβουλές ασφαλείας ή συντονισμού από την πρακτική σας
- φωτογραφίες υλικού, στησίματος ή σταθμών παιχνιδιού
- παλιά φυλλάδια, PDF, σενάρια ή ιστοσελίδες που δεν πρέπει να χαθούν
- διορθώσεις, συμπληρώσεις ή καλύτερες διατυπώσεις σε υπάρχουσες σελίδες
- μεταφράσεις ή τοπικές προσαρμογές
- υποδείξεις για καλές πηγές, έργα ή αρχεία

Δεν χρειάζεται να είναι τέλειο. Μια σύντομη περιγραφή, μια φωτογραφία από τον πίνακα ή ένα ημιτελές έγγραφο μπορεί να αρκεί για να εξελιχθεί κάτι.

## Ο ευκολότερος τρόπος: Στείλτε το υλικό σας

Στείλτε μας το υλικό σας μέσω email:

[info@nica.network](mailto:info@nica.network){ .md-button }

Μπορείτε να στείλετε, για παράδειγμα:

- κείμενο απευθείας στο email
- έγγραφα Word
- αρχεία Markdown ή TXT
- PDF
- εικόνες ή φωτογραφίες
- συνδέσμους προς ιστοσελίδες, άρθρα blog ή διαδικτυακά έγγραφα
- υποδείξεις όπως: "Αυτή η πηγή θα μπορούσε να είναι ενδιαφέρουσα για το CircusWiki"

Αν δεν είστε σίγουροι αν κάτι ταιριάζει, στείλτε το ούτως ή άλλως ή ρωτήστε μας σύντομα.

## Ιστότοποι, Blogs και υπάρχοντα έγγραφα

Αν το υλικό σας βρίσκεται ήδη κάπου στο διαδίκτυο, δεν χρειάζεται να το ξαναγράψετε. Απλώς στείλτε μας τον σύνδεσμο.

Σε πολλές περιπτώσεις, μπορούμε να πάρουμε περιεχόμενο από ιστοσελίδες, WordPress blogs ή PDF και να το επεξεργαστούμε για το CircusWiki. Το σημαντικό είναι μόνο να είναι σαφές ποιος κατέχει τα δικαιώματα του υλικού και αν μπορεί να δημοσιευτεί ή να επαναχρησιμοποιηθεί.

## Τι συμβαίνει μετά την αποστολή

Οι συνεισφορές δεν δημοσιεύονται χωρίς έλεγχο. Το CircusWiki είναι ανοιχτό σε συνεισφορές, αλλά επιμελημένο.

Συνήθως συμβαίνουν τα εξής:

1. Διαβάζουμε ή εξετάζουμε το υλικό.
2. Ελέγχουμε αν ταιριάζει στο Wiki.
3. Αν χρειάζεται, το δομούμε ως σελίδα Markdown.
4. Διευκρινίζουμε πηγές, συγγραφείς και δικαιώματα χρήσης.
5. Επεξεργαζόμαστε προσεκτικά το κείμενο για την κατανόηση, τους συνδέσμους και τα μεταδεδομένα.
6. Το δημοσιεύουμε, αφού διευκρινιστούν το περιεχόμενο και τα δικαιώματα.

Αν θέλετε να αναφέρεστε με το όνομά σας, μπορούμε να σας αναφέρουμε ως συγγραφέα ή πηγή. Αν προτιμάτε να μην αναφέρεστε ορατά, παρακαλούμε ενημερώστε μας.

## Μικρές συνεισφορές είναι ρητά ευπρόσδεκτες

Δεν χρειάζεται να παραδώσετε ένα πλήρες άρθρο. Ακόμη και μικρές υποδείξεις βοηθούν:

- "Η περιγραφή αυτού του παιχνιδιού είναι ασαφής."
- "Στην περίπτωσή μας, η παραλλαγή λειτουργεί διαφορετικά."
- "Εδώ λείπει μια συμβουλή ασφαλείας."
- "Γνωρίζω μια καλή πηγή γι' αυτό."
- "Αυτή η μετάφραση δεν ακούγεται φυσική."
- "Αυτός ο σύνδεσμος είναι σπασμένος."

Ακριβώς τέτοιες μικρές ανατροφοδοτήσεις κάνουν μια δημόσια συλλογή γνώσεων καλύτερη.

## Άμεση συνεργασία στο αποθετήριο

Αν θέλετε να εργαστείτε τεχνικά, μπορείτε επίσης να επεξεργαστείτε το CircusWiki απευθείας στο αποθετήριο του GitHub. Αυτό είναι χρήσιμο αν θέλετε να συντηρείτε τακτικά σελίδες, να κάνετε μεγάλες διορθώσεις ή να εργάζεστε με Markdown/Obsidian.

Αυτός είναι ο προηγμένος τρόπος. Για κανονικές συνεισφορές δεν είναι απαραίτητος.

[Διαβάστε την οδηγία για το GitHub](github-for-users.md){ .md-button }

## Γιατί να συμμετάσχετε;

Πολλά πρακτικά υλικά χάνονται όταν τελειώνουν έργα, οι ιστοσελίδες βγαίνουν εκτός σύνδεσης ή μεμονωμένα άτομα σταματούν να δίνουν μαθήματα. Το CircusWiki προσπαθεί να διατηρήσει τέτοιες γνώσεις ως ανοιχτή, εκδοτική και πολύγλωσση πηγή.

Όταν συνεισφέρετε κάτι, βοηθάτε όχι μόνο αυτήν την ιστοσελίδα. Βοηθάτε άλλους ανθρώπους να βρουν, να προσαρμόσουν, να μεταφράσουν και να διαδώσουν καλή πρακτική.
