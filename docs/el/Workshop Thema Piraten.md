# Θέμα Εργαστηρίου: Πειρατές

Ειδικά για παιδιά προσχολικής ηλικίας, συνιστάται η ενσωμάτωση των κλάδων (των παραστατικών τεχνών) με βάση ένα θέμα. Ένα δημοφιλές θέμα είναι σίγουρα οι «Πειρατές».

Απλές δυνατότητες για να ενσωματωθεί η ισορροπία στο σχοινί είναι:

- Διάσχιση ενός βαθιού φαραγγιού στην αναζήτηση του πειρατικού θησαυρού

Με παρόμοιο τρόπο, μπορούν να βρεθούν θεματικές χρήσεις για (σχεδόν) όλους τους κλάδους.

- Εναέρια ακροβατικά: σκαρφάλωμα στο πλοίο στην αρματωσιά
- Ζογκλερικά με μαντήλια: κόκκινα μαντήλια χρησιμοποιούνται ως φωτιά, πάνω στην οποία ψήνονται marshmallows / μήλα, αυτά ζεσταίνονται και πρέπει να πεταχτούν από χέρι σε χέρι
