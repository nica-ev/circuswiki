# Christchurch Circus Trust

Christchurch Circus Trust jest wymieniony na utrzymywanej przez społeczność JugglingMap jako miejsce treningów żonglerki lub klub żonglerski.

Lokalizacja podana przez źródło: Roy Stokes Community Hall, Seaview Road, Coastal-Burwood Community, Canterbury, Nowa Zelandia / Aotearoa

## Treningi żonglerki lub klub żonglerski

Drewniana podłoga z częściowo wykładanym dywanem, punkty do akrobacji powietrznych i materace. Sprzęt można wypożyczyć za niewielką opłatą lub przynieść własny.

Harmonogram podany przez źródło: Wtorek 19:15–20:45, Środa 18:00–20:00

Dostęp: ograniczony: Prosimy o wcześniejsze zapisy online, zwłaszcza jeśli chcesz skorzystać z punktu do akrobacji powietrznych. 7,50–15 $

Kontakt podany przez źródło:

https://linktr.ee/circustrust
