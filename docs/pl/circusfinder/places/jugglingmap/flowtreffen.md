# Flowtreffen

Flowtreffen jest wymienione na utrzymywanej przez społeczność JugglingMap jako trening żonglerski lub klub żonglerski.

Lokalizacja podana przez źródło: Bremer Damm, Hanower, Dolna Saksonia, Niemcy

## Trening żonglerski lub klub żonglerski

Środy, otwarte spotkanie w ramach „Sport im Park”, z muzyką od zmieniających się DJ-ów
https://www.sportimpark-hannover.de/sport-im-park/kurse/offener-flow-arts-treff/

kontynuowane również po oficjalnym zakończeniu zajęć.

Harmonogram podany przez źródło: Śr. 18:00–20:00

Dostęp: bezpłatny

Linki lub konta społecznościowe podane przez źródło:

@flowcommunityhannover
