# Südi (Südpark)

Südi (Südpark) jest wymieniony na utrzymywanej przez społeczność JugglingMap jako miejsce treningów żonglerskich lub klub żonglerski.

Lokalizacja podana przez źródło: Südpark, Münster, Nadrenia Północna-Westfalia, Niemcy

## Treningi żonglerskie lub klub żonglerski

Głównie akrobatyka i slackline, ale żonglerzy są mile widziani. Przy dobrej pogodzie prawdopodobnie można tam spotkać ludzi trenujących w inne dni tygodnia.

Dostęp: bezpłatny

Linki lub konta społecznościowe podane przez źródło:

slackline.akrobatik.muenster
