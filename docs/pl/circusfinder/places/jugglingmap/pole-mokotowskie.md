# Pole Mokotowskie

Pole Mokotowskie jest wymienione na utrzymywanej przez społeczność JugglingMap jako miejsce treningów żonglerskich lub klub żonglerski.

Lokalizacja podana przez źródło: Metro Politechnika 01, Aleja Armii Ludowej, Warszawa, województwo mazowieckie, Polska

## Treningi Żonglerskie lub Klub Żonglerski

Otwarte sesje żonglerskie (jammy).
Odbywają się latem w czwartki.

Możliwe jest również spotkanie żonglerów w inne dni, jeśli pogoda dopisuje.

Harmonogram podany przez źródło: Czw 18:00–20:00

Dostęp: bezpłatny
