# Tit for Tat Circus

Tit for Tat Circus jest wymieniony na utrzymywanej przez społeczność JugglingMap jako ośrodek treningu żonglerki lub klub żonglerski.

Lokalizacja podana przez źródło: Mivart Studios, Mivart Street, Bristol, Anglia, Wielka Brytania

## Trening Żonglerki lub Klub Żonglerski

Siedziba objazdowej firmy cyrkowej Tit for Tar. Dostępne do wynajęcia przestrzenie prób, z niskimi stawkami treningowymi dla artystów, gdy nie są zarezerwowane. Dostępne są również programy członkowskie na treningi.
