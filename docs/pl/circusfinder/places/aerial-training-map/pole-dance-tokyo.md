# Pole Dance Tokyo

Pole Dance Tokyo jest wymieniony jako otwarte miejsce treningowe dla akrobatyki powietrznej lub cyrku w mapie stworzonej przez społeczność „Siłownie / Szkoły Cyrkowe na całym świecie”.

Strona internetowa: [http://poledancetokyo.com/](http://poledancetokyo.com/)
