> [!info] Short Description
> A rhythmic circle game with rocket verses, animal transformations, and a shared return to the rocket.

**Group Size**: 4-20 people
**Difficulty**: Easy
**Materials**: None
**Duration**: 5-10 minutes

## **Game Description**:

Bang, bang, boom – we're flying to the moon!
We hold each other's hand,
And fly to... [animal name] land!

- Huddle in a circle.
- Clap in a three-beat rhythm.
- Transform into animals.
- 5, 4, 3, 2, 1 – back into the rocket!
