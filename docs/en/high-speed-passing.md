> [!info] Short Description
> Pairs pass a diabolo back and forth for one minute.

**Group Size**: 2 to 20 players  
**Difficulty**: mittel  
**Material**: Diabolos and handsticks, stopwatch  
**Duration**: approx. 5-15 minutes

## Game Description

Pairs pass a diabolo back and forth for one minute. Every clean pass counts. The pair with the highest number of successful passes wins.

## Variations

Run several heats and let pairs improve their score over two attempts.

## Safety Notes

Keep the playing area clear and define the limits before the round starts. For contact games, target props rather than bodies. For throwing, riding, balancing or acrobatic games, leave enough space for failed attempts and stop the round if the group starts taking unsafe risks.
