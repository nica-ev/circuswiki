> [!info] Short Description
> A unicycle race over a distance or obstacle course.

**Group Size**: 2 to 40 players  
**Difficulty**: schwer  
**Material**: Unicycles, race course  
**Duration**: approx. 5-15 minutes

## Game Description

Unicyclists race over a set distance or through an obstacle course. Larger wheels can be given a delayed start so the race stays fair. The first legal finish wins.

## Variations

Run separate wheel-size categories for serious competition.

## Safety Notes

Keep the playing area clear and define the limits before the round starts. For contact games, target props rather than bodies. For throwing, riding, balancing or acrobatic games, leave enough space for failed attempts and stop the round if the group starts taking unsafe risks.
