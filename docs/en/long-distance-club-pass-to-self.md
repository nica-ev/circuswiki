> [!info] Short Description
> A single player throws a club forward, moves after it and catches it as far from the start as possible.

**Group Size**: 2 to 40 players  
**Difficulty**: mittel  
**Material**: Juggling clubs, distance markers  
**Duration**: approx. 5-15 minutes

## Game Description

A single player throws a club forward, moves after it and catches it as far from the start as possible. The distance counts only if the throw is caught cleanly.

## Variations

Give each player three attempts and count the best valid catch.

## Safety Notes

Keep the playing area clear and define the limits before the round starts. For contact games, target props rather than bodies. For throwing, riding, balancing or acrobatic games, leave enough space for failed attempts and stop the round if the group starts taking unsafe risks.
