> [!info] Short Description
> Every competitor receives a diabolo setup tangled in the same way.

**Group Size**: 2 to 40 players  
**Difficulty**: mittel  
**Material**: Several identically tangled diabolo sets  
**Duration**: approx. 5-15 minutes

## Game Description

Every competitor receives a diabolo setup tangled in the same way. On the signal, players try to untangle the diabolo and handsticks cleanly. The first player to restore a usable setup wins.

## Variations

Create easier and harder tangles for different skill groups.

## Safety Notes

Keep the playing area clear and define the limits before the round starts. For contact games, target props rather than bodies. For throwing, riding, balancing or acrobatic games, leave enough space for failed attempts and stop the round if the group starts taking unsafe risks.
