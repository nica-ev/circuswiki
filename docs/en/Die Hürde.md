> [!info] Short Description
> A cooperative task where the entire group must cross over a taut rope without touching it.

**Group Size**: 4-20 people
**Difficulty**: Medium
**Materials**: Rope
**Playtime**: 5-10 minutes

## **Game Description**:

A rope is stretched taut between two fixed beams, posts, trees, or similar structures. The game leader must carefully judge the height at which the rope is tensioned. A single player should be able to jump over the rope. The goal of the game is to get everyone across the rope without touching it or crawling underneath. This means players must lift and carry each other over the rope, build human pyramids, or use "robber's ladders" (a technique where one person supports another to climb over). Each group will find its own way to get everyone across the rope. If any player touches the rope, everyone must return to the starting side.
