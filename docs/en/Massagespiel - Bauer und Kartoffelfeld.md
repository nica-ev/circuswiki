> [!info] Brief Description
> A circle massage game where pairs enact a calm farmer and potato field scenario together.

**Group Size**: 4-20 people
**Difficulty**: Easy
**Materials**: None
**Duration**: 5-10 minutes

## **Game Description**:

A massage game for small to medium-sized groups.
It is also excellently suited for younger children.

Everyone sits in a circle. There should be an even number of people (including the facilitator) so that everyone has a partner. If the number is odd, the facilitator can "assist" one of the pairs.
