# Hodgepodge

## Props

Balls and any other props.

## Goals

*   Team building
*   Memorizing names
*   Group cooperation
*   Learning to prioritize tasks
*   Practicing coordination
*   Getting comfortable with different props, throwing techniques, and passing methods
*   Building resilience to stress and pressure, which gradually increases and can reach its peak

## Procedure

1.  The group stands in a circle, with everyone's hands relaxed.
2.  The facilitator throws a ball to one person, says their name aloud, and remembers who they threw it to.
3.  After throwing, the facilitator puts their hands behind their back. This signifies they have already had the ball and cannot be thrown to.
4.  Each subsequent person repeats these actions.
5.  The last person has no one to throw to, so they throw it back to the facilitator. This closes the loop.
6.  The sequence is repeated without changes, and hands are no longer hidden.
7.  More balls are gradually added. The number depends on the group size.

## Additional Rules

More rules can be added, for example:

*   If I have a red ball, I do a squat before throwing it.
*   If I have a blue hoop, I must run to the person and hand it to them instead of throwing.
*   Additional props can be passed around the circle, such as hula hoops, rings, or scarves.
*   Some props can move in the opposite direction.
*   We start in a circle, but at some point, we can move around the room and continue the game while in motion.

## Applications

"Hodgepodge" can achieve various goals depending on the number and type of props used, as well as the additional tasks incorporated.

If scarves, feathers, or soft balls are used – props suitable for a slower pace – and tasks like taking a deep breath, yawning, or stretching are added, the game can serve as a good way to conclude a session.

If a large number of balls, hoops, or clubs are used, setting a fast pace, and tasks like "do a push-up," "touch the door," "jump 3 times," or "run around the circle" are included, the game can function as a warm-up and allow the group to expend energy.

## Related

This activity is related to existing games involving passing balls in a circle, but the source material describes a unique variation with a strong emphasis on changing props, task prioritization, and scaling pressure.
