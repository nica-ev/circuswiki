> [!info] Short Description
> A high-skill numbers endurance game for seven-club jugglers.

![7-club-endurance](../img/7-club-endurance.jpg){ width=300 }

**Group Size**: 2 to 30 players
**Difficulty**: schwer
**Material**: Seven juggling clubs per player
**Duration**: approx. 3-15 minutes

## Game Description

Players attempt to keep seven clubs in the air for as long as possible. The longest verified run wins.

## Setup

- Use a very open area with clear separation between jugglers.
- Define the start: simultaneous start, start window, or individual attempts.
- Assign judges or use video if exact timing matters.

## Rules

1. Players begin seven-club juggling under the agreed start rule.
2. The attempt continues while seven clubs are maintained in the agreed pattern.
3. A drop, collection, restart, or reduction below seven ends the attempt.
4. The winner is the player with the longest continuous verified run.
5. If several players exceed the time limit, run a final or declare shared winners.

## Variations

- Use individual attempts for safety and clearer judging.
- Run a personal-best workshop version.
- Require a clean collect after the run for advanced scoring.

## Safety Notes

This is for advanced jugglers only. Seven clubs need significant height and lateral space.
