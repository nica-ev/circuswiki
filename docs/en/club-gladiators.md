> [!info] Short Description
> The classic convention combat game where club jugglers try to be the last person still juggling.

![[../img/club-gladiators.jpg|300]]

**Group Size**: 3 to 80 players
**Difficulty**: schwer
**Material**: Three juggling clubs per player, marked arena
**Duration**: approx. 5-15 minutes

## Game Description

Everyone juggles three clubs in the same arena. Players attack the opponents' juggling patterns while keeping their own pattern alive.

## Setup

- Mark a clear arena with space for eliminated players to leave safely.
- Agree that attacks target props, not bodies.
- Only include players who can maintain a stable three-club pattern under movement.

## Rules

1. All players start juggling three clubs together.
2. Players move through the arena and try to make opponents drop by disturbing their club patterns.
3. A player is out when they drop, collect, stop juggling, or no longer have the required three clubs in pattern.
4. Eliminated players stop interfering immediately and leave the field.
5. The last player still juggling wins the round.

## Variations

- Run team gladiators and award points to the winner's team.
- Add handicap rules for very strong players.
- Use a no-body-contact rule for safer mixed-level play.

## Safety Notes

The public rule set should explicitly forbid attacks to bodies and dangerous throws into faces.
