> [!info] Short Description
> Players throw their diabolo forward from a start point, run after it and try to catch it themselves.

**Group Size**: 2 to 40 players  
**Difficulty**: mittel  
**Material**: Diabolos and handsticks, distance markers  
**Duration**: approx. 5-15 minutes

## Game Description

Players throw their diabolo forward from a start point, run after it and try to catch it themselves. The longest clean self-throw wins.

## Variations

Use lanes if several players throw at the same time, or run one player at a time for better safety.

## Safety Notes

Keep the playing area clear and define the limits before the round starts. For contact games, target props rather than bodies. For throwing, riding, balancing or acrobatic games, leave enough space for failed attempts and stop the round if the group starts taking unsafe risks.
