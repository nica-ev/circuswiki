> [!info] Short Description
> Players attempt seven-ball juggling for maximum duration.

**Group Size**: 3 to 60 players  
**Difficulty**: schwer  
**Material**: Seven balls per player  
**Duration**: approx. 5-15 minutes

## Game Description

Players attempt seven-ball juggling for maximum duration. The longest clean run wins. This is a high-skill numbers event and can be run as individual attempts for clearer judging.

## Variations

Require a clean collect after the run for an advanced scoring rule.

## Safety Notes

Keep the playing area clear and define the limits before the round starts. For contact games, target props rather than bodies. For throwing, riding, balancing or acrobatic games, leave enough space for failed attempts and stop the round if the group starts taking unsafe risks.
