> [!info] Short Description
> A five-ball endurance contest where the last active juggler wins.

![5-ball-endurance](../img/5-ball-endurance.jpg){ width=300 }

**Group Size**: 2 to 80 players  
**Difficulty**: mittel  
**Material**: Five juggling balls per player  
**Duration**: approx. 3-15 minutes

## Game Description

All players start juggling five balls at the same time. Anyone who drops, collects, restarts or stops the agreed five-ball pattern is out. Eliminated players leave the active area quietly so the remaining jugglers have enough space.

The last player still juggling wins. If several strong jugglers remain for a long time, set a time limit and move into a final round with extra tasks.

## Setup

- Give each player enough space for five-ball juggling.
- Agree whether any five-ball pattern is allowed or whether the cascade is required.
- Decide whether the game is elimination-based or a personal-best endurance challenge.

## Variations

- Add required tricks or movement after a fixed time.
- Run heats and a final for large groups.
- Use the same format for other numbers or props.

## Safety Notes

This is low-contact, but five-ball drops spread quickly. Keep spectators and eliminated players outside the active juggling area.
