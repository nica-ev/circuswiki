# Tuchjonglage - Basisprincipes

Het jongleren met doeken is, vanwege de langzame vluchtbeweging (door de hoge luchtweerstand van de doeken), bijzonder geschikt om de basisprincipes van het werpjongleren te leren.

Vaak kan binnen zeer korte tijd een leerresultaat worden bereikt, zelfs tot het jongleren met 3 doeken.

Voor beginners is het bovendien erg nuttig om verschillend gekleurde doeken te gebruiken om een beter overzicht van de gebeurtenissen te krijgen.
