# Workshop Thema Piraten

Vooral voor kinderen in de kleuterleeftijd is het aan te raden om disciplines thematisch te integreren. Een populair thema is zeker "Piraten".

Eenvoudige manieren om het balanceren op het koord te integreren zijn:

- het oversteken van een diepe kloof op zoek naar de piratenschat

Op vergelijkbare wijze kunnen voor (bijna) alle disciplines thematische toepassingen gevonden worden.

- Luchtacrobatiek: klimmen in het schip in de tuigage
- Doekjongleren: rode doeken worden gebruikt als vuur waarop marshmallows / appels worden geroosterd, deze worden heet en moeten van hand tot hand worden gegooid
